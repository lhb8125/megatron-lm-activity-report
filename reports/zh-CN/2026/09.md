# Megatron-LM 月度活动报告 — 2026年9月（截至2026-09-06）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/09.md)

> 统计周期：2026-09-01 至 2026-09-06（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作推进了 Megatron-LM 的推理服务、上下文并行执行、分布式优化、模型特性、检查点和验证；持续工作则推进稀疏注意力、分布式训练与分片、混合架构、推理、CUDA Graph 执行和动态上下文并行。

- 过滤后的实质性 PR 活动：新开 87；合并 58；关闭未合并 28；截止时仍在进行 147。
- 不计入报告正文和统计：纯 UT 12，纯 CI 2，UT/CI-only 1，纯格式化 0。

## 已交付成果

### 推理服务、路由与请求可靠性

改进了推理前端扩展、协调器路由、前缀缓存行为、请求取消、采样健壮性和多模态执行。

- 通过 data-parallel 副本扩展 HTTP 推理前端，将 tokenization 及相关 CPU 工作移出协调器 event loop，并更新协调器 framing、prompt hashing、prefix-cache versioning 与 TTL 处理，以及负载感知路由。（[main #6223](https://github.com/NVIDIA/Megatron-LM/pull/6223)、[main #6497](https://github.com/NVIDIA/Megatron-LM/pull/6497)）
- 通过取消孤立请求、清理非有限 log probability 与 sampling filter、验证 hybrid 和 asynchronous 路径中的 prefix-cache 状态、覆盖 asynchronous scheduling 场景，并在 vision-encoder 重计算前将 multimodal 输入移至 CUDA，增强服务可靠性。（[main #6916](https://github.com/NVIDIA/Megatron-LM/pull/6916)、[main #6976](https://github.com/NVIDIA/Megatron-LM/pull/6976)、[main #6993](https://github.com/NVIDIA/Megatron-LM/pull/6993)、[main #7031](https://github.com/NVIDIA/Megatron-LM/pull/7031)、[main #7053](https://github.com/NVIDIA/Megatron-LM/pull/7053)）

### 上下文并行与 packed-sequence 训练

扩展了 variable-length 和 packed-sequence 支持，同时修正 hybrid 与 runtime context-parallel 的 batch、attention 和 THD 布局。

- 在 context-parallel 分区期间保留 dataset metadata，将 variable-length batch 和 sequence-packing scheduling 集成到 GPT 与 hybrid pretraining，并恢复 tensor-parallel ranks 所需的二维 hybrid-CP batch schema。（[main #5531](https://github.com/NVIDIA/Megatron-LM/pull/5531)、[main #6742](https://github.com/NVIDIA/Megatron-LM/pull/6742)、[main #6820](https://github.com/NVIDIA/Megatron-LM/pull/6820)）
- 使 runtime context-parallel attention 使用惰性创建的 Transformer Engine streams 和 runtime packed-sequence groups，独立分区 packed THD sequences，并通过 MTP 复用 redistribution plans；同时在受支持的后端中加入 GDP chunkwise context parallelism。（[main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821)、[main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912)、[main #7038](https://github.com/NVIDIA/Megatron-LM/pull/7038)）

### FSDP 与 MFSDP 分片、预取和存储

改进了混合 MoE 分片、通信调度、持久化参数与梯度存储，以及分布式优化器兼容性。

- 加入 FSDP 参数预取和独立的 MFSDP forward、backward 预取预算，同时在 optimizer steps 之间将 model weights 与 main gradients 保存在持久化存储中。（[main #5985](https://github.com/NVIDIA/Megatron-LM/pull/5985)、[main #6905](https://github.com/NVIDIA/Megatron-LM/pull/6905)、[main #6962](https://github.com/NVIDIA/Megatron-LM/pull/6962)、[main #7001](https://github.com/NVIDIA/Megatron-LM/pull/7001)）
- 允许 expert 与 non-expert parameters 使用不同的 FSDP sharding strategies，将延迟的 Transformer Engine weight gradients 接入 MFSDP 完成流程，将 distributed-optimizer parameter views 解耦为 leaf shards，并使 sharding-strategy validation 与共享的 ZeRO ladder 对齐。（[main #6594](https://github.com/NVIDIA/Megatron-LM/pull/6594)、[main #6697](https://github.com/NVIDIA/Megatron-LM/pull/6697)、[main #6982](https://github.com/NVIDIA/Megatron-LM/pull/6982)、[main #6983](https://github.com/NVIDIA/Megatron-LM/pull/6983)）

### Transformer Engine 模型特性与训练路径

加入 fused attention 和 activation 能力、LatentMoE 归一化及仅 MTP 训练模式，同时修正 activation dispatch。

- 通过 Transformer Engine 将 DeepSeek Q up-projection 与 RoPE 和 MXFP8 quantization 融合，用于 MLA 执行。（[main #6213](https://github.com/NVIDIA/Megatron-LM/pull/6213)）
- 在 dense 与 expert 路径中加入 SiTU-GLU、LatentMoE RMSNorm projection 支持，以及 tanh soft-clamped squared-ReLU 和 SiTU GLU 变体，覆盖 fused 与 unfused MoE training 和 inference 路径。（[dev #6673](https://github.com/NVIDIA/Megatron-LM/pull/6673)、[dev #6804](https://github.com/NVIDIA/Megatron-LM/pull/6804)、[main #7003](https://github.com/NVIDIA/Megatron-LM/pull/7003)）
- 修正 ReGLU 和 ReLU 的 Transformer Engine activation selection，并加入仅 MTP 训练：将 backbone 排除在 optimizer 与 DDP buffers 之外，并无梯度运行其 decoder。（[main #5999](https://github.com/NVIDIA/Megatron-LM/pull/5999)、[main #7021](https://github.com/NVIDIA/Megatron-LM/pull/7021)）

### MoE 路由与并行执行正确性

改进了无辅助损失路由，并修复参数同步、tensor-parallel autograd、CUDA-graph capture、CPU 初始化和 GQA 配置验证。

- 加入基于 histogram 的 global-batch quantile balancing 用于 MoE routing，并将 grouped TP=1 MLP pre-forward hooks 传递 through normalization 和 fused execution views。（[dev #6637](https://github.com/NVIDIA/Megatron-LM/pull/6637)、[main #6654](https://github.com/NVIDIA/Megatron-LM/pull/6654)）
- 在 TP=1 时绕过 custom gather autograd view，在 CUDA-graph capture 期间记录 repeated generalized tensor-parallel weight-gradient finalization，为 GTP dense layers 加入 CPU initialization 支持，并在 configuration 阶段验证 GQA query-group counts 与 head divisibility。（[main #5756](https://github.com/NVIDIA/Megatron-LM/pull/5756)、[main #6657](https://github.com/NVIDIA/Megatron-LM/pull/6657)、[main #6862](https://github.com/NVIDIA/Megatron-LM/pull/6862)、[main #6986](https://github.com/NVIDIA/Megatron-LM/pull/6986)）

### 检查点、量化与环境兼容性

改进了 rank-specific checkpoint restoration、quantized refit conversion、可选 FlashAttention 导入、ModelOpt 导出行为和 experimental-tree 同步。

- 将 data-parallel 与 context-parallel ranks 纳入 checkpoint RNG shard keys，并使 experimental Megatron Lite tree 与 QAT、dynamic CP、checkpoint streaming、router replay 和 DeepSeek-V4 更新同步。（[dev #6397](https://github.com/NVIDIA/Megatron-LM/pull/6397)、[main #6858](https://github.com/NVIDIA/Megatron-LM/pull/6858)）
- 将 BF16 refit weights 直接转换为持久化 MXFP8 buffers，在 optional imports 前检查已安装的 FlashAttention 4 distribution，并在 ModelOpt FP8 exports 中加入 KV-cache scale clamping 控制。（[main #6952](https://github.com/NVIDIA/Megatron-LM/pull/6952)、[main #6964](https://github.com/NVIDIA/Megatron-LM/pull/6964)、[main #7024](https://github.com/NVIDIA/Megatron-LM/pull/7024)）

### CI、DSA 验证与并行配置覆盖

扩展了 multimodal 和 DSA 验证，并使 pipeline configuration checks 与 runtime argument validation 对齐。

- 加入专用 H100 multimodal unit-test bucket，将 multimodal parity scripts 转为可执行 pytest tests，并扩展 DSA ReFIT 覆盖，涵盖 absorbed-MLA 和 GQA models、TP、PP 与 DP transitions，同时在 CI 中固定 NCCL M2N extensions。（[dev #6083](https://github.com/NVIDIA/Megatron-LM/pull/6083)、[main #6998](https://github.com/NVIDIA/Megatron-LM/pull/6998)）
- 将 DSA FLOP accounting 扩展到 absorbed attention、top-k sparsity、indexer projections 和 dense indexer scoring，并使 interleaved pipeline parallelism 的 YAML validation 与 CLI 对 p2p overlap 和 pipeline size 的检查对齐。（[main #6732](https://github.com/NVIDIA/Megatron-LM/pull/6732)、[dev #6753](https://github.com/NVIDIA/Megatron-LM/pull/6753)、[main #7043](https://github.com/NVIDIA/Megatron-LM/pull/7043)）

## 进行中的方向

### DeepSeek V4 稀疏注意力与 DSA 执行

扩展 DeepSeek 稀疏注意力索引、packed context-parallel execution、scoring plans、static-shape backward 和 fused THD processing。

- 加入紧凑型 SM100 DSA indexer 和 BF16、MXFP8 的 Top-K execution，包括 THD context-parallel layouts 与 CUDA-graph workspaces，并支持 non-compact fallback。（[dev #5992](https://github.com/NVIDIA/Megatron-LM/pull/5992)）
- 加入 load-balanced packed-THD DSA context parallelism，支持 complementary query chunks、fixed-capacity all-to-all routing 和 graph-safe metadata；同时融合 packed-THD CSA layout lowering、position mapping、indexer 与 attention preparation、context-parallel compression 和 sparse-loss postprocessing。（[dev #6058](https://github.com/NVIDIA/Megatron-LM/pull/6058)、[dev #7064](https://github.com/NVIDIA/Megatron-LM/pull/7064)）
- 为 packed THD inputs 加入 plan-driven DSA scoring，并使用由 host-side sequence information 构建且 memoized 的 context-parallel layout metadata。（[dev #6206](https://github.com/NVIDIA/Megatron-LM/pull/6206)）
- 对空的 DSA sparse-attention query rows 使用 fixed-shape cuDNN tiles，在清零空行贡献的同时保留 CUDA-graph-compatible backward shapes。（[pull-request/6206 #6910](https://github.com/NVIDIA/Megatron-LM/pull/6910)）

### MFSDP v2 调度与 MXFP8 分片

围绕 fine-grained schedules、virtual-pipeline execution、MXFP8 weights 和 communication overlap 扩展 MFSDP v2。

- 将 MFSDP v2 与 activation recomputation、expert-parallel 1F1B overlap 以及 pipeline 或 virtual-pipeline model chunks 集成，包括 delayed expert gradients 和 cross-stage embedding reductions。（[main #6197](https://github.com/NVIDIA/Megatron-LM/pull/6197)）
- 加入 MXFP8 primary-weight parameter groups，配合 persistent FP32 master weights，以及用于 sharded Transformer Engine quantized compute 的 row-wise 和 column-wise payload buffers。（[main #6485](https://github.com/NVIDIA/Megatron-LM/pull/6485)）
- 在 virtual-pipeline chunks 间共享 MFSDP context，加入 communication streams 与 prefetch 或 release operations 的 trace-replay ordering，并将 NCCL memory pools 与 persistent allocation arenas 限定到每个 FSDP ParamAndGradBuffer，支持幂等 teardown。（[main #6486](https://github.com/NVIDIA/Megatron-LM/pull/6486)、[main #6923](https://github.com/NVIDIA/Megatron-LM/pull/6923)）
- 将 MFSDP v2 与 fine-grained combined-1F1B scheduling、demand unsharding、explicit resharding 和 delayed gradient reduction 集成，同时跟踪 producer streams、plan boundaries、aliases 与 phase finalization 之间的 tensor ownership 和 release。（[pull-request/6484 #6692](https://github.com/NVIDIA/Megatron-LM/pull/6692)、[dev #7062](https://github.com/NVIDIA/Megatron-LM/pull/7062)）

### 广义 tensor parallelism 与优化器分片

扩展 generalized tensor-parallel execution，并为 replicated weights 加入 hybrid optimizer-state sharding。

- 为 multimodal Qwen3.5-VL training、checkpointing、optimizer、inference、quantization、communication、resharding 和 CUDA-graph paths 加入 generalized tensor-parallel support。（[dev #6608](https://github.com/NVIDIA/Megatron-LM/pull/6608)）
- 为 replicated weights 加入 DP-Outer optimizer-state sharding、explicit single-rank gradient scaling，以及 hybrid ZeRO configurations 的 parameter-group splitting。（[main #6773](https://github.com/NVIDIA/Megatron-LM/pull/6773)）
- 通过 weight sharding、asynchronous materialization、gradient reduction、CUDA-graph support、low-precision gathering 和 checkpointing，扩展 model components 的 generalized tensor parallelism。（[dev #6882](https://github.com/NVIDIA/Megatron-LM/pull/6882)）

### DeepSeek 与混合模型架构

加入 native hybrid attention 和 routing 能力、fused GatedDeltaNet execution、residual aggregation 及新的 multimodal model paths。

- 加入 native DeepSeek V4 hybrid attention orchestration、module specifications、grouped output handling、MTP propagation 和 indexer-loss scheduling，支持 sparse 与 absorbed attention primitives。（[main #6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)）
- 在 HybridModel execution、MTP、recomputation、metrics 和 gradient finalization 中加入 token-ID transport 与 hash-based MoE routing，同时保留其他位置的 ordinary routing。（[main #6403](https://github.com/NVIDIA/Megatron-LM/pull/6403)）
- 集成基于内部 CuTe 的 GatedDeltaNet forward、backward 和 context-parallel preprocessing kernels，支持 dense 与 packed workloads。（[dev #6511](https://github.com/NVIDIA/Megatron-LM/pull/6511)）
- 加入可配置的 depth-wise attention residual aggregation，支持 block structure、pipeline-parallel transport、hybrid-model 和 MTP handling。（[dev #6840](https://github.com/NVIDIA/Megatron-LM/pull/6840)）

### 混合精度与多模态模型支持

改进 DeepSeek quantized training，并加入新的 multimodal hybrid architectures。

- 为 DeepSeek-V3 training 加入 NVFP4-aware overlap contexts、FP4 MTP initialization、fused-MLA checkpoint-name matching、delayed MLA weight-gradient handling 和 per-module precision names。（[main #6841](https://github.com/NVIDIA/Megatron-LM/pull/6841)）
- 加入 DeepSeek V4 Flash-Vision model，支持 native vision tower、2D RoPE、image-aware hybrid attention 和 VL-aware early MoE routing。（[dev #7022](https://github.com/NVIDIA/Megatron-LM/pull/7022)）
- 加入 opt-in RoPE Transformer audio encoder，支持 dense 与 packed THD inputs 的 offline、causal 和 mixed per-sequence attention，同时保留 legacy default。（[main #7066](https://github.com/NVIDIA/Megatron-LM/pull/7066)）

### MoE 执行与路由

加入 pluggable 和 specialized expert execution paths，同时改进 virtual-expert routing 与 expert-bias arithmetic。

- 加入 pluggable MoE megakernel interface，支持 Mixture-of-Kittens routing、expert execution、weight views 和 gradient adapters，同时保留 MCore-owned parameters 与 checkpoint names。（[dev #6572](https://github.com/NVIDIA/Megatron-LM/pull/6572)）
- 加入 virtual-expert HybridEP routing、planning、weight replication、gradient reduction 和 Triton transport，用于 dedicated expert duplication。（[main #6892](https://github.com/NVIDIA/Megatron-LM/pull/6892)）
- 将 local expert token counts 存储为 int64，并在转换 update 前使用 integer arithmetic 计算 expert-bias update directions。（[main #7081](https://github.com/NVIDIA/Megatron-LM/pull/7081)）

### 解耦与优化的推理

扩展 inference state transfer、expert execution、validity handling 和 prefix-cache reuse。

- 加入端到端 prefill/decode disaggregation，由 coordinator 管理 handoff，并通过 NCCL 或 NIXL 在独立并行化的 shards 间传输 KV 与 SSM state。（[main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)）
- 加入 Transformer Engine MXFP8 grouped-GEMM inference backend，支持 device-resident routing、fixed zero padding，以及 conversion、refit 和 CUDA graphs 兼容。（[main #6933](https://github.com/NVIDIA/Megatron-LM/pull/6933)）
- 通过为 EP=1 绑定 valid-row counts、保护 inherited cached KV blocks，并为 all-greedy FlashInfer batches 使用 deterministic argmax semantics，改进 dynamic inference。（[main #7061](https://github.com/NVIDIA/Megatron-LM/pull/7061)）
- 为 prefix KV blocks 加入 setting-keyed prompt-logprob sidecars，并支持 chunk-boundary score transfer 与 hybrid replay reconstruction。（[main #7063](https://github.com/NVIDIA/Megatron-LM/pull/7063)）

### CUDA Graph 执行与训练生命周期

改进 partial graph capture、offload replay、resource teardown、schedule-aware tensor ownership 和 training synchronization。

- 加入 opt-in local CUDA-graph mode，将 graphable Mamba、attention 和 MoE-router spans 合并，同时让 dynamic expert computation 保持 eager。（[main #6994](https://github.com/NVIDIA/Megatron-LM/pull/6994)）
- 使 hybrid mHC CUDA-graph capture 管理 activation-offload event boundaries、保留 rotary arguments，并在每个 graph task 中记录 backward completion；同时将 diagnostic scalars 保留在 device 上、批量执行 logging reads、延后 exit decisions，并使用 CUDA events 作为 training timers。（[dev #7014](https://github.com/NVIDIA/Megatron-LM/pull/7014)、[main #7076](https://github.com/NVIDIA/Megatron-LM/pull/7076)）
- 将 capture-local handshake events 与 cross-graph external events 分离，以支持 fine-grained offload throttling，并管理 nested sibling capture sessions。（[dev #7020](https://github.com/NVIDIA/Megatron-LM/pull/7020)）
- 通过重置 communicator-backed caches、删除 tracked CUDA graphs、安全中止 NCCL backends，并避免不必要的 checkpoint DTensor-group rebuilding，改进 model-parallel teardown。（[main #7029](https://github.com/NVIDIA/Megatron-LM/pull/7029)）

### Runtime context parallelism 与序列布局

加入 runtime context-parallel topology 支持，以及面向 packed training 和 evaluation 的 layout-aware sequence handling。

- 为 MTP inputs、masks、positions、cross-entropy 和 total-variation targets 加入 layout-aware absolute-offset sequence-roll contexts，覆盖 GPT、HybridModel、packed CP、dynamic CP 和 CUDA-graph paths。（[pull-request/6473 #6741](https://github.com/NVIDIA/Megatron-LM/pull/6741)）
- 为 packed microbatches 定义 runtime context-parallel group contract，集中处理 group resolution，并在 forward 后恢复 build-time attention 与 Transformer Engine state。（[main #7045](https://github.com/NVIDIA/Megatron-LM/pull/7045)）
- 将 dynamic context parallelism 集成到 standard training 和 evaluation schedules，支持 runtime subgroups、packed metadata propagation 和 CP-lane-local data-parallel rerouting；通过一个 DPxCP communicator 上的 logical descriptors，以及使用 native 或 ProcessGroup transport 的 bounded-peer ring layouts，支持任意 CP sizes。（[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)、[dev #7097](https://github.com/NVIDIA/Megatron-LM/pull/7097)）
- 将 runtime context-parallel groups 传递 through GatedDeltaNet、Mamba、MLA、absorbed MLA、attention 和 MTP hybrid-model paths。（[main #7048](https://github.com/NVIDIA/Megatron-LM/pull/7048)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
