# Megatron-LM 月度活动报告 — 2026年9月（截至2026-09-13）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/09.md)

> 统计周期：2026-09-01 至 2026-09-13（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作扩展了 DeepSeek-V4 和混合模型能力，强化了 MoE 与 MFSDP 执行，提升了推理和上下文并行的可靠性，并增加了 kernel 确定性覆盖。进行中的工作推进混合与多模态架构、分布式并行、稀疏注意力、checkpoint、CUDA Graph 执行、推理和训练可靠性。

- 过滤后的实质性 PR 活动：新开 237；合并 115；关闭未合并 59；截止时仍在进行 268。
- 不计入报告正文和统计：纯 UT 19，纯 CI 6，UT/CI-only 3，纯格式化 0。

## 已交付成果

### DeepSeek-V4 压缩稀疏注意力

DeepSeek-V4 原生支持压缩稀疏注意力编排、紧凑 indexer 执行、packed-THD 融合以及与执行对齐的 FLOP 统计。

- 原生 DeepSeek-V4 注意力现在通过 module specification、分组输出、MTP identity 传播和 indexer-loss 跟踪来构建并调度 SBHD 压缩稀疏注意力；紧凑的 cuDNN indexer 和 Top-K 执行将该路径扩展到 BF16、MXFP8、CUDA graphs 和 THD context parallelism。（[dev #5992](https://github.com/NVIDIA/Megatron-LM/pull/5992)、[main #6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)）
- Packed-THD CSA 执行融合了 layout lowering、位置映射、indexer 与 compressor 准备、sparse-loss 后处理及相关 context-parallel kernels；FLOP 统计覆盖 sparse core attention、indexer 工作、absorbed-MLA 成本和 hybrid DSA layers。（[dev #6753](https://github.com/NVIDIA/Megatron-LM/pull/6753)、[main #7043](https://github.com/NVIDIA/Megatron-LM/pull/7043)、[dev #7064](https://github.com/NVIDIA/Megatron-LM/pull/7064)、[dev #7157](https://github.com/NVIDIA/Megatron-LM/pull/7157)）

### Qwen3.5-VL HybridModel 架构

Qwen3.5-VL 转向显式的混合架构表示。

- Qwen3.5-VL decoder 现在使用显式的 HybridModel stack，由 GatedDeltaNet、attention、dense 和 MoE layers 组成，同时保留其 layer cadence、MTP behavior 和 mRoPE execution。（[dev #6315](https://github.com/NVIDIA/Megatron-LM/pull/6315)）

### 推理协调器路由

推理协调针对更大的 payload、prefix-cache 正确性和感知负载的路由进行了更新。

- Inference coordinator wire framing、frontend prompt hashing、prefix-cache versioning 与 TTL handling，以及 load-aware routing 均已更新：将大型 payload 移出 metadata，避免过期 cache 匹配，限制 coordinator hash state，并在 cache affinity 与 fleet load 之间实现平衡。（[main #6497](https://github.com/NVIDIA/Megatron-LM/pull/6497)）

### MoE 融合执行、分片与精度

MoE 执行新增可选的 fused backends、独立的 dense 与 expert sharding、精确的 expert balancing，以及更安全的 precision overrides。

- MoE 执行现在提供可插拔的 megakernel 边界和 Mixture-of-Kittens backend；MFSDP v2 允许 dense 与 expert parameters 使用独立的 optimizer-instance counts、meshes 和 outer data-parallel sharding strategies。（[dev #6572](https://github.com/NVIDIA/Megatron-LM/pull/6572)、[main #7012](https://github.com/NVIDIA/Megatron-LM/pull/7012)）
- MoE expert token counters 使用 int64 算术进行 bias updates；当任一 linear 被配置为 non-quantized execution 时，grouped-expert fusion 会被禁用，使 precision overrides 选择 unfused path。（[main #7081](https://github.com/NVIDIA/Megatron-LM/pull/7081)、[main #7212](https://github.com/NVIDIA/Megatron-LM/pull/7212)）

### Runtime 与 packed-THD 上下文并行

上下文并行注意力和 packed-batch 处理现在使用 runtime state，并保留每个 sequence 的布局。

- Runtime context-parallel attention 会延迟创建 Transformer Engine CP stream，并将 runtime packed-sequence CP group 传递给 RoPE，确保 attention 使用 active stream 和 sequence-position partition。（[main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821)）
- Packed THD batches 现在使用多个 CP views，并独立划分每个 packed sequence；通过 MTP forward execution 复用 redistribution plans，同时保持 token shards 与 PackedSeqParams 一致。（[main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912)）

### 分布式状态与 checkpoint 可靠性

分布式权重复制、RNG 恢复和重复 MTP 执行现在能在异步及恢复工作流中保持正确状态。

- Local refit-copy streams 在读取 source weights 前，会等待 caller stream 完成 NCCL、Gloo、NIXL 和 NVSHMEM services；这可防止同 rank copies 与排队的 producer updates 发生竞争。（[main #6823](https://github.com/NVIDIA/Megatron-LM/pull/6823)）
- Checkpoint RNG shard keys 现在包含 data-parallel 和 context-parallel rank，从而恢复独立的 expert-parallel RNG streams；重复的 MTP layers 还会避免在 checkpoint resume 和 backward execution 期间向 Transformer Engine 传递过期的 first-microbatch state。（[main #6858](https://github.com/NVIDIA/Megatron-LM/pull/6858)、[main #6965](https://github.com/NVIDIA/Megatron-LM/pull/6965)）

### MFSDP v2 CUDA graphs 与梯度累积

MFSDP v2 获得了 full-iteration CUDA-graph 支持和正确的 no-sync gradient accumulation。

- MFSDP v2 现在支持 full-iteration CUDA graphs，并在 replay 期间保留 optimizer gradient bindings；Hybrid mHC graph capture 保留 fine-grained activation-offload events、callable backward-completion ordering 和 rotary-position arguments，使 Transformer Engine replay 保留 offload dependencies 及所需的 RoPE inputs。（[dev #7014](https://github.com/NVIDIA/Megatron-LM/pull/7014)、[main #7075](https://github.com/NVIDIA/Megatron-LM/pull/7075)）
- MFSDP v2 的 no-sync handling 会标记非最终 microbatches 并安装 reduction context，使 accumulated gradients 仅在最后一个 microbatch 上完成。（[main #7186](https://github.com/NVIDIA/Megatron-LM/pull/7186)）

### Kernel 确定性覆盖

现在通过 byte-exact tests 和 CI coverage requirements 强制执行 kernel replay determinism。

- Byte-exact kernel replay tests、kernel-source manifest 和 CI gate 现在要求发生变更的 kernel files 包含 determinism coverage 或经批准的 exemption。（[main #7148](https://github.com/NVIDIA/Megatron-LM/pull/7148)）

## 进行中的方向

### 混合、DeepSeek 与多模态模型架构

新的模型能力和执行路径将 HybridModel 扩展到 DeepSeek、GLM、Engram、attention residual、audio 和 multimodal workloads。

- HybridStack 新增 grouped scheduling，包含 grouped layer allocation、expert-parallel overlap、recomputation、inference-cache indexing 和兼容的 checkpoint naming；attention residuals 则新增 depth-wise softmax aggregation，并支持 pipeline-parallel、interleaved、hybrid-model 和 MTP。（[main #4942](https://github.com/NVIDIA/Megatron-LM/pull/4942)、[dev #6840](https://github.com/NVIDIA/Megatron-LM/pull/6840)）
- DeepSeek-V4 和 V4.1 新增 sparse-attention construction 与 fused execution、NVFP4 training support、CSA2、cross-layer sharing、native mHC、THD、pipeline parallelism、recomputation 和 CUDA-graph integration。（[main #6404](https://github.com/NVIDIA/Megatron-LM/pull/6404)、[main #6841](https://github.com/NVIDIA/Megatron-LM/pull/6841)、[dev #7224](https://github.com/NVIDIA/Megatron-LM/pull/7224)、[dev #7285](https://github.com/NVIDIA/Megatron-LM/pull/7285)）
- HybridModel 新增 ShortcutMoE、GLM-5.3 Flash、DeepSeek V4 Flash-Vision 和 trainable Engram memory capabilities。（[main #6959](https://github.com/NVIDIA/Megatron-LM/pull/6959)、[dev #7022](https://github.com/NVIDIA/Megatron-LM/pull/7022)、[main #7054](https://github.com/NVIDIA/Megatron-LM/pull/7054)、[main #7178](https://github.com/NVIDIA/Megatron-LM/pull/7178)、[dev #7231](https://github.com/NVIDIA/Megatron-LM/pull/7231)）
- Multimodal training 通过 dual-mode RoPE audio encoder、Energon conversation and media processing，以及集成式 packed multimodal SFT training 得到扩展。（[main #7066](https://github.com/NVIDIA/Megatron-LM/pull/7066)、[main #7254](https://github.com/NVIDIA/Megatron-LM/pull/7254)、[main #7255](https://github.com/NVIDIA/Megatron-LM/pull/7255)）

### Checkpoint 合并、互操作性与可训练参数状态

Checkpoint 工作改进了分布式合并、optimizer resharding、GPT-to-Hybrid 兼容性、逻辑 GTP shard 处理和 adapter-only 保存。

- 一个 CPU-only、metadata-driven 工具可使用 weighted 和 WSM policies 合并兼容的 torch_dist checkpoints，并支持 external common state、dry runs 和显式 state filtering。（[main #5114](https://github.com/NVIDIA/Megatron-LM/pull/5114)）
- MFSDP v2 在 fsdp_dtensor DCP format 中新增 optimizer checkpoint save/load，包括针对空 local shards 的 rank-consistent placeholders。（[main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215)）
- Bridge-compatible train_state sidecars 和 GPT-to-Hybrid conversion 改进了 model、optimizer 和 training state 的恢复与互操作性；trainable-parameter filtering 支持 adapter-only PEFT/LoRA checkpoints，可在不包含 frozen base weights 的情况下恢复 trainable parameters、optimizer state 和 iteration state。（[main #6807](https://github.com/NVIDIA/Megatron-LM/pull/6807)、[pull-request/4942 #7192](https://github.com/NVIDIA/Megatron-LM/pull/7192)、[main #7280](https://github.com/NVIDIA/Megatron-LM/pull/7280)）
- GTP checkpointing 现在处理 fused projection reconstruction、reshardable optimizer state、logical padding removal、optimizer identity 和 grouped gated projections。（[main #7161](https://github.com/NVIDIA/Megatron-LM/pull/7161)、[main #7162](https://github.com/NVIDIA/Megatron-LM/pull/7162)、[main #7168](https://github.com/NVIDIA/Megatron-LM/pull/7168)）

### THD、DSA 与稀疏上下文并行执行

Packed-THD 和 DSA 工作新增 balanced indexing、显式 planning、min-memory kernels、training integration 和 graph-safe sparse attention。

- DSA indexing 和 scoring 新增 balanced context-parallel routing、explicit THD plans、host-prebuilt layout tables、static-shape backward handling 和 stable metric reduction。（[dev #6058](https://github.com/NVIDIA/Megatron-LM/pull/6058)、[dev #6206](https://github.com/NVIDIA/Megatron-LM/pull/6206)、[pull-request/6206 #6910](https://github.com/NVIDIA/Megatron-LM/pull/6910)、[dev #6980](https://github.com/NVIDIA/Megatron-LM/pull/6980)）
- MTP 和 hybrid context-parallel paths 新增 absolute-offset sequence rolls、通过 GDN 进行的 contiguous-layout conversion，以及带 per-sequence zigzag padding 的 packed-THD batching。（[pull-request/6473 #6741](https://github.com/NVIDIA/Megatron-LM/pull/6741)、[main #7128](https://github.com/NVIDIA/Megatron-LM/pull/7128)、[main #7238](https://github.com/NVIDIA/Megatron-LM/pull/7238)）
- Simplified DSA over GQA 获得 min-memory Triton 和 autograd kernels、integrated sparse-attention layer、indexer training controls 以及 DSA-over-GQA inference。（[main #6869](https://github.com/NVIDIA/Megatron-LM/pull/6869)、[main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152)、[pull-request/7152 #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156)、[pull-request/7158 #7181](https://github.com/NVIDIA/Megatron-LM/pull/7181)、[main #7211](https://github.com/NVIDIA/Megatron-LM/pull/7211)）
- Fused CSA RoPE bounds 和 top-k selection 得到强化，以实现安全且可重复的 sparse-attention execution。（[main #7104](https://github.com/NVIDIA/Megatron-LM/pull/7104)、[dev #7169](https://github.com/NVIDIA/Megatron-LM/pull/7169)）

### MFSDP v2、MXFP8 与融合式分布式梯度

MFSDP v2 工作结合了 quantized weights、pipeline 与 1F1B scheduling、fused gradient paths 和 distributed communication overlap。

- MFSDP v2 prototype 在 hybrid MoE workload 上组合了 MXFP8 primary weights、virtual pipeline parallelism、combined 1F1B scheduling 和 distributed Muon。（[main #6197](https://github.com/NVIDIA/Megatron-LM/pull/6197)）
- MFSDP v2 新增带 persistent FP32 masters 以及 row-wise、column-wise payload buffers 的 MXFP8 parameter groups。（[main #6485](https://github.com/NVIDIA/Megatron-LM/pull/6485)）
- Fused weight-gradient accumulation 直接写入 MFSDP v2 reduce-scatter buffers；fine-grained 1F1B 则集成 parameter lifecycle hooks 和 no-sync gradient accumulation。（[main #7101](https://github.com/NVIDIA/Megatron-LM/pull/7101)、[main #7112](https://github.com/NVIDIA/Megatron-LM/pull/7112)）

### 动态上下文并行与显式 process groups

Parallel-state modernize 和 dynamic CP 为 model、schedule、MoE 与 hybrid consumers 提供 runtime topology selection。

- Core model 和 attention paths 越来越多地使用显式 ProcessGroupCollection instances，而不是 global parallel-state accessors。（[main #6293](https://github.com/NVIDIA/Megatron-LM/pull/6293)）
- Dynamic CP 新增 runtime group resolution、singleton CP1 handling、arbitrary CP sizes、exact validation 和 exception-safe Transformer Engine binding。（[main #7045](https://github.com/NVIDIA/Megatron-LM/pull/7045)、[dev #7097](https://github.com/NVIDIA/Megatron-LM/pull/7097)）
- Dynamic CP 与 training 和 evaluation schedules、packed-microbatch MoE losses，以及包括 Mamba、GDN、MLA 和 DSA 在内的 hybrid layers 集成。（[main #7046](https://github.com/NVIDIA/Megatron-LM/pull/7046)、[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)、[main #7048](https://github.com/NVIDIA/Megatron-LM/pull/7048)）

### 动态与混合训练的 CUDA Graph capture

CUDA Graph 工作扩展了 capture coverage，同时支持 dynamic packed inputs、hybrid execution、offload 和 pipeline schedules。

- Dynamic CP graph execution 在 graph banks 之间共享 slot 和 liveness arenas，减少重复存储，同时保留 per-size executables 和 process groups。（[dev #6479](https://github.com/NVIDIA/Megatron-LM/pull/6479)）
- Full-iteration 和 partial HybridStack capture 支持 grouped layers、paged MoE stashing、graphable Mamba 与 attention spans，以及 eager dynamic expert execution。（[main #6958](https://github.com/NVIDIA/Megatron-LM/pull/6958)、[main #6994](https://github.com/NVIDIA/Megatron-LM/pull/6994)）
- Capture-safe offload 和 dynamic packed inputs 将 local 与 external events 分离，并把变化的 THD 和 balanced-indexer metadata 暂存到 fixed-address replay buffers。（[dev #7020](https://github.com/NVIDIA/Megatron-LM/pull/7020)、[dev #7102](https://github.com/NVIDIA/Megatron-LM/pull/7102)）
- Balanced DSA graphs 扩展到 EP 1F1B overlap、pipeline 与 virtual-pipeline schedules，以及 dynamic packed microbatches。（[dev #7206](https://github.com/NVIDIA/Megatron-LM/pull/7206)）

### 解耦式与动态推理

推理工作改进了 prefill/decode disaggregation、MTP caching、prefix-score reuse、request lifecycle handling 和 generation compatibility。

- Prefill/decode disaggregation 通过 coordinator-managed handoff，使用 NCCL 或 NIXL 传输 live KV 和 SSM state。（[main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)）
- Inference correctness improvements 覆盖 NVLS row binding、resume rebinding、inherited KV blocks、deterministic greedy sampling，以及完整的 EOS 和 sampling-default handling。（[main #7061](https://github.com/NVIDIA/Megatron-LM/pull/7061)、[main #7191](https://github.com/NVIDIA/Megatron-LM/pull/7191)）
- MTP inference 新增 dynamic-context KV caching；prefix caching 则从 canonical KV blocks 存储并重建 prompt log probabilities。（[main #7033](https://github.com/NVIDIA/Megatron-LM/pull/7033)、[main #7063](https://github.com/NVIDIA/Megatron-LM/pull/7063)）
- Dynamic inference 强化 admission、pause/resume、recomputation、completion、reset、failure ownership、prompt-memory release 和 token-score handling；gathered MoE weights 会原地刷新，以支持 serving 和 resume。（[main #6931](https://github.com/NVIDIA/Megatron-LM/pull/6931)、[main #7256](https://github.com/NVIDIA/Megatron-LM/pull/7256)）

### Muon、GTP、GDN 与分布式训练可靠性

Optimizer、fused-kernel、通信和 runtime-safety 变更改进了分布式执行并减少故障模式。

- Muon 新增紧凑的 LayerWise layouts、FP8 gathering、per-head QKV orthogonalization、layer-sharded updates、generalized tensor-parallel integration，以及 multimodal Qwen3.5-VL support。（[main #5479](https://github.com/NVIDIA/Megatron-LM/pull/5479)、[main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326)、[dev #6608](https://github.com/NVIDIA/Megatron-LM/pull/6608)、[main #6683](https://github.com/NVIDIA/Megatron-LM/pull/6683)、[dev #6882](https://github.com/NVIDIA/Megatron-LM/pull/6882)、[dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085)）
- GatedDeltaNet 新增内部 CuTe backend，并以 FLA fallback；EP-overlap scheduling 支持带 RNG 和 MTP state snapshots 的 segmented recomputation。（[main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)、[dev #6511](https://github.com/NVIDIA/Megatron-LM/pull/6511)）
- Virtual-expert MoE routing 新增 replica exchange 和 gradient-reduction paths；MFSDP/FSDP runtime 变更改进了 NCCL pool ownership 和 model-parallel teardown。（[main #6892](https://github.com/NVIDIA/Megatron-LM/pull/6892)、[main #6923](https://github.com/NVIDIA/Megatron-LM/pull/6923)、[main #7029](https://github.com/NVIDIA/Megatron-LM/pull/7029)）
- Training diagnostics 和 optimizer control 通过减少 host synchronization、per-group optimizer clocks、custom quantization recipes、mixed-dtype gradient clipping 及 distributed edge-case handling 得到改进。（[main #7076](https://github.com/NVIDIA/Megatron-LM/pull/7076)、[pull-request/7156 #7158](https://github.com/NVIDIA/Megatron-LM/pull/7158)、[main #7176](https://github.com/NVIDIA/Megatron-LM/pull/7176)、[main #7177](https://github.com/NVIDIA/Megatron-LM/pull/7177)、[main #7279](https://github.com/NVIDIA/Megatron-LM/pull/7279)）

### NCCL resharding 与大规模传输安全

通信可靠性工作限制大型传输，以避免 refit 和 resharding 期间出现依赖环与死锁。

- NCCL resharding P2P submissions 通过 parameter batches 和针对 oversized transfer groups 的 deterministic task-id windows 进行限制。（[main #7189](https://github.com/NVIDIA/Megatron-LM/pull/7189)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
