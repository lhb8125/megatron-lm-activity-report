已交付工作推进了 DeepSeek-V4 与混合模型执行、MFSDP 与并行训练、MoE 与量化支持、推理服务、多模态 SFT 以及 checkpoint 可靠性。进行中的工作推进混合模型架构、稀疏注意力、分布式执行、checkpoint 可移植性、CUDA Graph 与 offload 路径、MoE 与 MTP 效率、量化、推理和确定性。

## 已交付成果

### DeepSeek-V4 稀疏注意力与 CSA

DeepSeek-V4 获得原生混合注意力构建、紧凑 DSA 索引、融合 CSA 执行、packed-THD 支持及确定性稀疏注意力行为。

- 新增紧凑 cuDNN DSA 索引、负载均衡的 context-parallel 索引，以及由 plan 驱动并复用布局元数据的 packed-THD 打分。（[dev #5992](https://github.com/NVIDIA/Megatron-LM/pull/5992)、[dev #6058](https://github.com/NVIDIA/Megatron-LM/pull/6058)、[dev #6206](https://github.com/NVIDIA/Megatron-LM/pull/6206)）
- 新增 DeepSeek-V4 HybridModel 构建与编排，支持 compressed、windowed、sink 和 D2 注意力模式，包括融合 SBHD CSA 执行，以及使用 Core 融合、THD 注意力投影、主梯度累积和重叠 collective 的 Agent Compose 路径。（[main #6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)、[main #6404](https://github.com/NVIDIA/Megatron-LM/pull/6404)、[main #6405](https://github.com/NVIDIA/Megatron-LM/pull/6405)、[dev #7127](https://github.com/NVIDIA/Megatron-LM/pull/7127)）
- 通过重新计算逆 RoPE，并融合 layout lowering、位置映射、indexer 准备、compressor 准备和 sparse-loss 处理，优化 CSA 反向传播与 packed-THD 训练。（[dev #7036](https://github.com/NVIDIA/Megatron-LM/pull/7036)、[dev #7064](https://github.com/NVIDIA/Megatron-LM/pull/7064)）
- 稳定融合 CSA Top-K 排序与 context-parallel padding 行为，确保 rollout 和 policy-loss 比较的确定性。（[dev #7169](https://github.com/NVIDIA/Megatron-LM/pull/7169)）

- 开放 MFSDP v2 生命周期控制，并在 virtual pipeline chunks 间集成共享 context，使外部 schedule 与 VPP 执行能够协调 unshard、reshard、prefetch、gradient 和 optimizer 处理。（[main #6484](https://github.com/NVIDIA/Megatron-LM/pull/6484)、[main #6486](https://github.com/NVIDIA/Megatron-LM/pull/6486)）
- 新增 mixed dense 与 expert 分片策略、hybrid FSDP bucket 构建、细粒度 1F1B 集成及正确的 microbatch 累积行为。（[main #6594](https://github.com/NVIDIA/Megatron-LM/pull/6594)、[main #6773](https://github.com/NVIDIA/Megatron-LM/pull/6773)、[main #7112](https://github.com/NVIDIA/Megatron-LM/pull/7112)、[main #7186](https://github.com/NVIDIA/Megatron-LM/pull/7186)）
- 将 MXFP8 参数存储与执行集成到 MFSDP v2，包括 quantized data 和 scale planes、redistribution、分布式 requantization 及经过验证的 compute recipes。（[main #7114](https://github.com/NVIDIA/Megatron-LM/pull/7114)、[main #7265](https://github.com/NVIDIA/Megatron-LM/pull/7265)、[main #7588](https://github.com/NVIDIA/Megatron-LM/pull/7588)）

### THD、context parallelism 与分布式 collective

Packed sequence 训练和运行时 context parallelism 获得动态 process-group 处理、更安全的 stream 排序及更低的 collective 开销。

- 新增可复用的 packed-THD context-parallel layouts，并通过延迟创建的 Transformer Engine streams 路由运行时 CP attention，同时使用正确的 fused RoPE group。（[main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821)、[main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912)）
- 将 resharding local-copy streams 按 caller stream 排序，并将 NCCL resharding 提交限制为确定性的 parameter batches 和 task windows。（[main #6823](https://github.com/NVIDIA/Megatron-LM/pull/6823)、[main #7189](https://github.com/NVIDIA/Megatron-LM/pull/7189)）
- 使 Muon QKV splitting 在 GTP 下与 layout 无关；在 GTP-by-TP 域上加入 layer-sharded Newton-Schulz 处理；并将重复的 MTP output-layer gradients 合并为每次迭代一次 GTP reduce-scatter。（[main #6683](https://github.com/NVIDIA/Megatron-LM/pull/6683)、[main #7117](https://github.com/NVIDIA/Megatron-LM/pull/7117)、[main #7573](https://github.com/NVIDIA/Megatron-LM/pull/7573)）

- Routed inference 新增 MXFP8 grouped-MoE backends，以及面向 dynamic scheduling 的 routing-output 异步 capture、transfer、compaction 和 replay。（[main #6933](https://github.com/NVIDIA/Megatron-LM/pull/6933)、[main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310)）

### MTP 共享、loss 处理与 packed 执行

优化重复 MTP 计算，并修正其 loss、masking、normalization 和 packed context-parallel 行为。

- Forward-sharing 和 checkpoint replay 在重复 MTP depths 间复用 DSA sparse indices 与 latent KV，包括受支持的 activation-recompute 组合。（[dev #6472](https://github.com/NVIDIA/Megatron-LM/pull/6472)、[dev #7107](https://github.com/NVIDIA/Megatron-LM/pull/7107)）
- MTP 新增 TP-aware total-variation objective、absolute-offset sequence rolls，以及针对 original 和 shifted targets 的 CP-wide loss normalization；masked loss callbacks 现按 CP-wide token count 归一化，并补偿 uneven masks 与 pipeline schedules 下的 DDP averaging。（[dev #6473](https://github.com/NVIDIA/Megatron-LM/pull/6473)、[pull-request/6473 #6741](https://github.com/NVIDIA/Megatron-LM/pull/6741)、[main #7498](https://github.com/NVIDIA/Megatron-LM/pull/7498)、[main #7513](https://github.com/NVIDIA/Megatron-LM/pull/7513)）
- Padding validity 现会贯穿 MTP depths 和 distributed layouts 传播，使 invalid positions 不参与 routing、rolls 和 auxiliary losses。（[main #7611](https://github.com/NVIDIA/Megatron-LM/pull/7611)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
