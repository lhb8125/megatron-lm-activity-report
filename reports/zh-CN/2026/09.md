# Megatron-LM 月度活动报告 — 2026年9月（截至2026-09-20）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/09.md)

> 统计周期：2026-09-01 至 2026-09-20（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作推进了 DeepSeek-V4 稀疏 attention、MFSDP 与 context parallelism、MoE 执行、推理服务、checkpoint 可靠性、量化执行和训练正确性。进行中的工作推进混合与多模态架构、动态 context parallelism、稀疏 attention、分布式分片、CUDA Graph 执行、推理，以及确定性和 checkpoint 可靠性。

- 过滤后的实质性 PR 活动：新开 433；合并 227；关闭未合并 135；截止时仍在进行 317。
- 不计入报告正文和统计：纯 UT 37，纯 CI 17，UT/CI-only 4，纯格式化 0。

## 已交付成果

### DeepSeek-V4 压缩稀疏 attention

实现原生混合 attention 构建，以及融合、打包和确定性的压缩稀疏 attention 执行。

- 新增原生 DeepSeek-V4 混合 attention 编排和 HybridModel 构建，包括分组投影、MTP identity 传播、indexer-loss 调度、层比例校验和 stack 规格。（[main #6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)、[main #6405](https://github.com/NVIDIA/Megatron-LM/pull/6405)）
- 新增带硬件感知选择和融合 indexer loss 的融合 SBHD 压缩稀疏 attention 后端，并融合 packed-THD 布局 lowering、indexer 与 compressor 准备、attention glue 和 sparse-loss 后处理。（[main #6404](https://github.com/NVIDIA/Megatron-LM/pull/6404)、[dev #7064](https://github.com/NVIDIA/Megatron-LM/pull/7064)）
- 使 CSA Top-K 选择在有梯度和无梯度 forward 中保持确定性，并在 sparse attention 前屏蔽填充 token。（[dev #7169](https://github.com/NVIDIA/Megatron-LM/pull/7169)）

### MFSDP 与 packed context parallelism

扩展 MFSDP 分片和细粒度调度，同时支持 packed context-parallel attention 与累积工作流。

- 支持对 expert 和 non-expert 参数采用不同的 ZeRO 分片策略、混合 inner 与 outer data parallelism，以及经过修正 gradient scaling 的显式 bucket 布局。（[main #6594](https://github.com/NVIDIA/Megatron-LM/pull/6594)、[main #6773](https://github.com/NVIDIA/Megatron-LM/pull/6773)）
- 集成 MFSDP v2 生命周期 hooks 和 no-sync gradient accumulation，并通过组合式 1F1B 调度实现 expert-parallel overlap，同时跨 microbatch 保留 accumulated gradients。（[main #7112](https://github.com/NVIDIA/Megatron-LM/pull/7112)、[main #7186](https://github.com/NVIDIA/Megatron-LM/pull/7186)）
- 新增运行时 context-parallel attention 支持，使用延迟创建的 Transformer Engine streams 和 packed-THD batch layout views 处理独立分片的序列；同时传递多模态 metadata，分片和聚合 vision tokens，保留 padding 与 loss weighting，并协调 dataloader checkpoint state。（[main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821)、[main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912)、[main #7315](https://github.com/NVIDIA/Megatron-LM/pull/7315)）

### MoE megakernel、routing 与 hybrid blocks

新增替代性的 MoE 执行和 routing 机制，包括 megakernel 集成、全局均衡、expert-bias 正确性和 ShortcutMoE blocks。

- 引入可插拔的 Mixture-of-Kittens MoE megakernel 边界，覆盖 routing、expert computation、combination、MXFP8 views 和 gradient accumulation，同时保留 MCore 参数及 checkpoint ownership。（[dev #6572](https://github.com/NVIDIA/Megatron-LM/pull/6572)）
- 新增 Kimi K3 global-batch quantile balancing，在 gradient-accumulation microbatch 间持久化 expert histograms，并为 routing-bias 更新保留精确的 int64 expert counts。（[dev #6637](https://github.com/NVIDIA/Megatron-LM/pull/6637)、[main #6638](https://github.com/NVIDIA/Megatron-LM/pull/6638)、[main #7081](https://github.com/NVIDIA/Megatron-LM/pull/7081)、[main #7394](https://github.com/NVIDIA/Megatron-LM/pull/7394)）
- 新增 ShortcutMoE hybrid blocks，支持 shortcut normalization 和 interleaved attention-over-A2A execution，并覆盖 offload、recompute 和 hybrid model paths。（[main #6959](https://github.com/NVIDIA/Megatron-LM/pull/6959)）

### Inference coordinator、prefix caching 与 MTP serving

改进动态 inference request 处理，并在各 serving 路径扩展 prefix-cache 与 MTP attention-cache 支持。

- 修改 inference coordinator 消息传递，将 metadata 与 body frames 分离；将 prompt hashing 移至 clients；按 weights 对 prefix hashes 进行版本化，并新增基于 TTL 的 eviction。（[main #6497](https://github.com/NVIDIA/Megatron-LM/pull/6497)）
- 在 dynamic inference、prefix caching、disaggregation 和 CUDA-graph request paths 中新增 MTP attention KV-cache 支持。（[main #7033](https://github.com/NVIDIA/Megatron-LM/pull/7033)）
- 强化 dynamic inference 的 admission、checkpointing、pause/resume、recomputation、completion 和 result construction，同时保留 request identity 与 prompt-memory ownership。（[main #7256](https://github.com/NVIDIA/Megatron-LM/pull/7256)）

### Checkpointing、refit 与 distributed state correctness

改进量化 checkpoint 的可复现性、distributed RNG 与 dataloader state、GTP rematerialization 以及大规模 resharding 传输。

- 在 checkpoint loading 期间从 FP32 optimizer masters 重新推导 quantized parameters，并在 distributed RNG-state shard addresses 中加入 data/context-parallel rank 信息。（[main #6666](https://github.com/NVIDIA/Megatron-LM/pull/6666)、[main #6858](https://github.com/NVIDIA/Megatron-LM/pull/6858)）
- 修正 GTP-rematerialization sizing、process-group propagation、inference shard declarations，以及 checkpointing 和 RL refit 流程中的 tied-embedding compatibility。（[main #6940](https://github.com/NVIDIA/Megatron-LM/pull/6940)）
- 将 NCCL refit peer-to-peer groups 与 parameter batches 和 task-ID windows 绑定，避免大模型 resharding 中产生过大的 split kernel plans。（[main #7189](https://github.com/NVIDIA/Megatron-LM/pull/7189)）
- 将 dataloader checkpoint indexing 改为使用跨越 GTP 的 data-parallel rank，并为 rank-independent loaders 提供 opt-in shared state file。（[main #7413](https://github.com/NVIDIA/Megatron-LM/pull/7413)）

### NVFP4、MXFP8 与 Megatron-Lite 执行

扩展 DeepSeek、selective module storage、batch-invariant MoE paths 和 DSv4 Lite stack 中的量化训练与推理执行。

- 为 overlap 和 MTP paths 新增 DeepSeek-V3 NVFP4 支持、selective module precision configuration、delayed MLA down-projection gradients，以及 fused-MLA checkpoint-name compatibility。（[main #6841](https://github.com/NVIDIA/Megatron-LM/pull/6841)）
- 新增按 module 选择 BF16 或 MXFP8 inference storage，并在 Torch、vLLM-selected、FlashInfer 和 Transformer Engine grouped-tensor paths 中实现 batch-invariant MXFP8 execution。（[main #7300](https://github.com/NVIDIA/Megatron-LM/pull/7300)、[main #7302](https://github.com/NVIDIA/Megatron-LM/pull/7302)）
- 推动 DSv4 Lite path 使用 Core attention、MoE、activation、rotary 和 gradient-accumulation fusions，同时移除冗余 layout 与 optimizer 工作。（[dev #7127](https://github.com/NVIDIA/Megatron-LM/pull/7127)）

### CUDA Graph、optimizer 与 deterministic training correctness

强化 graph-captured training、optimizer layout handling、cross-parallel gradient scaling 和 determinism validation。

- 使 Hybrid mHC activation-offload event ownership、backward completion、rotary capture 和 delayed expert offload 与 Transformer Engine CUDA Graphs 对齐。（[dev #7014](https://github.com/NVIDIA/Megatron-LM/pull/7014)）
- 通过防止不受支持的 first-microbatch signaling 覆盖 repeated layers 中的 contributions，修正 repeated MTP gradient accumulation。（[main #6965](https://github.com/NVIDIA/Megatron-LM/pull/6965)）
- 使 Muon fused-QKV splitting 依赖 GTP all-gather 后 globally gathered shape，并在 EGTP 与 GTP degrees 不同时修正 expert gradient prescaling。（[main #7117](https://github.com/NVIDIA/Megatron-LM/pull/7117)、[main #7165](https://github.com/NVIDIA/Megatron-LM/pull/7165)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
