# Megatron-LM 月度活动报告 — 2026年8月（最终版，截至2026-08-31）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/08.md)

> 统计周期：2026-08-01 至 2026-08-31（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作推进了 MFSDP 与并行训练、CUDA Graph 执行、混合架构、注意力 kernel、推理服务、RL 持久性和模型重拟合。持续中的工作推进分布式训练、模型架构、MoE 与推理执行、checkpoint、optimizer 策略及运行时可靠性。

- 过滤后的实质性 PR 活动：新开 667；合并 334；关闭未合并 208；截止时仍在进行 349。
- 不计入报告正文和统计：纯 UT 42，纯 CI 44，UT/CI-only 0，纯格式化 0。

## 已交付成果

### MFSDP 分片、梯度与 optimizer 内存

MFSDP 扩展了分片和 optimizer 能力，并增强了梯度、绑定参数、通信 buffer 及权重同步的正确性。

- MFSDP v2 现在能够正确扩展 expert 梯度，处理重计算阶段，保留绑定参数别名，在 reduce-scatter stream 上分配持久梯度，在 optimizer step 后刷新 BF16 计算权重，并验证 fused MLA/MTP checkpoint 命名以支持 unfused-to-fused 及 fused 往返加载。（[#5956](https://github.com/NVIDIA/Megatron-LM/pull/5956)、[#6153](https://github.com/NVIDIA/Megatron-LM/pull/6153)、[#6164](https://github.com/NVIDIA/Megatron-LM/pull/6164)、[#6187](https://github.com/NVIDIA/Megatron-LM/pull/6187)、[#6271](https://github.com/NVIDIA/Megatron-LM/pull/6271)、[#6336](https://github.com/NVIDIA/Megatron-LM/pull/6336)）
- FSDP 通信支持可配置的持久 buffer；optimizer state 和选定的 master-weight 更新可在由 pinned CPU storage 支持的有界 GPU 内存中运行。（[#6244](https://github.com/NVIDIA/Megatron-LM/pull/6244)、[#6316](https://github.com/NVIDIA/Megatron-LM/pull/6316)）

### CUDA Graph 重计算与重叠

CUDA Graph 路径获得了更安全的重计算、capture 作用域通信、fused mHC 执行以及混合训练正确性保护。

- 选择性 mHC 重计算现在可在 CUDA Graphs 下配合 EP all-to-all overlap 工作；Transformer Engine paged-stash capture 管理 capture 顺序、辅助 stream、运行时恢复和容量检查。（[#5841](https://github.com/NVIDIA/Megatron-LM/pull/5841)、[#6022](https://github.com/NVIDIA/Megatron-LM/pull/6022)、[#6870](https://github.com/NVIDIA/Megatron-LM/pull/6870)）
- GTP backward reduce-scatter、EP A2A 重计算及仅 checkpoint 参数发现现在能够保留 capture 作用域的所有权、activation 生命周期和所需的 autograd edge。（[#6060](https://github.com/NVIDIA/Megatron-LM/pull/6060)、[#6311](https://github.com/NVIDIA/Megatron-LM/pull/6311)、[#6373](https://github.com/NVIDIA/Megatron-LM/pull/6373)、[#6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)）
- 混合模型可以使用 fused mHC 执行，并获得针对重计算状态、路由 metadata、layer-norm checkpoint 及 CUDA-Graph batch 隔离的修复。（[#6401](https://github.com/NVIDIA/Megatron-LM/pull/6401)、[#6704](https://github.com/NVIDIA/Megatron-LM/pull/6704)）
- GTP 重计算使用独立的 gather-buffer 选择，避免异步 prefetch 覆盖重计算 forward 仍需使用的权重。（[#6407](https://github.com/NVIDIA/Megatron-LM/pull/6407)）

### GDP 与混合模型架构

新增及扩展的混合模型路径支持 GDP、Ling-V3 Tiny、分块 context parallelism 和优化的混合布局。

- Gated Delta Product 成为一等 trainable 和 inferable 的混合组件，支持 TP/CP、packed sequences、dynamic inference、checkpoint resharding 及 optimizer 集成。（[#6074](https://github.com/NVIDIA/Megatron-LM/pull/6074)）
- GDP 增加 activation recompute 与 offload 控制、CuTeDSL kernel 路径，以及适用于 training、prefill 和 decode 的 channel-last causal-convolution 处理。（[#6553](https://github.com/NVIDIA/Megatron-LM/pull/6553)）
- 新增对 Ling-V3 Tiny KDA–MLA hybrid sparse-MoE 架构的训练支持，包括 gated MLA、MTP、QK clipping 和模型特定的 layer 分配。（[#6556](https://github.com/NVIDIA/Megatron-LM/pull/6556)）
- GDP 通过分布式 recurrent-state prefix 与 suffix 组合支持 chunkwise context parallelism；混合模型则可保持 GDN layer 连续，仅在常规 attention 周围转换布局。（[#6387](https://github.com/NVIDIA/Megatron-LM/pull/6387)、[#6815](https://github.com/NVIDIA/Megatron-LM/pull/6815)）

### 动态推理、KV-cache 交接与多模态服务

推理服务通过弹性 prefix caching、分离式 state transfer、多模态 dynamic batching 和 video 支持得到扩展。

- Prefix-cache accounting 现在对 resumed request 一致地处理 free 和 evictable block；当缓存 block 可被驱逐时，暂停的 request 可以恢复。（[#5995](https://github.com/NVIDIA/Megatron-LM/pull/5995)）
- Prefill-to-decode handoff 通过 NIXL 或 NCCL 传输 KV cache；hybrid handoff 还会通过 resharding 和 partial prefix reuse 传输 SSM convolution 及 recurrent state。（[#6222](https://github.com/NVIDIA/Megatron-LM/pull/6222)、[#6584](https://github.com/NVIDIA/Megatron-LM/pull/6584)）
- Dynamic batching 现在支持 image-aware VLM request 和 video prompt，包括 preprocessing、placeholder expansion、vision execution、multimodal caching 以及 HTTP/API 集成。（[#6260](https://github.com/NVIDIA/Megatron-LM/pull/6260)、[#6809](https://github.com/NVIDIA/Megatron-LM/pull/6809)）
- Batch-invariant Nemotron inference 会移除 decode attention 和 SSM execution 周围仅针对 token 的 padding，并在之后恢复，从而避免对齐的 CUDA-Graph batch 将 padding 误识别为 request。（[#6893](https://github.com/NVIDIA/Megatron-LM/pull/6893)）

### GTP、Muon 与分布式 optimizer 并行

Generalized tensor parallelism 增强了梯度通信、就绪管理、内存及 Muon 执行支持。

- GTP 支持重复的 MTP-weight 通信，并通过独立的 all-gather 和面向 successor 的 reduce-scatter 完成来保留 shared-weight gradient。（[#6242](https://github.com/NVIDIA/Megatron-LM/pull/6242)）
- DP-balanced rerouting 现在在 CP lane 内使用按 field padding 的 all-gather；GTP-sharded Muon 按 Newton–Schulz 计算成本平衡 shard，并支持 blockwise、duplicated 和 distributed orthogonalization。（[#6378](https://github.com/NVIDIA/Megatron-LM/pull/6378)、[#6379](https://github.com/NVIDIA/Megatron-LM/pull/6379)、[#6380](https://github.com/NVIDIA/Megatron-LM/pull/6380)）
- DDP 在 GTP prefetch 前发布 parameter readiness；GTP 则新增可选的 symmetric-memory registration，以及用于 dense 和 expert reduce-scatter 的 pooled weight-gradient buffer。（[#6388](https://github.com/NVIDIA/Megatron-LM/pull/6388)、[#6535](https://github.com/NVIDIA/Megatron-LM/pull/6535)）

### MLA、DSA 与 Compressed Sparse Attention

Attention 实现获得了 fused positional processing、更高精度的 DSA projection、reference SBHD CSA 路径以及修正后的 fused loss normalization。

- TileLang DSA 支持独立量化和 BF16/FP32 projection-output 控制；MLA 与 DSA RoPE packing 使用 fused Triton forward 和 backward 路径。（[#6279](https://github.com/NVIDIA/Megatron-LM/pull/6279)、[#6343](https://github.com/NVIDIA/Megatron-LM/pull/6343)、[#6842](https://github.com/NVIDIA/Megatron-LM/pull/6842)、[#6846](https://github.com/NVIDIA/Megatron-LM/pull/6846)）
- CSA teacher 和 fused indexer-loss normalization 现在在 SBHD、THD、packed、sparse 及 dense 路径中纳入 compressed-key、sliding-window 和 sink term。（[#6349](https://github.com/NVIDIA/Megatron-LM/pull/6349)）
- 面向正确性的 native SBHD Compressed Sparse Attention 实现现在覆盖 compression、sparse 与 dense attention、sliding window、sink 以及 teacher LSE。（[#6400](https://github.com/NVIDIA/Megatron-LM/pull/6400)）

### 持久化 RL rollout 存储

RL rollout 处理获得了跨进程中断的持久化与恢复能力。

- 已完成的 rollout group 会存储在带 checksum 的 write-through rollout bank 中，并支持 restore、compaction、resume integration 及按 environment 平衡。（[#6352](https://github.com/NVIDIA/Megatron-LM/pull/6352)）

### Batch-invariant MoE 执行

Batch-invariant MoE 训练和推理获得了可选 collective backend、gated-MoE 执行及对齐的 token-bucketing 行为。

- Batch-invariant MoE 支持 fused-vLLM、native Transformer Engine 以及 FlashInfer routed block-scale MXFP8 gated-MoE backend，并提供对齐的 CUDA-Graph token bucket、确定性 reduction 行为，以及带 full-capacity fallback 的有界 decode-only graph prefix。（[#6521](https://github.com/NVIDIA/Megatron-LM/pull/6521)、[#6864](https://github.com/NVIDIA/Megatron-LM/pull/6864)）
- 可选的 ordered 和 multimem reduction backend 在支持的 collective 路径中提供对齐的 token bucketing、GEMM 选择和 exact-sum accumulation。（[#6806](https://github.com/NVIDIA/Megatron-LM/pull/6806)）

### NCCL ReFIT 与可变 MXFP8 权重

Refit 工作流获得了 NCCL many-to-many transfer、有界内存 MXFP8 更新及 communicator 初始化修复。

- NCCL many-to-many ReFIT 支持 topology caching、layout-agreement fingerprint、padding 处理及 benchmark 集成，以支持跨 parallel layout 的 transfer。（[#6712](https://github.com/NVIDIA/Megatron-LM/pull/6712)）
- MXFP8 inference weight 可通过 logical tensor metadata 和刷新后的 derived cache 原地更新；大型 refit 使用 parameter-aligned bounded batch，在运行之间释放 staging 和 dequantization buffer。（[#6826](https://github.com/NVIDIA/Megatron-LM/pull/6826)、[#6878](https://github.com/NVIDIA/Megatron-LM/pull/6878)）
- NCCLCopyService 现在会在检查 queued work 前主动连接 communicator，使 idle rank 参与 resharding 初始化，并避免仅部分 rank 存在 copy operation 时发生 hang。（[#6955](https://github.com/NVIDIA/Megatron-LM/pull/6955)）

## 进行中的方向

### MFSDP/FSDP 调度与分片

MFSDP 和 FSDP 获得了更细粒度的生命周期控制、通信重叠、checkpoint 支持及更稳健的分片行为。

- Combined 1F1B 和 expert-parallel schedule 协调 MFSDP state transition、prefetch、delayed reduction 及 custom lifecycle hook。（[#6174](https://github.com/NVIDIA/Megatron-LM/pull/6174)、[#6197](https://github.com/NVIDIA/Megatron-LM/pull/6197)、[#6665](https://github.com/NVIDIA/Megatron-LM/pull/6665)、[#6692](https://github.com/NVIDIA/Megatron-LM/pull/6692)、[#6694](https://github.com/NVIDIA/Megatron-LM/pull/6694)）
- MFSDP v2 增加 optimizer Distributed Checkpoint 支持、grouped-MoE storage remapping、hybrid sharding，以及对外部 EP-sharded expert weight 的支持。（[#6215](https://github.com/NVIDIA/Megatron-LM/pull/6215)、[#6228](https://github.com/NVIDIA/Megatron-LM/pull/6228)、[#6773](https://github.com/NVIDIA/Megatron-LM/pull/6773)、[#6785](https://github.com/NVIDIA/Megatron-LM/pull/6785)）
- 确定性的 user-buffer registration 和按 wrapper 管理的 NCCL pool ownership 可防止 rank-dependent layout、resource aliasing 及 registration failure。（[#6317](https://github.com/NVIDIA/Megatron-LM/pull/6317)、[#6923](https://github.com/NVIDIA/Megatron-LM/pull/6923)）

### Checkpoint 与分布式状态可靠性

Checkpoint conversion、restoration、validation、RNG addressing 及异步 worker 处理获得可靠性改进。

- CPU-only model conversion 和 checkpointing、quantized-parameter restoration 以及 optimizer-state slicing 提升了 device 与 precision transition 之间的兼容性。（[#6270](https://github.com/NVIDIA/Megatron-LM/pull/6270)、[#6342](https://github.com/NVIDIA/Megatron-LM/pull/6342)、[#6666](https://github.com/NVIDIA/Megatron-LM/pull/6666)）
- Uneven-DTensor preflight validation、data-parallel-aware RNG shard addressing 及 model-owned process-group 使用提升了 distributed checkpoint 一致性。（[#6573](https://github.com/NVIDIA/Megatron-LM/pull/6573)、[#6858](https://github.com/NVIDIA/Megatron-LM/pull/6858)、[#6940](https://github.com/NVIDIA/Megatron-LM/pull/6940)）
- 异步 checkpoint worker failure 现在会传播带 rank 标记的 error、清除 failed state，并允许替换 worker。（[#6971](https://github.com/NVIDIA/Megatron-LM/pull/6971)）

### MoE 路由、expert 执行与推理 kernel

MoE 工作扩展了 routing policy 和 backend 覆盖范围，同时改进 decode execution 及 expert-state 处理。

- Dynamic MoE decode path 增加 optimized routing、GEMM、token-count、combine、attention、normalization 和 diagnostic kernel，并加入 expert-parallel graph 初始化保护。（[#6064](https://github.com/NVIDIA/Megatron-LM/pull/6064)、[#6412](https://github.com/NVIDIA/Megatron-LM/pull/6412)）
- MoE stack 增加可插拔 MOK backend、dense top-k routing-map compatibility、batch-invariant combine behavior 及 global-batch quantile balancing。（[#6572](https://github.com/NVIDIA/Megatron-LM/pull/6572)、[#6614](https://github.com/NVIDIA/Megatron-LM/pull/6614)、[#6615](https://github.com/NVIDIA/Megatron-LM/pull/6615)、[#6634](https://github.com/NVIDIA/Megatron-LM/pull/6634)、[#6637](https://github.com/NVIDIA/Megatron-LM/pull/6637)、[#6638](https://github.com/NVIDIA/Megatron-LM/pull/6638)）
- Expert duplication 和 Transformer Engine MXFP8 grouped-GEMM inference 扩展了 replica-aware placement、checkpoint handling 及 device-resident routing。（[#6892](https://github.com/NVIDIA/Megatron-LM/pull/6892)、[#6933](https://github.com/NVIDIA/Megatron-LM/pull/6933)）
- Fused expert storage 被组织为相邻 view，使 colocated generation 能够从更新后的 weight 重建 zero-copy serving view。（[#6963](https://github.com/NVIDIA/Megatron-LM/pull/6963)）

### Context parallelism、THD、DSA 与 MTP

Packed-sequence execution 获得了更广泛的 context-parallel layout、MTP 对齐、sparse-attention 支持和 state-passing 路径。

- THD sequence-level MoE loss 和 context-parallel batch partitioning 现在根据 logical packed-sequence boundary 推导 ownership 和 shard。（[#6115](https://github.com/NVIDIA/Megatron-LM/pull/6115)、[#6912](https://github.com/NVIDIA/Megatron-LM/pull/6912)）
- Context-parallel layout 变为显式的 per-batch 和 per-layer contract；runtime attention group 及 latent MLA context parallelism 支持不同 layout 和 backend。（[#6233](https://github.com/NVIDIA/Megatron-LM/pull/6233)、[#6821](https://github.com/NVIDIA/Megatron-LM/pull/6821)、[#6829](https://github.com/NVIDIA/Megatron-LM/pull/6829)）
- MTP 为 packed context-parallel input 增加 layout-aware absolute sequence alignment；Mamba2 则增加带 halo 和 boundary-state exchange 的 sequence-sharded state passing。（[#6426](https://github.com/NVIDIA/Megatron-LM/pull/6426)、[#6741](https://github.com/NVIDIA/Megatron-LM/pull/6741)、[#6808](https://github.com/NVIDIA/Megatron-LM/pull/6808)）
- 基于 GQA 的 DSA 及其 sparse backward path 通过 static safe tile 和 zeroed gradient 处理 minimum-memory execution 与 empty query row。（[#6869](https://github.com/NVIDIA/Megatron-LM/pull/6869)、[#6910](https://github.com/NVIDIA/Megatron-LM/pull/6910)、[#6939](https://github.com/NVIDIA/Megatron-LM/pull/6939)）

### DeepSeek、Qwen 与新模型架构

模型开发增加了异构 decoder 结构、hybrid attention、宽 residual stream 及低精度训练路径。

- Qwen3.5-VL 迁移至 HybridModel，包含 GatedDeltaNet、attention、dense 和 MoE layer；generalized tensor parallelism 覆盖 training、checkpoint、inference 和 MIMO path；Megatron Lite experimental stack 增加 QAT format、router replay、dynamic context-parallel runtime support、streaming checkpoint conversion 及 model integration。（[#6315](https://github.com/NVIDIA/Megatron-LM/pull/6315)、[#6397](https://github.com/NVIDIA/Megatron-LM/pull/6397)、[#6608](https://github.com/NVIDIA/Megatron-LM/pull/6608)）
- DeepSeek-V4 获得 hybrid-layer construction、SBHD attention orchestration、fused CSA、hash routing、TP/CP attention path 及 learned indexer 支持。（[#6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)、[#6403](https://github.com/NVIDIA/Megatron-LM/pull/6403)、[#6404](https://github.com/NVIDIA/Megatron-LM/pull/6404)、[#6405](https://github.com/NVIDIA/Megatron-LM/pull/6405)、[#6887](https://github.com/NVIDIA/Megatron-LM/pull/6887)）
- Streamwise wide-residual 支持增加多种宽度的 residual stream、selective replay、ordinary-width MTP/MIMO boundary 及 shortcut-MoE integration。（[#6716](https://github.com/NVIDIA/Megatron-LM/pull/6716)、[#6805](https://github.com/NVIDIA/Megatron-LM/pull/6805)、[#6855](https://github.com/NVIDIA/Megatron-LM/pull/6855)、[#6959](https://github.com/NVIDIA/Megatron-LM/pull/6959)）
- Attention Residual aggregation、DeepSeek-V3 NVFP4 training 及 SiTU-GLU Transformer Engine dispatch 扩展了可配置的 model 和 precision behavior；TE microbatch-state handling 则在 checkpoint resume 后为复用 layer 保持正确的 accumulation behavior。（[#6673](https://github.com/NVIDIA/Megatron-LM/pull/6673)、[#6674](https://github.com/NVIDIA/Megatron-LM/pull/6674)、[#6840](https://github.com/NVIDIA/Megatron-LM/pull/6840)、[#6841](https://github.com/NVIDIA/Megatron-LM/pull/6841)、[#6965](https://github.com/NVIDIA/Megatron-LM/pull/6965)）

### Muon 与 optimizer 内存策略

Muon 获得了新的分片和正交化模式，同时 optimizer-state offloading 降低了 GPU 驻留。

- Per-head Muon orthogonalization 和 Hyperball constraint 支持 QKV、MLA、GQA、gated、expert 及 rematerialized layout。（[#6326](https://github.com/NVIDIA/Megatron-LM/pull/6326)、[#6422](https://github.com/NVIDIA/Megatron-LM/pull/6422)）
- Layer-sharded 和 hybrid Muon strategy 在 tensor、expert 和 layer-sharding domain 间分配 matrix update，并分别支持 dense 与 expert policy。（[#6683](https://github.com/NVIDIA/Megatron-LM/pull/6683)、[#6761](https://github.com/NVIDIA/Megatron-LM/pull/6761)）
- Chunked CPU offloading 将 Adam moment 和 master weight 存储在 GPU memory 之外，同时避免 checkpoint save 时进行完整 state rematerialization。（[#6544](https://github.com/NVIDIA/Megatron-LM/pull/6544)）

### 推理服务、rollout 持久性与解码

推理和 RL 路径改进了 disaggregation、request lifecycle handling、selected-logprob computation、speculative replay 及 durable rollout recovery。

- Disaggregated prefill/decode handoff 通过 coordinator 管理的 lifecycle operation，在独立并行化的 shard 间传输 KV 和 recurrent SSM state。（[#6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)）
- Inference lifecycle 修复涵盖 prefix-cache reconstruction、异步 request-state correctness、client-disconnect cancellation 及 incomplete rollout group 的 durable replay。（[#6768](https://github.com/NVIDIA/Megatron-LM/pull/6768)、[#6852](https://github.com/NVIDIA/Megatron-LM/pull/6852)、[#6853](https://github.com/NVIDIA/Megatron-LM/pull/6853)、[#6916](https://github.com/NVIDIA/Megatron-LM/pull/6916)）
- RL inference 增加 local-vocabulary selected-token logprob computation；Mamba speculative decoding 则可通过 checkpointed circular buffer replay state。（[#6617](https://github.com/NVIDIA/Megatron-LM/pull/6617)、[#6706](https://github.com/NVIDIA/Megatron-LM/pull/6706)）

### 确定性运行时、CUDA Graphs 与可扩展性

运行时基础设施改进了确定性执行、显式 process-group ownership、GTP graph 支持、metrics 及 kernel backend 选择。

- 确定性的 Triton tuning 和显式 process-group propagation 扩展至核心 model path；process-group lifecycle management 会清理已创建的 communicator；AsyncZMQ collective startup 会在初始 broadcast 前等待 subscriber ready。（[#6076](https://github.com/NVIDIA/Megatron-LM/pull/6076)、[#6293](https://github.com/NVIDIA/Megatron-LM/pull/6293)、[#6303](https://github.com/NVIDIA/Megatron-LM/pull/6303)、[#6715](https://github.com/NVIDIA/Megatron-LM/pull/6715)、[#6902](https://github.com/NVIDIA/Megatron-LM/pull/6902)）
- 集中式 kernel backend registry 和 construction-time selection 使 optional implementation 及不兼容 configuration 更加明确；可配置 tensor metrics 提供带 timing 的 scheduled forward、parameter 和 gradient observation，并支持 TensorBoard、W&B 或 stdout logging。（[#6650](https://github.com/NVIDIA/Megatron-LM/pull/6650)、[#6690](https://github.com/NVIDIA/Megatron-LM/pull/6690)）
- GTP 增加 persistent CUDA-graph buffer、symmetric-memory 支持，以及统一的 sharding、communication、optimizer 和 checkpoint integration。（[#6713](https://github.com/NVIDIA/Megatron-LM/pull/6713)、[#6867](https://github.com/NVIDIA/Megatron-LM/pull/6867)、[#6882](https://github.com/NVIDIA/Megatron-LM/pull/6882)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
