# Megatron-LM 月度活动报告 — 2026年8月（截至2026-08-23）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/08.md)

> 统计周期：2026-08-01 至 2026-08-23（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作扩展了 MFSDP 和通用张量并行，引入 GDP/GDN 与解耦推理能力，并增强了重计算、上下文并行、可观测性和运行时可靠性。进行中的工作持续推进稀疏与混合模型、分布式训练、多模态与序列打包执行、推理性能、检查点及优化器效率。

- 过滤后的实质性 PR 活动：新开 490；合并 260；关闭未合并 152；截止时仍在进行 266。
- 不计入报告正文和统计：纯 UT 35，纯 CI 36，UT/CI-only 0，纯格式化 0。

## 已交付成果

### MFSDP 分片、优化器与检查点

MFSDP 扩展了分片与优化器支持，并改进了梯度、重计算、权重绑定、卸载和检查点恢复的正确性。

- MFSDP v2 新增专用 FullyShardedOptimizer 及适配器，支持选择 no-shard、ZeRO-1 和 ZeRO-2 布局，并为混合精度优化器提供精度感知的优化器状态与梯度处理。（[#5865](https://github.com/NVIDIA/Megatron-LM/pull/5865)、[#6137](https://github.com/NVIDIA/Megatron-LM/pull/6137)、[#6506](https://github.com/NVIDIA/Megatron-LM/pull/6506)）
- 专家并行 MFSDP v2 现可在专家数据并行网格上对专家参数分片并应用专家梯度除数；HFSDP 则延迟 DP 外层梯度归约，并处理优化器权重刷新及已归约梯度缓冲区重置。（[#5956](https://github.com/NVIDIA/Megatron-LM/pull/5956)、[#5972](https://github.com/NVIDIA/Megatron-LM/pull/5972)、[#6450](https://github.com/NVIDIA/Megatron-LM/pull/6450)）
- MFSDP 执行阶段在激活重计算期间保持参数物化，别名感知注册可保留绑定参数的身份，且 reduce-scatter 流分配可在异步归约期间保护持久化 main_grad 缓冲区。（[#6153](https://github.com/NVIDIA/Megatron-LM/pull/6153)、[#6164](https://github.com/NVIDIA/Megatron-LM/pull/6164)、[#6187](https://github.com/NVIDIA/Megatron-LM/pull/6187)）
- 完全可重分片的 torch_dist 优化器加载现会考虑已移除的桶间填充；DCP 辅助函数可往返处理非均匀 MFSDP v2 DTensor 模型与优化器分片，并重新同步计算权重。（[#5077](https://github.com/NVIDIA/Megatron-LM/pull/5077)、[#6024](https://github.com/NVIDIA/Megatron-LM/pull/6024)）

### LayerWise Muon 与优化器内存调度

优化器工作降低了更新阶段的内存需求，并改进了分片训练的梯度调度与 Muon 放置。

- Distributed Adam 和紧凑型 LayerWise Muon 通过固定页 CPU 规范存储，支持分块卸载优化器状态和主权重。（[#6244](https://github.com/NVIDIA/Megatron-LM/pull/6244)）
- MFSDP v1 ZeRO-1 和 ZeRO-2 新增默认 FSDP 单元分配及计划式梯度 reduce-scatter，并修正了 ZeRO-1 融合权重梯度累加。（[#6357](https://github.com/NVIDIA/Megatron-LM/pull/6357)）
- LayerWise Muon 现可在优化器分片间均衡完整矩阵 Newton–Schulz 计算，并为 GTP 分片参数支持分块、复制和分布式正交化模式。（[#6379](https://github.com/NVIDIA/Megatron-LM/pull/6379)、[#6380](https://github.com/NVIDIA/Megatron-LM/pull/6380)）

### GTP 通信与 CUDA Graph 重叠

通用张量并行增强了通信重叠、缓冲区所有权、重计算、MTP 集成、评估和检查点行为的安全性。

- GTP 通信所有权与缓冲区生命周期修复使本地 CUDA Graph 能与 reduce-scatter 完成阶段重叠，并跨图边界保留传入 all-gather 预取依赖。（[#6060](https://github.com/NVIDIA/Megatron-LM/pull/6060)、[#6696](https://github.com/NVIDIA/Megatron-LM/pull/6696)）
- 独立及双缓冲 gather ticket 可防止相邻或重计算权重覆盖正在使用的缓冲区；DDP 就绪回调会在 GTP 预取消费前发布已更新的参数桶。（[#6207](https://github.com/NVIDIA/Megatron-LM/pull/6207)、[#6388](https://github.com/NVIDIA/Megatron-LM/pull/6388)、[#6407](https://github.com/NVIDIA/Megatron-LM/pull/6407)）
- CUDA Graph 捕获现可处理仅在 CheckpointWithoutOutput 重计算期间使用的参数，并记录 GTP all-gather 访问，确保 DDP 参数在重放前发布。（[#6373](https://github.com/NVIDIA/Megatron-LM/pull/6373)、[#6525](https://github.com/NVIDIA/Megatron-LM/pull/6525)）
- MTP 推理现会在 NVLS all-gather 前执行屏障并切取有效的序列并行分片；GTP 则通过逐次消费 gather 和已完成的 reduce-scatter 工作，支持重复消费 MTP 权重。（[#5748](https://github.com/NVIDIA/Megatron-LM/pull/5748)、[#6242](https://github.com/NVIDIA/Megatron-LM/pull/6242)）

### GTP 对称内存、评估与检查点

GTP 重物化获得集合通信内存优化，并修正了评估和分布式检查点写入的副本组语义。

- 在独立的显式启用标志下，GTP 和专家 GTP 权重梯度 reduce-scatter 发送缓冲区可使用进程组对称内存池。（[#6535](https://github.com/NVIDIA/Megatron-LM/pull/6535)）
- 评估归约与批次可整除性检查现包含 GTP 重物化 rank；检查点写入者选举使用调用方持有、排除重物化轴的副本组，包括专家副本组。（[#6717](https://github.com/NVIDIA/Megatron-LM/pull/6717)、[#6775](https://github.com/NVIDIA/Megatron-LM/pull/6775)）

### Gated Delta Product 与 Gated DeltaNet

GDP 成为一等混合模型混合器，具备优化的树内 kernel、分布式检查点及图捕获动态推理路径。

- Gated Delta Product 混合器现支持训练、静态与动态推理、张量与上下文并行、THD 打包、检查点重分片、优化器路由及 FLOPs 统计。（[#6074](https://github.com/NVIDIA/Megatron-LM/pull/6074)）
- 树内 flash-linear-attention kernel 覆盖 GDP 分块与循环运算；优化路径减少张量复制，并新增 CuTeDSL 执行、选择性投影重计算、QKV 卸载，以及训练和推理共享辅助函数。（[#6538](https://github.com/NVIDIA/Megatron-LM/pull/6538)、[#6553](https://github.com/NVIDIA/Megatron-LM/pull/6553)）
- 动态推理现支持 Gated DeltaNet prefill 与单 token decode、GDP CUDA Graph，以及携带循环卷积状态的 GDP 分块 prefill。（[#6499](https://github.com/NVIDIA/Megatron-LM/pull/6499)、[#6595](https://github.com/NVIDIA/Megatron-LM/pull/6595)、[#6711](https://github.com/NVIDIA/Megatron-LM/pull/6711)）
- GDP 输入投影分片会在分布式检查点拆分前完成 gather 并移除填充，恢复时再重新填充和切片。（[#6503](https://github.com/NVIDIA/Megatron-LM/pull/6503)）

### 批次不变与解耦混合推理

推理工作新增批次不变的 MoE 与 SSM 执行、缓存感知请求准入，以及引擎间 KV-cache 和混合状态交接。

- 批次不变执行现覆盖 Nemotron MoE 和 Mamba 运算，并支持 vLLM Triton fused-MoE 后端、门控 SwiGLU、对齐的 CUDA Graph 桶和原生 Transformer Engine GEMM 模式。（[#4871](https://github.com/NVIDIA/Megatron-LM/pull/4871)、[#6521](https://github.com/NVIDIA/Megatron-LM/pull/6521)）
- LRU 感知准入将恢复请求的分配与活动缓冲区需求分离；解耦推理可通过 NIXL 或 NCCL 传输预取的 KV-cache 状态，并支持块所有权、前缀复用和故障同步。（[#5995](https://github.com/NVIDIA/Megatron-LM/pull/5995)、[#6222](https://github.com/NVIDIA/Megatron-LM/pull/6222)）
- 解耦混合推理可在注意力状态之外传输 Mamba 系列状态；模型权重替换后，refit hook 会刷新由 Mamba 权重派生的 decode 缓存。（[#6584](https://github.com/NVIDIA/Megatron-LM/pull/6584)、[#6672](https://github.com/NVIDIA/Megatron-LM/pull/6672)）

### mHC 与激活重计算

Manifold Hyper-Connection 支持已完成，并针对融合精度、CUDA Graph、专家并行重叠和别名检查点存储进行了强化。

- 核心 PyTorch mHC 模块现已集成到 transformer 层和重计算中；融合 cuTile 路径使用 FP32 执行映射计算和反向归约，并采用 BF16 激活。（[#4531](https://github.com/NVIDIA/Megatron-LM/pull/4531)、[#6172](https://github.com/NVIDIA/Megatron-LM/pull/6172)）
- mHC 选择性重计算现支持专家并行 all-to-all 重叠下的 CUDA Graph 作用域，并带有卸载保护。（[#5841](https://github.com/NVIDIA/Megatron-LM/pull/5841)）
- 激活检查点会保留与已保存输入共享存储的输出；专家并行 all-to-all 重叠支持虚拟流水线阶段粒度的完整激活重计算。（[#4497](https://github.com/NVIDIA/Megatron-LM/pull/4497)、[#5869](https://github.com/NVIDIA/Megatron-LM/pull/5869)）

### 上下文并行、THD 与专家数据移动

上下文并行执行已扩展至 RL、混合布局、打包注意力、样本路由、CSA 对齐及专家分发格式。

- RL 训练现通过序列打包工具、Transformer Engine 集成和 CUDA Graph 支持上下文并行；CSA indexer-loss 修复可保留 THD 布局，并排除打包序列中的填充位置。（[#5882](https://github.com/NVIDIA/Megatron-LM/pull/5882)、[#5960](https://github.com/NVIDIA/Megatron-LM/pull/5960)）
- 数据并行样本重路由在上下文并行 lane 内对各字段执行填充式 all-gather；混合堆栈保留连续 GDN 布局，并在常规注意力边界通过可复用 THD 路由转换为 zigzag 布局。（[#6378](https://github.com/NVIDIA/Megatron-LM/pull/6378)、[#6387](https://github.com/NVIDIA/Megatron-LM/pull/6387)、[#6515](https://github.com/NVIDIA/Megatron-LM/pull/6515)）
- Megatron Lite 的 Qwen3-MoE 模型新增可选 MagiAttention，用于打包变长训练中的负载均衡 token 放置和上下文并行注意力通信。（[#6478](https://github.com/NVIDIA/Megatron-LM/pull/6478)）
- NCCL 专家并行 dispatch 与 combine-backward 运算可通过 Transformer Engine 使用配置的 BF16 或 MXFP8 张量格式。（[#6524](https://github.com/NVIDIA/Megatron-LM/pull/6524)）

### 多模态配置与 OpenTelemetry 插桩

训练示例扩展了多模态配置传递，并为核心执行路径加入可配置的可观测性。

- 多模态示例现提供统一的语言、视觉、声音、投影、融合、重计算、打包、动态分辨率、推理、视频、音频和 dataloader 选项。（[#6332](https://github.com/NVIDIA/Megatron-LM/pull/6332)）

### RL rollout 持久性与已发布依赖

RL 恢复新增持久化 rollout 存储，开发依赖则迁移至已发布的韧性和数据包。

## 进行中的方向

DeepSeek-V4 工作正在构建稀疏注意力 kernel、参考路径、混合模型集成及可复用 MTP 状态。

- 开发了面向 BF16 和 MXFP8 的紧凑型 SM100 DSA indexer 与 Top-K 执行，同时构建可配置的低内存 DeepSeek Sparse Attention 路径以处理 GQA 张量，并在 MTP 步骤间以类型化方式复用 Top-K 输出及上下文并行 gather 的潜在 KV。（[#5992](https://github.com/NVIDIA/Megatron-LM/pull/5992)、[#6426](https://github.com/NVIDIA/Megatron-LM/pull/6426)、[#6472](https://github.com/NVIDIA/Megatron-LM/pull/6472)）
- 新增 Compressed Sparse Attention 的 eager BF16 SBHD 参考实现，以及由 cuDNN 选择、融合 indexer loss 的后端。（[#6400](https://github.com/NVIDIA/Megatron-LM/pull/6400)、[#6404](https://github.com/NVIDIA/Megatron-LM/pull/6404)）
- 新增 DeepSeek-V4 混合层构建，并通过原生注意力模块、分组输出、MTP 传播及 indexer-loss 调度接入 CSA。（[#6402](https://github.com/NVIDIA/Megatron-LM/pull/6402)、[#6405](https://github.com/NVIDIA/Megatron-LM/pull/6405)）

### Qwen3.5-VL 与异构 MIMO/GTP 训练

### Muon、FP8/MXFP8 与优化器内存

优化器工作结合新的 Muon 分布策略、量化参数同步、检查点恢复及 CPU 卸载。

- 新增 Hyperball 约束的 Muon 更新，并提出跨 TP 和 GTP 域的逐层分片及稠密/专家混合 Newton–Schulz 执行。（[#6422](https://github.com/NVIDIA/Megatron-LM/pull/6422)、[#6683](https://github.com/NVIDIA/Megatron-LM/pull/6683)、[#6761](https://github.com/NVIDIA/Megatron-LM/pull/6761)）

- 跨分支对齐 LayerWise FP8 参数 gather 与检查点填充；新增检查点加载后从 FP32 优化器主副本恢复链式及逐层优化器的量化参数；并提出支持重叠或同步 GTP 参数 gather 的 MXFP8 感知 Muon 布局。（[#5479](https://github.com/NVIDIA/Megatron-LM/pull/5479)、[#6015](https://github.com/NVIDIA/Megatron-LM/pull/6015)、[#6666](https://github.com/NVIDIA/Megatron-LM/pull/6666)、[#6754](https://github.com/NVIDIA/Megatron-LM/pull/6754)）

### MoE decode kernel 与 Blackwell attention

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
