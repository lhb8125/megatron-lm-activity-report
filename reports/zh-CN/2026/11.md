# Megatron-LM 月度活动报告 — 2026年11月（截至2026-11-01）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/11.md)

> 统计周期：2026-11-01 至 2026-11-01（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作改进了 MFSDP 通信重叠和 MXFP8 重计算，同时强化了 ScheduleNode 激活所有权。进行中的工作推进 MoE 路由与执行、集合感知的进程组处理、MFSDP 流水线跟踪以及 Transformer Engine 兼容性。

- 过滤后的实质性 PR 活动：新开 5；合并 13；关闭未合并 5；截止时仍在进行 56。
- 不计入报告正文和统计：纯 UT 0，纯 CI 1，UT/CI-only 1，纯格式化 0。

## 已交付成果

### MFSDP 梯度通信重叠

MFSDP v2 将外层梯度归约分离到专用 stream，并提供独立的重叠控制。

- DP-outer 梯度归约现在使用专用 stream，可与后续 inner 归约重叠，且无需增加 gradient buffer。（[main #6973](https://github.com/NVIDIA/Megatron-LM/pull/6973)）

### MFSDP MXFP8 重计算

MFSDP 重计算现在支持收集 MFSDP 所有模块之外所需的 MXFP8 数据。

- 完善了重计算测试，并将 opt-in 调度设置重命名为在 backward 期间收集所有 MXFP8 planes，从而提供对 rowwise 和 columnwise MXFP8 数据的访问。（[main #8432](https://github.com/NVIDIA/Megatron-LM/pull/8432)）

### ScheduleNode 激活所有权

ScheduleNode 激活处理为可释放输入和分组张量保留与存储无关的所有权。

- 将 autograd-boundary 分支与 main 同步，同时保留支持 MXFP8 分组张量和 dispatch buffers 的所有权，无需调整 storage 大小即可手动释放。（[main #8302](https://github.com/NVIDIA/Megatron-LM/pull/8302)）

## 进行中的方向

### MoE 路由与执行

MoE 工作正在改进推理重叠、确定性 expert 合并、分块执行以及 batch-invariant 路由。

- Shortcut MoE 推理通过 opt-in CUDA-graph-compatible 重叠，在路由与 attention 或 GDP 分支之间实现重叠；串行推理仍为默认模式。（[main #8257](https://github.com/NVIDIA/Megatron-LM/pull/8257)）
- opt-in 的固定 FP32 reduction tree 为 batch-invariant MoE 路由提供 EP-invariant 合并。（[main #8261](https://github.com/NVIDIA/Megatron-LM/pull/8261)）
- 分块 MoE 执行保持调用次数固定，并重放每个 chunk 的路由，以避免 expert-parallel 死锁并保持重计算行为。（[main #8463](https://github.com/NVIDIA/Megatron-LM/pull/8463)）
- 共享的 Triton sigmoid top-k 路径使受支持的训练和推理配置具备一致的 batch-invariant 路由行为。（[main #8602](https://github.com/NVIDIA/Megatron-LM/pull/8602)）

### 核心进程组所有权

核心训练和 checkpoint 路径正在将通信及辅助操作迁移到每次运行的进程组集合上，同时提供 global-grid 回退。

- 核心辅助函数现在会在省略的进程组解析为 global grid 时发出警告，覆盖 attention、推理、CUDA-graph、MoE 和日志路径。（[main #8755](https://github.com/NVIDIA/Megatron-LM/pull/8755)）
- 训练循环辅助函数使用基于集合的数据并行选择，并将该集合传递到模型设置、归约、优化器使用和辅助检查中。（[main #8757](https://github.com/NVIDIA/Megatron-LM/pull/8757)）
- Checkpoint 元数据、RNG、dataloader 和 gradient-dump 处理现在使用集合感知的进程组，而不是静默回退到 global grid。（[main #8758](https://github.com/NVIDIA/Megatron-LM/pull/8758)）

### 进程组注册与强制执行

进程组迁移工作正在扩展基于 registry 的 bootstrap、自动检查以及针对自定义 grid 的端到端验证。

- Bootstrap 从已注册的进程组集合初始化，并构建 all-gather 组，同时支持 framework 创建的组、expert GTP 以及非默认 rank 排列。（[main #8768](https://github.com/NVIDIA/Megatron-LM/pull/8768)）
- 进程组检查器强制执行规则，对 global-grid 读取进行分类，并更新 CI 检查以覆盖有警告、受保护和无警告的回退路径。（[main #8770](https://github.com/NVIDIA/Megatron-LM/pull/8770)）
- 集成测试在严格回退和弃用设置下，于非 global grid 上验证模型构建、DDP、优化、训练、checkpointing 和推理。（[main #8771](https://github.com/NVIDIA/Megatron-LM/pull/8771)）
- 全树范围的 CI 检查覆盖隐藏别名、私有 global 读取、被忽略的警告和功能测试覆盖率，从而强制在合并时执行进程组回退策略。（[main #8773](https://github.com/NVIDIA/Megatron-LM/pull/8773)）

### MFSDP 流水线执行跟踪

MFSDP 执行顺序记录正在扩展，以验证完整的流水线调度。

- 执行顺序记录现在覆盖完整的 PP/VPP 流水线窗口，包括多次 backward 调用以及 forward/backward 转换，并通过共享 cursor 和 lookahead 实现。（[main #8778](https://github.com/NVIDIA/Megatron-LM/pull/8778)）

### Transformer Engine 2.21 兼容性

Transformer Engine 兼容性工作更新了引擎基线，并适配分片 LayerNormLinear 梯度及受影响的引用。

- Transformer Engine 固定到 release_v2.21 tip；LayerNormLinear dummy weight 梯度使用本地参数形状，并刷新受影响的数值、推理和 CUDA-graph 引用。（[main #8807](https://github.com/NVIDIA/Megatron-LM/pull/8807)）
