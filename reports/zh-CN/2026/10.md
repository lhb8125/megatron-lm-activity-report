# Megatron-LM 月度活动报告 — 2026年10月（截至2026-10-11）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/10.md)

> 统计周期：2026-10-01 至 2026-10-11（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作增强了 attention 与 distributed training 的正确性，扩展了 MFSDP 和模型能力，并提升了 CUDA Graph、MoE、多模态及 inference 的可靠性。持续工作推进 custom parallel topologies、MFSDP 与 checkpointing、CUDA Graph 可靠性、inference execution、hybrid model features 以及 MoE 性能。

- 过滤后的实质性 PR 活动：新开 277；合并 98；关闭未合并 44；截止时仍在进行 335。
- 不计入报告正文和统计：纯 UT 29，纯 CI 26，UT/CI-only 7，纯格式化 0。

## 已交付成果

### MLA RoPE 与 fused attention 正确性

Attention kernels 与 fused normalization paths 针对 packed 和 sliding-window workloads 获得了 race-safety、masking 及 execution-path 修复。

- Fused MLA Q-RoPE kernels 现在会在 source loads 与重叠的 in-place stores 之间插入 barriers，同时 per-head bounds 使用 absolute indices，防止 partial-block accesses 访问相邻 token rows。（[main #5963](https://github.com/NVIDIA/Megatron-LM/pull/5963)、[main #6890](https://github.com/NVIDIA/Megatron-LM/pull/6890)、[dev #7789](https://github.com/NVIDIA/Megatron-LM/pull/7789)）
- Sliding-window attention 现在使用 masking-aware PyTorch softmax path，而不是可能静默应用完整 causal attention 的 Apex fused kernels。（[main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850)）
- Fused MLA pre-MLP normalization specification 暴露 residual input，使 Transformer Engine 的 fused residual RMSNorm backward path 得以启用；MLA down-projection preparation 则使用 vectorized tiled copy kernel 处理 row-strided Q 和 KV inputs。（[main #7942](https://github.com/NVIDIA/Megatron-LM/pull/7942)、[main #7957](https://github.com/NVIDIA/Megatron-LM/pull/7957)）

### MFSDP v2 checkpointing 与 distributed layouts

MFSDP v2 扩展了 optimizer checkpoint 支持，并强化了 layout construction、communication、conversion 及 delayed-gradient handling。

- MFSDP v2 optimizer state 现在支持以共享的 fsdp_dtensor format 进行 DCP save 和 load，包括 empty-local-shard placeholders；Torch-dist 到 FSDP-DTensor 的 conversion 也能处理 embedded common state 与 fused Gated DeltaProduct projection keys。（[main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215)、[main #7674](https://github.com/NVIDIA/Megatron-LM/pull/7674)）
- DBuffer 和 TensorAtomic 现在支持 multi-axis 与 uneven layouts，包括 zero-owned-tensor ranks；fully_shard 根据 parameter-owner assignments 构造 TensorAtomic layouts，同时保留 parameter ordering 和 tied parameters。（[main #7633](https://github.com/NVIDIA/Megatron-LM/pull/7633)、[main #7671](https://github.com/NVIDIA/Megatron-LM/pull/7671)、[main #7672](https://github.com/NVIDIA/Megatron-LM/pull/7672)）
- MFSDP v2 明确了 delayed weight-gradient synchronization 的 ownership，使 MCore 在 optimizers 消费 gradients 前完成 reductions。（[main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854)）

### CUDA Graph capture 与 Triton determinism

Initialization 和 capture paths 现在提供更可预测的 kernel configuration 与 runtime RNG behavior。

- 打包的 Triton autotune policy 在 deterministic mode 下固定 covered in-tree kernel configurations，使 Mamba、MLA RoPE、mHC 和 core autotuners 在各 rank 选择一致的 non-timed configurations。（[main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076)）
- CUDA Graph capture 现在会探测并缓存 lazy generator-registration support；在较新的 PyTorch versions 中，full-iteration capture 会预热 CUDA generator states，防止 lazy Philox initialization 使 multi-stage capture 失效。（[main #7800](https://github.com/NVIDIA/Megatron-LM/pull/7800)、[main #7885](https://github.com/NVIDIA/Megatron-LM/pull/7885)）

### MoE dispatch 与 distributed routing 可靠性

MoE dispatch 获得了 backend 与 routing compatibility 改进，同时 collective exchange 和 scratch-buffer reuse 更加安全。

- Flex dispatch 支持带有 deterministic replay coverage 的 DeepEP v2 backend，并在可用时使用 Transformer Engine dense top-k routing indices，同时保留 boolean-map compatibility paths。（[main #5153](https://github.com/NVIDIA/Megatron-LM/pull/5153)、[main #6615](https://github.com/NVIDIA/Megatron-LM/pull/6615)）
- MoE auxiliary 和 sequence-auxiliary loss reductions 现在使用每个 packed microbatch 的 runtime context-parallel topology 及 local valid-token counts，包括 uneven token distributions。（[main #7046](https://github.com/NVIDIA/Megatron-LM/pull/7046)）
- HybridEP routing exchanges 现在使用 NCCL all-gather，替代容易超时的 custom kernel；recycled GTP wgrad scratch buffers 会携带 completion events，并由 next writer stream 在 checkout 时遵守这些 events。（[main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771)、[main #7927](https://github.com/NVIDIA/Megatron-LM/pull/7927)）

### Muon 与 wide residual-stream model 支持

Model architecture 工作保留了 logical attention updates，并将 wide residual streams 集成到 auxiliary 与 ShortcutMoE paths。

- Muon 为 TP-fragmented QKV layouts 增加了 per-head QKV orthogonalization 和 reconstruction，包括 MLA 与 GTP-rematerialization cases。（[main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326)、[dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085)）
- Wide residual streams 现在可与 MTP 和 MIMO 组合，同时保留 ordinary-width auxiliary 与 modality paths；ShortcutMoE 支持 wide residual input/output views、residual replay、MTP/MIMO composition 及 FP32 residuals。（[main #6855](https://github.com/NVIDIA/Megatron-LM/pull/6855)、[main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440)）

### Mamba continuation state 与 inference caching

Inference state handling 现在保护 recurrent transitions、partial-prefill boundaries、cache epochs 及 short-sequence execution。

- 当 matching attention KV blocks 缺少可用的 Mamba state boundary 时，Hybrid inference 会重新计算 continuation chunks，防止 cached attention prefixes 跳过 recurrent transitions。（[main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714)）
- Mamba snapshot extraction 使用 scan 的 actual chunk indices 处理 context-aligned partial prefills；inference 将 published FlashAttention query length 的最小值设为 two，而不是对 prefill chunks 进行 clamping。（[main #7755](https://github.com/NVIDIA/Megatron-LM/pull/7755)、[main #7905](https://github.com/NVIDIA/Megatron-LM/pull/7905)）
- Model refit 后，unprefilled requests 会重新加 salt 并重新 hash，使新 requests 无法匹配在 previous weight epoch 下生成的 KV 或 Mamba blocks。（[main #7891](https://github.com/NVIDIA/Megatron-LM/pull/7891)）

### MIMO 与 multimodal checkpoint inference

Multimodal 和 MIMO inference paths 获得了 checkpoint loading、model resolution 及 rank-safe checkpoint discovery 支持。

- Dynamic inference 可以通过 remapping nested MIMO state-dict keys 并暴露 vision configuration overrides，将 MIMO-trained VLM checkpoints 加载到 LLaVAModel；Nemotron loading 和 inference paths 也针对 revised mappings、hybrid blocks 及 wide residuals 进行了更新。（[main #7752](https://github.com/NVIDIA/Megatron-LM/pull/7752)、[main #7839](https://github.com/NVIDIA/Megatron-LM/pull/7839)）
- MTP 现在通过 generic helper 为 multimodal wrappers 解析 underlying language model；MIMO checkpoint directories 会在 rank-zero metadata reads 前由每个 rank 解析，以避免 checkpoint-completeness deadlocks。（[main #7940](https://github.com/NVIDIA/Megatron-LM/pull/7940)、[main #7941](https://github.com/NVIDIA/Megatron-LM/pull/7941)）

### Low-precision 与 inference kernel 优化

Precision controls 和 fused kernels 减少了不必要的工作，同时保留受支持的 optimizer、expert 及 inference behaviors。

- DSA projection paths 现在独立控制 FP8/FP4 participation 以及 BF16 或 FP32 outputs；ModelOpt 支持 separate learning rate，并为 NVFP4 LSQ scale parameters 提供 expert-parallel reduction metadata。（[main #6842](https://github.com/NVIDIA/Megatron-LM/pull/6842)、[main #7802](https://github.com/NVIDIA/Megatron-LM/pull/7802)）
- GDP padding writes 和 vLLM MoE counter initialization 被融合进 preceding kernels；paged-stash launch geometry 可配置；在满足条件时，fused shared-expert 和 residual additions 使用一个 Triton kernel。（[main #7841](https://github.com/NVIDIA/Megatron-LM/pull/7841)、[main #7897](https://github.com/NVIDIA/Megatron-LM/pull/7897)、[main #7943](https://github.com/NVIDIA/Megatron-LM/pull/7943)）
- Precision-aware FP8 optimizer selection 现在会在 parameters 仍为 BF16 且未作为 FP8 gathered 时保留 optimized path，避免不必要的 MCore FP32 gradient copies。（[26.09-beta #7915](https://github.com/NVIDIA/Megatron-LM/pull/7915)）

## 进行中的方向

### Explicit process-group collections 与 custom topologies

Model、training、inference、quantization、checkpoint 和 communication paths 正在迁移到经过验证的 model-local process-group collections。

- Attention、language modules 和 model-parallel teardown 现在使用 explicit process-group collections；custom data-schedule domains 和 pipeline construction 遵循 caller-provided topology 与 ranks。（[main #6293](https://github.com/NVIDIA/Megatron-LM/pull/6293)、[main #6303](https://github.com/NVIDIA/Megatron-LM/pull/6303)、[main #7029](https://github.com/NVIDIA/Megatron-LM/pull/7029)、[main #8020](https://github.com/NVIDIA/Megatron-LM/pull/8020)、[main #8022](https://github.com/NVIDIA/Megatron-LM/pull/8022)、[main #8023](https://github.com/NVIDIA/Megatron-LM/pull/8023)、[main #8033](https://github.com/NVIDIA/Megatron-LM/pull/8033)）
- Gradient finalization、inference padding、symmetric-memory barriers、RNG seeding 和 optimizer duplicate filtering 根据 active model topology 推导其 groups 与 dimensions。（[main #8027](https://github.com/NVIDIA/Megatron-LM/pull/8027)、[main #8029](https://github.com/NVIDIA/Megatron-LM/pull/8029)、[main #8030](https://github.com/NVIDIA/Megatron-LM/pull/8030)、[main #8031](https://github.com/NVIDIA/Megatron-LM/pull/8031)、[main #8042](https://github.com/NVIDIA/Megatron-LM/pull/8042)）
- Quantization、training initialization、Transformer Engine operations、checkpoint replica metadata 和 fallback validation 现在使用 owner-local groups，并显式检查 required groups。（[main #8035](https://github.com/NVIDIA/Megatron-LM/pull/8035)、[main #8037](https://github.com/NVIDIA/Megatron-LM/pull/8037)、[main #8038](https://github.com/NVIDIA/Megatron-LM/pull/8038)、[main #8044](https://github.com/NVIDIA/Megatron-LM/pull/8044)、[main #8049](https://github.com/NVIDIA/Megatron-LM/pull/8049)）

### MFSDP v2 scheduling、gradients 与 uneven shards

MFSDP v2 正在扩展其 runtime scheduling、gradient lifecycle、prefetching、checkpoint 和 sharding 支持。

- MFSDP v2 使 runtime parameters 和 optimizer state 保持 local，协调 shared-weight gradient callbacks，并支持 backward 期间的 repeated 或 unused modules。（[main #7322](https://github.com/NVIDIA/Megatron-LM/pull/7322)、[main #7581](https://github.com/NVIDIA/Megatron-LM/pull/7581)、[main #7582](https://github.com/NVIDIA/Megatron-LM/pull/7582)、[main #7750](https://github.com/NVIDIA/Megatron-LM/pull/7750)、[main #7783](https://github.com/NVIDIA/Megatron-LM/pull/7783)、[pull-request/8113 #7902](https://github.com/NVIDIA/Megatron-LM/pull/7902)、[main #7912](https://github.com/NVIDIA/Megatron-LM/pull/7912)）
- Hybrid 和 Shortcut MoE execution 获得 aligned prefetch order、phase-specific MXFP8 scheduling（forward 聚合 rowwise planes、backward 聚合 columnwise planes）、residual-aware prefetch policies，以及针对 shared modules 的 runtime-accurate schedules。（[main #7809](https://github.com/NVIDIA/Megatron-LM/pull/7809)、[main #7907](https://github.com/NVIDIA/Megatron-LM/pull/7907)、[main #7929](https://github.com/NVIDIA/Megatron-LM/pull/7929)、[main #7992](https://github.com/NVIDIA/Megatron-LM/pull/7992)、[main #7998](https://github.com/NVIDIA/Megatron-LM/pull/7998)）
- MFSDP v2 增加 fused weight-gradient accumulation、embedding-gradient synchronization，以及面向 uneven shards 的 opt-in unpadded row- 和 block-atomic layouts。（[pull-request/7757 #7836](https://github.com/NVIDIA/Megatron-LM/pull/7836)、[main #7860](https://github.com/NVIDIA/Megatron-LM/pull/7860)、[main #7978](https://github.com/NVIDIA/Megatron-LM/pull/7978)、[main #8116](https://github.com/NVIDIA/Megatron-LM/pull/8116)）

### Checkpointing、state restoration 与 model compatibility

Checkpoint handling 正在针对 distributed optimizer state、training state、grouped models 和 cross-layer execution state 进行强化。

- Grouped HybridModel loading、cross-layer tensor-state transport 和 tied-embedding initialization 扩展了 grouped 与 pipeline-parallel models 之间的 checkpoint 和 model-state compatibility。（[main #7192](https://github.com/NVIDIA/Megatron-LM/pull/7192)、[main #7678](https://github.com/NVIDIA/Megatron-LM/pull/7678)、[main #8010](https://github.com/NVIDIA/Megatron-LM/pull/8010)）

### CUDA Graph capture 与 determinism

CUDA Graph coverage 和 deterministic execution 正在扩展到 THD training、attention kernels、mHC、CSA 及 validation tooling。

- THD 获得了 chunk-wise Transformer Engine CUDA Graph capture plumbing，并针对 padding masks、KDA synchronization、batch mutation、recomputation context 和 NUMA handling 增加 robustness fixes。（[dev #5258](https://github.com/NVIDIA/Megatron-LM/pull/5258)、[dev #8105](https://github.com/NVIDIA/Megatron-LM/pull/8105)）
- 共享的 determinism policy 现在会在 entrypoints 早期初始化；DSv4 attention 和 mHC/CSA kernels 获得 deterministic ordering、indexing、reduction 及 backward fixes。（[main #7419](https://github.com/NVIDIA/Megatron-LM/pull/7419)、[dev #7441](https://github.com/NVIDIA/Megatron-LM/pull/7441)、[main #7704](https://github.com/NVIDIA/Megatron-LM/pull/7704)、[dev #7706](https://github.com/NVIDIA/Megatron-LM/pull/7706)）
- Activation-checkpointing state 会在 exceptions 和 nested calls 之间恢复，使 graph 和 recompute paths 不会留下不一致的 global checkpointing state。（[main #7975](https://github.com/NVIDIA/Megatron-LM/pull/7975)）

### Disaggregated 与 fused inference execution

Inference 工作涵盖 prefill/decode disaggregation、replayable sampling、fused MoE execution、streaming loads 及 state-transfer reliability。

- Prefill/decode disaggregation 增加了 coordinator routing、NCCL/NIXL KV 和 SSM handoff、recovery，以及 asynchronous routing-replay preservation。（[main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)、[main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310)、[pull-request/6675 #7999](https://github.com/NVIDIA/Megatron-LM/pull/7999)）
- Inference loads 可以执行 FP8 和 FP4 dequantization streaming；MTP KV-cache graph validation 与 shared-prefix execution 在 speculative 和 branched requests 之间保留 state。（[main #7405](https://github.com/NVIDIA/Megatron-LM/pull/7405)、[main #7914](https://github.com/NVIDIA/Megatron-LM/pull/7914)、[main #8040](https://github.com/NVIDIA/Megatron-LM/pull/8040)）
- MoE inference 获得 inference-kernel training forwards、FlashInfer EP megakernel backend、request-local FlashInfer seeds 和 offsets，以及 fused routing 与 expert-GEMM paths。（[main #7798](https://github.com/NVIDIA/Megatron-LM/pull/7798)、[main #7830](https://github.com/NVIDIA/Megatron-LM/pull/7830)、[pull-request/7828 #7955](https://github.com/NVIDIA/Megatron-LM/pull/7955)、[pull-request/7828 #7976](https://github.com/NVIDIA/Megatron-LM/pull/7976)、[main #8114](https://github.com/NVIDIA/Megatron-LM/pull/8114)）

### DSA、MLA、KDA 与 hybrid attention models

新的及扩展的 attention architectures 增加了 KDA、simplified DSA、gated MLA、Lite indexer integration 和 packed CSA2 execution。

- HybridModel 在 GQA 之上获得 KDA 和 simplified DSA，包括 bounded-memory kernels、learned top-k routing、sparse selected-key attention 及 context-parallel support。（[main #7054](https://github.com/NVIDIA/Megatron-LM/pull/7054)、[main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152)、[pull-request/7152 #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156)、[dev #7876](https://github.com/NVIDIA/Megatron-LM/pull/7876)）
- mHC precision 和 recomputation、KPool DSA 与 MLA precision controls、large-offset MLA indexing 以及 absorbed MLA output gating 扩展了 hybrid attention configurations。（[main #7521](https://github.com/NVIDIA/Megatron-LM/pull/7521)、[main #7522](https://github.com/NVIDIA/Megatron-LM/pull/7522)、[dev #7787](https://github.com/NVIDIA/Megatron-LM/pull/7787)、[main #8004](https://github.com/NVIDIA/Megatron-LM/pull/8004)、[dev #8006](https://github.com/NVIDIA/Megatron-LM/pull/8006)、[main #8008](https://github.com/NVIDIA/Megatron-LM/pull/8008)）
- DeepSeek-V4.1 CSA2 增加 packed THD 和 contiguous context parallelism，并支持 stateful recomputation 与 cross-layer state handling；multimodal V4-Flash-Vision path 获得 SFT support。（[dev #7808](https://github.com/NVIDIA/Megatron-LM/pull/7808)、[pull-request/7502 #8018](https://github.com/NVIDIA/Megatron-LM/pull/8018)）

### Hybrid parallel schedules 与 generalized tensor parallelism

Hybrid execution 正在获得 EP overlap、dynamic context parallelism、MTP scheduling 及 generalized tensor-parallel infrastructure。

- HybridStack 增加 bracketed layer groups、independent FSDP units 及 layer-granular expert-parallel communication overlap；EP overlap 也支持 segment-level activation recomputation。（[main #4942](https://github.com/NVIDIA/Megatron-LM/pull/4942)、[main #4943](https://github.com/NVIDIA/Megatron-LM/pull/4943)、[main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)）
- Dynamic context parallelism 已集成到 standard schedules，并通过 hybrid runtime consumers 传播；MTP sequence rolling 和 multi-layer EP overlap 支持 packed layouts 与 multiple depths。（[dev #6741](https://github.com/NVIDIA/Megatron-LM/pull/6741)、[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)、[main #7048](https://github.com/NVIDIA/Megatron-LM/pull/7048)、[pull-request/4942 #7954](https://github.com/NVIDIA/Megatron-LM/pull/7954)）
- Mamba 获得带 recurrent boundary exchange 的 chunkwise context-parallel execution；generalized tensor parallelism 现在覆盖 model、MoE、inference、checkpoint、optimizer、CUDA Graph 和 resharding paths。（[main #7910](https://github.com/NVIDIA/Megatron-LM/pull/7910)、[dev #8109](https://github.com/NVIDIA/Megatron-LM/pull/8109)）
- mHC activation transport 适配 physical 和 virtual pipeline schedules。（[main #7336](https://github.com/NVIDIA/Megatron-LM/pull/7336)）

### MoE routing、dispatch 与 packed-sequence accounting

MoE 工作改进了 virtual-expert balancing、dispatcher safety，以及 packed 和 delayed-gradient paths 的 auxiliary-loss handling。

- Virtual expert replicas 和 HybridEP dispatch 支持 MoonEP-style load balancing，同时保留 weights、gradients、DDP 和 checkpointing 的 native expert ownership。（[main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450)）
- NVLS dispatcher masking 正确处理 large token rows；packed THD sequences 获得 sequence-level auxiliary-loss accounting，且无需 dense sequence materialization。（[main #8002](https://github.com/NVIDIA/Megatron-LM/pull/8002)、[main #8014](https://github.com/NVIDIA/Megatron-LM/pull/8014)）
- Delayed-wgrad hooks 按产生各 gradient 的 slot 排序，防止带 Megatron-FSDP 的 latent MoE 中出现无效 synchronization。（[main #8056](https://github.com/NVIDIA/Megatron-LM/pull/8056)）

### Memory-efficient recurrent execution 与 optimizer numerics

Recurrent kernels 和 optimizer paths 正在针对更少的数据移动、稳定 accumulation 及 batch-invariant arithmetic 进行优化。

- Activation reload synchronization、GDN decode slot-indexed kernels 及 batch-invariant GDN/GDP arithmetic 改进了 offload safety、recurrent-state movement 和 fixed-block numerical behavior。（[main #7399](https://github.com/NVIDIA/Megatron-LM/pull/7399)、[main #7896](https://github.com/NVIDIA/Megatron-LM/pull/7896)、[main #7917](https://github.com/NVIDIA/Megatron-LM/pull/7917)）
- GTP FP32 reduce-scatter results 在 accumulation 期间保持为 FP32，以避免过早 rounding。（[main #7889](https://github.com/NVIDIA/Megatron-LM/pull/7889)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
