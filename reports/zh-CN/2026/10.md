# Megatron-LM 月度活动报告 — 2026年10月（截至2026-10-04）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/10.md)

> 统计周期：2026-10-01 至 2026-10-04（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作扩展了模型与并行训练能力，改进了 checkpoint 和配置兼容性，并增强了循环状态与推理可靠性。进行中的工作推进 hybrid 与 context-parallel 训练、DSA 与多模态模型能力、分布式 checkpoint、确定性执行，以及推理性能和可靠性。

- 过滤后的实质性 PR 活动：新开 86；合并 23；关闭未合并 16；截止时仍在进行 164。
- 不计入报告正文和统计：纯 UT 12，纯 CI 3，UT/CI-only 2，纯格式化 0。

## 已交付成果

### 宽 residual 流与模型兼容性

将宽 residual 执行扩展到辅助架构，并更新模型 checkpoint 与构造路径以支持 hybrid 推理。

- 宽 residual 流现可与 MTP 和 MIMO 组合，同时保持辅助路径和模态路径的常规宽度；ShortcutMoE 也支持 residual replay、MTP/MIMO 组合和 FP32 residual 处理。（[main #6855](https://github.com/NVIDIA/Megatron-LM/pull/6855)、[main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440)）
- LLaVA 可构造所需的 hybrid 模型，Nemotron checkpoint 和推理路径支持更新后的映射、hybrid blocks、宽 residual 和推理 wrappers。（[main #7752](https://github.com/NVIDIA/Megatron-LM/pull/7752)、[main #7799](https://github.com/NVIDIA/Megatron-LM/pull/7799)）

### MFSDP 与 DBuffer 并行布局

为分布式 optimizer shards 和不均匀 collective communication 添加了多轴及 TensorAtomic 布局支持。

- DBuffer views 和 all-gathers 支持跨多个 placement axes 的转换，包括 hybrid ZeRO 布局，且无需创建新的 process groups。（[main #7633](https://github.com/NVIDIA/Megatron-LM/pull/7633)）
- DBuffer 支持一维 TensorAtomic placement，并通过基于 list 的 all-gather 和 reduce-scatter 处理不均匀的 rank segments，包括不拥有任何 tensors 的 ranks。（[main #7671](https://github.com/NVIDIA/Megatron-LM/pull/7671)）
- MFSDP fully_shard 根据 parameter-owner assignments 构造 TensorAtomic 布局，同时保留 parameter ordering 和 tied-parameter 支持。（[main #7672](https://github.com/NVIDIA/Megatron-LM/pull/7672)）

### MoE 路由与 optimizer 更新

改进了 routing metadata 处理、按 head 的 Muon 更新以及 replicated-parameter 统计。

- Flex dispatchers 在可用时使用 Transformer Engine dense top-k routing indices，同时保留 boolean-map 兼容性，以及既有的 padding、expert-TP 和 bias-count 处理。（[main #6615](https://github.com/NVIDIA/Megatron-LM/pull/6615)）
- Muon 支持可选的按 head 的 QKV orthogonalization，以及面向 attention 和 MLA 布局的 tensor-parallel-fragmented QKV reconstruction。（[dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085)）
- Gradient norm 和 zero-count filtering 使用 optimizer process-group collection 处理 GTP ownership，并以 MPU global 作为 fallback。（[main #7359](https://github.com/NVIDIA/Megatron-LM/pull/7359)）

### Mamba cached continuation state

修正了 hybrid 推理和 partial-prefill snapshots 的 recurrent-state 处理。

- 当匹配的 attention KV blocks 缺少可用的 Mamba state boundary 时，hybrid 推理会重新计算 continuation chunks，避免 cached prefixes 跳过 recurrent transitions。（[main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714)）
- Mamba snapshot extraction 使用 scan 的实际 chunk indices，使 partial-prefill snapshots 与其声明的 token boundaries 对齐。（[main #7755](https://github.com/NVIDIA/Megatron-LM/pull/7755)）

### 训练与量化配置持久化

结构化了 reinforcement-learning 设置，并为 callable model 和 quantization configuration values 添加了 serialization 支持。

- Training configuration 现提供专用的 RLConfig section，并支持 argument、serialization 和 validation。（[main #7430](https://github.com/NVIDIA/Megatron-LM/pull/7430)）
- Callable model-configuration fields 可通过 model configuration 和 YAML argument paths 进行 serialization 与恢复。（[main #7571](https://github.com/NVIDIA/Megatron-LM/pull/7571)）
- Quantization RecipeConfig 可转换为 dictionaries，以便通过 dictionaries 或 YAML configuration 进行保存和恢复。（[main #7590](https://github.com/NVIDIA/Megatron-LM/pull/7590)）

### Checkpoint 转换与依赖兼容性

改进了 hybrid checkpoint 转换，并将 Transformer Engine 依赖栈与确定性的 expert-parallel 设置对齐。

- Torch-dist 到 FSDP-DTensor 的转换会读取嵌入的 common state，避免 opaque common-state materialization，并合并 fused Gated DeltaProduct projection keys。（[main #7674](https://github.com/NVIDIA/Megatron-LM/pull/7674)）
- Transformer Engine 已推进到 release 2.20 tip，并更新 cuDNN Frontend、CUTLASS DSL、Quack 以及 deterministic NCCL expert-token settings。（[main #7683](https://github.com/NVIDIA/Megatron-LM/pull/7683)）

### 多模态与 chat 推理兼容性

移除了限制性的 media 处理，并修正了推理接口中的 response、tool-call 和 vision-input 边界情况。

- 多模态 inference server 现使用 server-wide maximum 处理 image 和 video size，而不是 endpoint-specific byte limit。（[main #7702](https://github.com/NVIDIA/Megatron-LM/pull/7702)）
- Reasoning-aware non-streaming chat responses 保留空的 reasoning metadata；当不存在 final answer 或 tool call 时返回 null content。（[main #7749](https://github.com/NVIDIA/Megatron-LM/pull/7749)）
- Qwen3-Coder tool function names 会在 schema lookup 和 response construction 前进行规范化，避免空的 normalized names 导致 invalid calls。（[main #7753](https://github.com/NVIDIA/Megatron-LM/pull/7753)）
- RADIO temporal grouping 使用基于 length 的 inspection 处理 host-list image sizes，同时处理 tensor image sizes。（[main #7760](https://github.com/NVIDIA/Megatron-LM/pull/7760)）

## 进行中的方向

### Hybrid EP overlap、MFSDP 与 distributed lifecycle

Hybrid expert-parallel overlap 和 MFSDP execution 正扩展到 recomputation、CUDA graphs、expert balancing、repeated modules、partial graphs 及 delayed synchronization。

- HybridStack grouped scheduling 和 FSDP unit selection 针对 expert-parallel overlap 进行了优化，并加入 layer-segment recomputation 和更安全的 CUDA-graph capture 行为。（[main #4942](https://github.com/NVIDIA/Megatron-LM/pull/4942)、[main #4943](https://github.com/NVIDIA/Megatron-LM/pull/4943)、[main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)、[main #6958](https://github.com/NVIDIA/Megatron-LM/pull/6958)）
- HybridEP routing 和 expert balancing 得到强化；model-parallel teardown 会在 repeated initialization cycles 中清理 communicators 和 buffers。（[main #7029](https://github.com/NVIDIA/Megatron-LM/pull/7029)、[main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450)、[main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771)）
- MFSDP v2 现可处理 repeated 和 shared modules、ShortcutMoE ownership 与 prefetch order、unused parameters、forward-graph gradient countdowns、frozen-weight guards、checkpoint child replay 以及 delayed gradient synchronization。（[main #7750](https://github.com/NVIDIA/Megatron-LM/pull/7750)、[main #7757](https://github.com/NVIDIA/Megatron-LM/pull/7757)、[main #7781](https://github.com/NVIDIA/Megatron-LM/pull/7781)、[main #7783](https://github.com/NVIDIA/Megatron-LM/pull/7783)、[main #7809](https://github.com/NVIDIA/Megatron-LM/pull/7809)、[pull-request/7822 #7815](https://github.com/NVIDIA/Megatron-LM/pull/7815)、[main #7822](https://github.com/NVIDIA/Megatron-LM/pull/7822)、[pull-request/7757 #7836](https://github.com/NVIDIA/Megatron-LM/pull/7836)、[main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854)）

### Runtime context parallelism 与 GTP 布局

显式 process-group propagation 和 runtime context-parallel metadata 现支持更多独立的 model grids 及 contiguous attention layouts。

- Attention、model、inference、multimodal、MTP 和 scheduler paths 现使用显式的 process-group collections，并在 LanguageModule constructors 中进行 validation。（[main #6293](https://github.com/NVIDIA/Megatron-LM/pull/6293)、[main #6303](https://github.com/NVIDIA/Megatron-LM/pull/6303)）
- Dynamic context parallelism 现通过 standard schedules 运行，并将 per-microbatch geometry、groups、valid-token counts 和 auxiliary-loss metadata 传递 through hybrid model layers。（[main #7046](https://github.com/NVIDIA/Megatron-LM/pull/7046)、[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)、[main #7048](https://github.com/NVIDIA/Megatron-LM/pull/7048)）
- GTP 可分离 weight-ownership groups 与 token-processing groups；softmax attention 现可在 packed-sequence 和 MTP paths 中获得 contiguous context-parallel 支持。（[main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748)、[main #7834](https://github.com/NVIDIA/Megatron-LM/pull/7834)）

### DSA 稀疏 attention 与 indexer training

Simplified DSA 开发涵盖 bounded-memory kernels、sparse GQA、staged indexer training、deterministic execution 以及 context-parallel 支持。

- Triton 和 autograd kernels 提供 bounded-memory simplified DSA indexing、sparse GQA scoring、top-k routing 及其 gradients，并通过 HybridModel 集成 learned sparse attention。（[main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152)、[pull-request/7152 #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156)）
- Training loop 支持 staged DSA indexer freezing、initialization、optimizer-state handling 和 split gradient logging。（[pull-request/7158 #7181](https://github.com/NVIDIA/Megatron-LM/pull/7181)）
- DSv4 获得 deterministic sparse-attention backward dispatch 和稳定的 top-k 行为；simplified DSA GQA 现可跨 context-parallel layouts gather keys 和 values。（[main #7708](https://github.com/NVIDIA/Megatron-LM/pull/7708)、[pull-request/7158 #7766](https://github.com/NVIDIA/Megatron-LM/pull/7766)）

### Hybrid model architectures 与多模态训练

模型覆盖范围通过新的 hybrid attention components、mHC pipeline support、dual-mode audio encoding 以及 DeepSeek 多模态 SFT path 得到扩展。

- HybridModel 添加带 gated projections 的 Kimi Delta Attention、packed-sequence context parallelism 和可选 BF16 execution；audio encoder 支持带 RoPE 的 offline、causal 和 mixed-mode packed attention。（[main #7054](https://github.com/NVIDIA/Megatron-LM/pull/7054)、[main #7066](https://github.com/NVIDIA/Megatron-LM/pull/7066)）
- Pipeline 和 virtual-pipeline schedules 现通过 P2P buffers 与 intermediate stages 携带 mHC-expanded residual widths。（[main #7336](https://github.com/NVIDIA/Megatron-LM/pull/7336)）
- DeepSeek-V4-Flash-Vision 支持添加了 model、image/text preparation、hybrid decoder integration 以及 real-data supervised fine-tuning recipe。（[dev #7808](https://github.com/NVIDIA/Megatron-LM/pull/7808)）

### Checkpoint interoperability 与 training-state ownership

Checkpoint 和 state-management 工作改进了 grouped-model interoperability、cross-layer tensor transport、optimizer restoration 以及 inference initialization。

- 现有 GPT checkpoints 可初始化 grouped HybridModel layers，包括 optimizer 和 FSDP loading paths；cross-layer tensor state 可通过 checkpointing、CUDA graphs、pipeline schedules 和 parallel redistributions 传输。（[main #7192](https://github.com/NVIDIA/Megatron-LM/pull/7192)、[main #7678](https://github.com/NVIDIA/Megatron-LM/pull/7678)）
- Hybrid optimizer step counters 和 distributed optimizer parameter indices 会在 updates 以及 mixed-dtype checkpoint reads and writes 之间保留。（[main #7785](https://github.com/NVIDIA/Megatron-LM/pull/7785)、[main #7804](https://github.com/NVIDIA/Megatron-LM/pull/7804)）
- Inference runtime setup 和 checkpoint loading 已与 training-state、optimizer、scheduler 及 batch-progress restoration 分离。（[main #7792](https://github.com/NVIDIA/Megatron-LM/pull/7792)）

### 确定性 CUDA kernels 与 large-offset safety

Determinism 和 fused-kernel reliability 工作添加了 early policy setup、pinned autotuning，以及针对 MLA RoPE paths 更安全的 indexing 和 synchronization。

- Deterministic policy initialization 现发生在 Core GPU imports 之前；Triton autotuning 可固定 in-tree configurations，同时保留 graph 和 shared-resource cleanup。（[main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076)、[main #7419](https://github.com/NVIDIA/Megatron-LM/pull/7419)）
- Fused MLA RoPE paths 现处理 partial head blocks，并对 large inputs 使用 64-bit row、head 和 channel offsets。（[main #7770](https://github.com/NVIDIA/Megatron-LM/pull/7770)、[dev #7787](https://github.com/NVIDIA/Megatron-LM/pull/7787)）
- In-place MLA 和 DSA RoPE kernels 在 permuting stores 前添加 synchronization，以避免 outstanding loads 与 warp writes 之间的 races。（[dev #7789](https://github.com/NVIDIA/Megatron-LM/pull/7789)）

### CUDA-graph 与 inference-kernel execution

推理工作添加了 Nemotron graph execution、training-forward 对 inference MoE kernels 的复用、reproducible request sampling 以及正确的 sliding-window dispatch。

- Nemotron 4 text models 可使用带 GDP、ShortcutMoE、宽 residual、graph-safe decode padding 和 checkpoint expert-bias restoration 的 local CUDA-graph inference。（[main #7772](https://github.com/NVIDIA/Megatron-LM/pull/7772)）
- 受支持的 MoE training forwards 可通过 FlashInfer 或 inference-kernel paths 使用 inference expert kernels，包括 BF16 和 MXFP8 preparation。（[main #7798](https://github.com/NVIDIA/Megatron-LM/pull/7798)、[main #7830](https://github.com/NVIDIA/Megatron-LM/pull/7830)）
- Dynamic Torch sampling 支持 request-local seeds，其 draws 不受 batching 和 reordering 影响；sliding-window attention 会路由到支持 masking 的 softmax implementations。（[main #7828](https://github.com/NVIDIA/Megatron-LM/pull/7828)、[main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850)）
