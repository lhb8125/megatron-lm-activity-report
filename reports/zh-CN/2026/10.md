# Megatron-LM 月度活动报告 — 2026年10月（最终版，截至2026-10-31）

> English version: [English](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/en-US/2026/10.md)

> 统计周期：2026-10-01 至 2026-10-31（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作推进了分布式训练、attention 与 MoE 执行、MFSDP checkpoint、CUDA Graph 可靠性，以及新模型和硬件配置下的动态推理服务。进行中工作涵盖独立 process-grid 支持、分片训练与 checkpoint、CUDA Graph 执行、MoE 与 attention kernel、混合模型集成和推理可靠性。

- 过滤后的实质性 PR 活动：新开 841；合并 320；关闭未合并 168；截止时仍在进行 675。
- 不计入报告正文和统计：纯 UT 79，纯 CI 51，UT/CI-only 13，纯格式化 0。

## 已交付成果

### DSA、MLA 与 attention kernel 正确性

扩展 DSA 和 attention 支持，并改进确定性执行、masking 与 fused-kernel 安全性。

- Muon 现在支持 per-head QKV 正交化，以及 MHA、GQA、gated attention、MLA 和碎片化 tensor-parallel 权重中的逻辑 QKV 布局。（[main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326)、[dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085)）
- Fused MLA RoPE head 边界现在对每个已启动 block 使用绝对索引，防止 partial-block 访问相邻 token row。（[main #6890](https://github.com/NVIDIA/Megatron-LM/pull/6890)）
- DSA sparse-attention backward 现在通过静态安全输入和显式清零的 query gradient 处理空的 top-k query row。（[main #6939](https://github.com/NVIDIA/Megatron-LM/pull/6939)、[dev #7434](https://github.com/NVIDIA/Megatron-LM/pull/7434)）
- Simplified DSA 增加了有界内存的 Triton 和 autograd kernel，用于 indexer scoring、top-k routing、sparse GQA attention 及其 gradient。（[main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152)）

### DSA GQA 与确定性 attention 执行

增加 hybrid DSA attention 路径，并收紧 fused attention 实现的确定性和 masking 行为。

- Hybrid models 现在包含 simplified DSA GQA attention，支持 learned top-k indexing、sparse attention、reference path、indexer loss 和可配置的 dense fallback。（[main #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156)）
- DSv4 deterministic mode 会规范化 compact top-k 顺序，使用 deterministic sparse-attention 和 indexer reduction，并拒绝不支持的 nondeterministic router auxiliary loss。（[dev #7441](https://github.com/NVIDIA/Megatron-LM/pull/7441)、[dev #7706](https://github.com/NVIDIA/Megatron-LM/pull/7706)、[main #8194](https://github.com/NVIDIA/Megatron-LM/pull/8194)）
- Sliding-window attention 现在使用支持 masking 的 PyTorch softmax 路径，而不是可能静默应用完整 causal attention 的 Apex fused kernel。（[main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850)）
- 打包的 Triton autotune policy 在 deterministic mode 下固定 tree 内 kernel configuration，使各 rank 选择一致的 configuration。（[main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076)）

### MoE expert parallelism 与 routing

改进 expert-parallel dispatch、recomputation、virtual expert、routing exchange 和 batch-invariant MoE 执行。

- Inference MoE models 可以使用基于 NVLS 的 expert tensor-parallel dispatch，并在 routing 和 determinism coverage 中传递 expert group。（[main #4743](https://github.com/NVIDIA/Megatron-LM/pull/4743)）
- MoE expert-parallel A2A overlap 路径现在支持以 layer-segment 为粒度的 full activation recomputation。（[main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)）
- HybridEP 增加 MoonEP 风格的 virtual expert duplication，支持 symmetric-memory weight 和 gradient arena、route planning 及 owner-gradient reduction。（[main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450)）
- HybridEP routing 现在使用 NCCL all-gather，而不是容易超时的 custom all-gather kernel。（[main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771)）

### MoK 与 batch-invariant MoE 推理

增加 MCore 自有的 MoK backend，并优化 routed-expert inference 和 unpermutation 路径。

- Megatron 增加 Mixture-of-Kittens MoE backend，包含 MCore 自有的 routing、parameter、optimizer state、DDP hook、checkpoint，以及对 routed 和 gated shared expert 的支持。（[main #8210](https://github.com/NVIDIA/Megatron-LM/pull/8210)）
- 默认的 batch-invariant MoE unpermute 路径现在在不需要 probability 时使用 fused Triton combine kernel；FlashInfer 支持 squared-ReLU 和 SwiGLU expert 的 batch-invariant NVFP4 routed-MoE inference。（[main #8262](https://github.com/NVIDIA/Megatron-LM/pull/8262)、[main #8559](https://github.com/NVIDIA/Megatron-LM/pull/8559)）

### Hybrid architecture 与 parallel strategy

通过 dynamic context parallelism、KDA、wide residual stream 和 sequence-partitioned execution 扩展 hybrid models。

- Dynamic context parallelism 现在使用标准 training 和 evaluation schedule，支持 caller-owned process group、packed PP/VPP/MTP data 及 runtime CP layout。（[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)）
- Kimi Delta Attention hybrid layer 增加 GLM 风格的 two-stage low-rank gate、packed 和 context-parallel execution，以及可配置的 BF16 或 FP8 projection。（[main #7054](https://github.com/NVIDIA/Megatron-LM/pull/7054)、[main #7521](https://github.com/NVIDIA/Megatron-LM/pull/7521)、[dev #8400](https://github.com/NVIDIA/Megatron-LM/pull/8400)）
- ShortcutMoE 现在集成 wide residual stream、residual replay、MTP/MIMO composition 和 FP32 residual 支持。（[main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440)）
- GTP_remat 支持可配置的 sequence 和 batch partitioning，提供独立的 weight 与 batch/sequence process-group view，并与 context parallelism 集成。（[main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748)）

### MIMO context parallelism 与 checkpoint 可靠性

将 MIMO context-parallel layout 与 checkpoint-safe execution 及 heterogeneous language grid 连接起来。

- MIMO 现在将 context-parallel batch 和 layout handling 与 GTP sequence partition 集成，同时保持 embedding、position、label 和 mask 对齐。（[main #7758](https://github.com/NVIDIA/Megatron-LM/pull/7758)）
- MIMO checkpoint directory resolution 现在会在 rank-zero 读取 metadata 前于每个 rank 上执行，避免 checkpoint-completeness deadlock。（[main #7941](https://github.com/NVIDIA/Megatron-LM/pull/7941)）

### MFSDP v2 sharding、checkpoint 与 gradient synchronization

扩展 MFSDP v2 checkpoint 支持、shard layout、expert-parallel restart、delayed reduction 和 MXFP8 安全性。

- MFSDP v2 optimizer state 现在支持以共享 FSDP DTensor format 执行 DCP save 和 load，包括 empty-local-shard placeholder；distributed checkpoint process-group cache 以 ordered global rank 的 digest 为 key，从而隔离 shard distribution。（[main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215)、[main #8251](https://github.com/NVIDIA/Megatron-LM/pull/8251)）
- MFSDP v2 明确 delayed weight-gradient synchronization 的 ownership，并仅在所有 delayed gradient 生成后完成 reduction；VocabParallelEmbedding 可将 weight gradient 直接累积到 main_grad，并返回 zero dummy gradient。（[main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854)、[main #8142](https://github.com/NVIDIA/Megatron-LM/pull/8142)）
- MFSDP v2 增加 opt-in unpadded RowAtomic 和 BlockAtomic shard，支持 uneven rank range 与 quantized buffer。（[main #8116](https://github.com/NVIDIA/Megatron-LM/pull/8116)）
- MFSDP v2 checkpoint save 和 restart 现在支持当前及旧版 Transformer Engine path 中的 expert-parallel MoE model。（[main #8230](https://github.com/NVIDIA/Megatron-LM/pull/8230)）

### MFSDP MXFP8 安全性与 CUDA Graph 执行

增强 quantized MFSDP buffer，并防护 full-iteration CUDA Graph execution 中的 synchronization 和 capture-state error。

- MFSDP v2 在 Transformer Engine quantization 前对 MXFP8 scale buffer 进行 padding，并仅拷回 compact local region；FlashInfer MXFP8 refit 直接将 quantized expert 写入 routed weight layout，并释放 canonical expert storage。（[main #8247](https://github.com/NVIDIA/Megatron-LM/pull/8247)、[main #8560](https://github.com/NVIDIA/Megatron-LM/pull/8560)）
- Full-iteration GTP CUDA Graph capture 现在使用 event ordering 和 stream-aware scratch ownership，并在 replay 与 eager execution 前后重置 capture fence。（[main #7780](https://github.com/NVIDIA/Megatron-LM/pull/7780)）
- GTP scratch buffer 现在携带 completion event，并在 checkout 时等待 next writer stream，防止支持的 buffer path 之间发生 cross-stream overwrite。（[main #7927](https://github.com/NVIDIA/Megatron-LM/pull/7927)）
- 在 PyTorch 2.14 及更新版本中，CUDA generator capture state 会在 full-iteration graph capture 开始时预热。（[main #7885](https://github.com/NVIDIA/Megatron-LM/pull/7885)）

### Dynamic inference state、serving 与 recurrent model

改进 disaggregated serving、asynchronous routing、prefix-cache validity、recurrent inference 和 streamed response correctness。

- Dynamic inference 支持端到端的 prefill/decode disaggregation，通过 coordinator routing 以及 NCCL 或 NIXL 在独立 parallelized shard 间传输 KV 和 SSM state，包括带 paired source replica 的 replicated KV-head resharding。（[main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)、[main #8506](https://github.com/NVIDIA/Megatron-LM/pull/8506)）
- Asynchronous inference 会在 scheduling、row compaction、prefix caching、MTP acceptance 和 CUDA-stream transfer 期间保留每次 forward 的 MoE routing metadata。（[main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310)）
- Model refit 后会对 inference request 重新加盐并重新 hash，使新 weight 无法复用前一 weight epoch 的 KV 或 Mamba block。（[main #7891](https://github.com/NVIDIA/Megatron-LM/pull/7891)）
- Expert-parallel dummy MTP forward 在启用 MTP KV cache 时现在通过 inference context 执行，并复用 KV-aware CUDA Graph；batch-invariant Mamba decode 使用 row-specific fused kernel，无需 replayed z buffer。（[main #8040](https://github.com/NVIDIA/Megatron-LM/pull/8040)、[main #8221](https://github.com/NVIDIA/Megatron-LM/pull/8221)）

### Inference lifecycle、recurrent state 与 distributed handoff

强化 dynamic inference lifecycle behavior、pipeline-wide recurrent validation、collective masking、streamed output 和 replicated KV-head transfer。

- Streaming partial response 现在在 request eviction 或 suspension 后使用合并的 checkpoint-record coordinate 处理 token 和 probability；inference lifecycle coverage 还会验证 prefix-cached score、MTP stop boundary、worker failure、batch-invariant scaling 和 disaggregated Mamba-state lifetime。（[main #8150](https://github.com/NVIDIA/Megatron-LM/pull/8150)、[main #8426](https://github.com/NVIDIA/Megatron-LM/pull/8426)）
- Pipeline-parallel inference 现在共享 recurrent-layer presence，并验证 Mamba prefix-cache continuation boundary；当 cached attention block 缺少可用的 Mamba state boundary 时，会重新计算 continuation chunk。（[main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714)、[main #8250](https://github.com/NVIDIA/Megatron-LM/pull/8250)）
- 当 hidden dimension 超过 block width 时，NVLS inference collective kernel 会在 token boundary mask final channel block。（[main #8002](https://github.com/NVIDIA/Megatron-LM/pull/8002)）
- Dynamic inference 会在 published real-token boundary 将 padding row 清零，防止 CUDA Graph replay 期间 stale activation 进入 quantized amax calculation。（[main #8274](https://github.com/NVIDIA/Megatron-LM/pull/8274)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
