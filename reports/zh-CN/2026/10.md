# Megatron-LM 月度活动报告 — 2026年10月（截至2026-10-25）

> 统计周期：2026-10-01 至 2026-10-25（Asia/Shanghai）；源仓库：[`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM)。

## 概览

已交付工作推进了确定性 attention 与 CUDA-graph 执行、MFSDP checkpoint、并行布局、MoE 执行以及动态推理可靠性。持续工作推进模型架构、并行执行、MoE 与推理系统、optimizer 与 checkpoint 可靠性、确定性计算以及自定义 process-group 支持。

- 过滤后的实质性 PR 活动：新开 566；合并 252；关闭未合并 134；截止时仍在进行 469。
- 不计入报告正文和统计：纯 UT 61，纯 CI 40，UT/CI-only 9，纯格式化 0。

## 已交付成果

### DSA、MLA 与确定性 attention kernels

扩展 DSA 与 fused attention 执行，同时改进确定性行为与 masking 正确性。

- 封装确定性 Triton autotuning，并扩展 fused MLA RoPE 边界处理，以选择一致的 kernel 配置并避免 partial-head 越界访问。（[main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076)、[main #6890](https://github.com/NVIDIA/Megatron-LM/pull/6890)）
- 新增 bounded-memory simplified DSA kernels 以及基于 GQA 的 simplified DSA，涵盖 sparse attention、top-k routing、indexer loss 与 validation 路径。（[main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152)、[main #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156)）
- 使 DSv4 支持路径在 compact indexing、sparse attention、indexer gradients 以及 grouped-MLP routing-probability 路径上实现 bit-reproducible。（[dev #7441](https://github.com/NVIDIA/Megatron-LM/pull/7441)、[dev #7706](https://github.com/NVIDIA/Megatron-LM/pull/7706)、[main #8194](https://github.com/NVIDIA/Megatron-LM/pull/8194)）
- 修正 sliding-window attention 的 fused softmax 选择，使 windowed 配置使用 masking-aware 路径，而不是静默应用完整 causal attention。（[main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850)）

### MFSDP v2 checkpoint 与 gradient 执行

改进 MFSDP v2 distributed checkpoint、delayed gradient 处理、quantized buffers 与 checkpoint process-group 隔离。

- 为 MFSDP v2 optimizer state 新增 distributed checkpoint save/load，包括 rank-consistent DTensor keyspaces 与 empty-local-shard placeholders。（[main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215)）
- 明确 delayed weight-gradient synchronization 的所有权，并仅在所有 delayed Transformer Engine gradients 到达后完成 MFSDP reductions。（[main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854)）
- 为 expert-parallel MoE 新增 checkpoint save 与 restart 支持，覆盖当前及旧版 Transformer Engine 路径，包括 optimizer-state 处理与 BF16 weight refresh。（[main #8230](https://github.com/NVIDIA/Megatron-LM/pull/8230)）
- 在量化前填充 MFSDP MXFP8 scale buffers，并仅复制回 compact local regions，防止写入跨越 rank 边界。（[main #8247](https://github.com/NVIDIA/Megatron-LM/pull/8247)）

### Checkpoint 分发与 process-group 安全性

强化 distributed checkpoint 发现以及面向 process-group 的 shard 分发处理。

- 以有序 global ranks 的 SHA-256 digest 为 distributed checkpoint process-group caches 建立键，防止具有相同最小 rank 的不同 groups 共享 shard distributions；在 rank-zero metadata 读取前于每个 rank 解析 MIMO checkpoint directories，避免 checkpoint-completeness synchronization deadlocks。（[main #7941](https://github.com/NVIDIA/Megatron-LM/pull/7941)、[main #8251](https://github.com/NVIDIA/Megatron-LM/pull/8251)）

### 模型架构与并行布局集成

围绕 dynamic context parallelism、GTP rematerialization、MIMO 与 gradient accumulation 扩展模型架构和并行策略。

- 新增 Muon per-head QKV orthogonalization，并在 MHA、GQA、gated attention、heterogeneous attention 与 MLA 间重建 fragmented layouts，包括 TP 大于 query-group count 的情况。（[main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326)、[dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085)）
- 启用标准 dynamic context-parallel training 与 evaluation schedules，支持 caller-owned process groups、packed PP/VPP/MTP data 及 runtime layouts。（[main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047)）
- 在 GTP rematerialization 内新增可配置的 sequence 与 batch partitioning，并提供独立的 weight 和 batch/sequence process-group views。（[main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748)）
- 将 context-parallel batch 与 layout 处理集成到 MIMO，并结合面向 heterogeneous language grids 的 GTP sequence partitions；同时集成 ShortcutMoE，支持 wide residual streams、residual replay、MTP/MIMO composition 与 FP32 residual handling，使成对的 predecessor 和 MoE blocks 使用 ordinary-width views。（[main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440)、[main #7758](https://github.com/NVIDIA/Megatron-LM/pull/7758)）

### GTP 通信与模型梯度优化

改进跨 rank 的 gradient communication，并减少 parallel model paths 中不必要的 gradient materialization。

- 将 completion events 与复用的 GTP weight-gradient scratch buffers 关联，并在 checkout 时等待 next writer stream，防止 cross-stream overwrites。（[main #7927](https://github.com/NVIDIA/Megatron-LM/pull/7927)）
- 允许 vocab-parallel embedding backward 直接将 weight gradients 累积到 main_grad，避免 dense DDP-hook gradients 与不必要的 MTP LM-head dummy work。（[main #8142](https://github.com/NVIDIA/Megatron-LM/pull/8142)）

### MoE expert parallelism 与 recomputation

通过 activation recomputation、virtual experts、更安全的 routing exchange 与 NVFP4 inference 扩展 expert-parallel 执行。

- 以 layer-segment 粒度为 MoE expert-parallel A2A overlap path 实现完整 activation recomputation。（[main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429)）
- 新增 HybridEP virtual expert duplication，支持 symmetric-memory weight 与 gradient arenas、route planning 及 owner-gradient reduction。（[main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450)）
- 以 NCCL all-gather 替换易超时的 HybridEP custom routing all-gather kernel，防止 stale routing maps。（[main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771)）
- 通过 FlashInfer CuTe DSL grouped GEMMs，新增可被 CUDA-graph capture、batch-invariant 的 NVFP4 routed-MoE inference。（[main #8262](https://github.com/NVIDIA/Megatron-LM/pull/8262)）

### 动态推理状态、缓存与 streaming

改进 disaggregated serving、recurrent-state 处理、cache validity 与 streamed response 对齐。

- 新增端到端 prefill/decode disaggregation，通过 coordinator routing 以及 NCCL 或 NIXL，在独立并行化的 shards 之间传输 KV 和 SSM state。（[main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)）
- 在 asynchronous inference scheduling、row compaction、prefix caching、MTP acceptance 与 CUDA-stream transfer 中保留 MoE routing metadata；为 expert-parallel dummy MTP forwards 暂存 draft metadata，并在启用 MTP KV cache 时通过 inference context 执行，复用 KV-aware CUDA graphs，避免使用不受支持的 cache-free attention backend。（[main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310)、[main #8040](https://github.com/NVIDIA/Megatron-LM/pull/8040)）
- 当 attention KV blocks 缺少可用的 Mamba state boundary 时，重新计算 hybrid-inference continuation chunks，使 recurrent state 与 prompt 保持对齐。（[main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714)）
- model refits 后对 unprefilled requests 重新加盐并 re-hash，使 new-weight requests 无法匹配早期 weight epoch 的 KV 或 Mamba blocks。（[main #7891](https://github.com/NVIDIA/Megatron-LM/pull/7891)）

### Inference streaming 与 recurrent decode 正确性

强化 partial outputs 与 pipeline-parallel 执行下的 response streaming 和 recurrent decode。

- 在 request eviction 或 suspension 后，使 streamed token、log-probability 与 top-n probability deltas 与 merged checkpoint-record coordinates 对齐。（[main #8150](https://github.com/NVIDIA/Megatron-LM/pull/8150)）
- 移除 replayed Mamba z buffer，并对 batch-invariant decode 使用 row-specific fused kernels，减少 state storage，并仅计算 consumed rows。（[main #8221](https://github.com/NVIDIA/Megatron-LM/pull/8221)）
- 共享 pipeline-wide recurrent-layer presence，并在各 stages 间一致应用 Mamba prefix-cache validation 与 prompt skipping。（[main #8250](https://github.com/NVIDIA/Megatron-LM/pull/8250)）

### CUDA Graph capture 与 inference memory safety

改进 CUDA-graph RNG capture，并保护 inference collectives 与 quantized replay，避免 stale 或 invalid data。

- 在 PyTorch 2.14 及更高版本的 full-iteration graph capture 开始时预热 CUDA generator capture states，防止 lazy Philox initialization 使 capture 失效。（[main #7885](https://github.com/NVIDIA/Megatron-LM/pull/7885)）
- 当 hidden dimensions 超过 block width 时，针对 token boundaries mask final NVLS inference collective channel blocks。（[main #8002](https://github.com/NVIDIA/Megatron-LM/pull/8002)）
- 在 dynamic-inference padding rows 发布的 real-token boundary 处将其清零，防止 CUDA-graph replay 期间 stale activations 进入 quantized amax calculations。（[main #8274](https://github.com/NVIDIA/Megatron-LM/pull/8274)）

### 确定性与 batch-invariant 计算

Determinism 与 batch-invariant execution 正从 startup policy 扩展到 attention、reductions 与 loss computation。

- Deterministic startup 与 mHC execution 建立一致的 policies 和 ordered reductions，而 batch-invariant tensor-parallel reductions 使用 fixed accumulation behavior。（[main #7419](https://github.com/NVIDIA/Megatron-LM/pull/7419)、[main #7704](https://github.com/NVIDIA/Megatron-LM/pull/7704)、[main #8421](https://github.com/NVIDIA/Megatron-LM/pull/8421)）
- Batch-invariant MoE combine 与 perfect-precision Flash Attention 为 training 和 inference 中支持的 layouts 提供 fixed reduction behavior。（[main #8261](https://github.com/NVIDIA/Megatron-LM/pull/8261)、[main #8405](https://github.com/NVIDIA/Megatron-LM/pull/8405)、[main #8406](https://github.com/NVIDIA/Megatron-LM/pull/8406)）
- Activation-checkpointing state 可通过 exceptions 与 nested calls 恢复，vocabulary-parallel cross entropy 则为 highly confident tokens 保持准确 gradients。（[main #7975](https://github.com/NVIDIA/Megatron-LM/pull/7975)、[main #8477](https://github.com/NVIDIA/Megatron-LM/pull/8477)）

GDN 工作新增 fused backends、recurrent context parallelism、batch-invariant arithmetic 与 deterministic execution controls。

- 内部 CuTe backend 支持 fused GDN forward 与 backward execution，并提供 controlled fallback；chunkwise context parallelism 交换 recurrent boundaries 与 adjoints。（[dev #6511](https://github.com/NVIDIA/Megatron-LM/pull/6511)、[main #7910](https://github.com/NVIDIA/Megatron-LM/pull/7910)）
- Fixed-block arithmetic backend 使 GDN 与 GDP 结果独立于 batch composition 和 prefill boundaries，而 fused GDN preparation 在 variable-length inputs 上保持 deterministic。（[main #7917](https://github.com/NVIDIA/Megatron-LM/pull/7917)、[main #8467](https://github.com/NVIDIA/Megatron-LM/pull/8467)）
- Experimental MLA context parallelism 交换 compressed KV latents，并在每个 ring step 重新计算 projections。（[dev #8182](https://github.com/NVIDIA/Megatron-LM/pull/8182)）

## 口径说明

正文按技术主题组织，而不是按 PR 时间顺序罗列。同一变更的 `dev` / `main` PR 只描述一次；可重建的完整流水账、过滤证据、提交活动和状态事件保存在工作流数据库 artifact 中。关闭未合并的 PR 只计入统计；每个 PR 引用均标明目标分支；open PR 如果本月没有 code 或 state activity，不会沿用到新月报告。
