# Megatron-LM Monthly Activity Report — August 2026 (through August 23, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/08.md)

> Reporting window: 2026-08-01 through 2026-08-23 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work expanded MFSDP and generalized tensor parallelism, added GDP/GDN and disaggregated inference capabilities, and strengthened recomputation, context parallelism, observability, and runtime reliability. Ongoing work advances sparse and hybrid models, distributed training, multimodal and packed-sequence execution, inference performance, checkpointing, and optimizer efficiency.

- Substantive PR activity after filtering: opened 490; merged 260; closed without merge 152; active at cutoff 266.
- Excluded from the report and statistics: test-only 35, CI-only 36, test/CI-only 0, format-only 0.

## Delivered

### MFSDP sharding, optimizers, and checkpoints

MFSDP gained broader sharding and optimizer support alongside correctness improvements for gradients, recomputation, tied weights, offload, and checkpoint restoration.

- MFSDP v2 gained a dedicated FullyShardedOptimizer and adapter, selectable no-shard, ZeRO-1, and ZeRO-2 layouts, and precision-aware optimizer-state and gradient handling for mixed-precision optimizers. ([#5865](https://github.com/NVIDIA/Megatron-LM/pull/5865), [#6137](https://github.com/NVIDIA/Megatron-LM/pull/6137), [#6506](https://github.com/NVIDIA/Megatron-LM/pull/6506))
- Expert-parallel MFSDP v2 now shards expert parameters on the expert-data-parallel mesh and applies the expert gradient divisor, while HFSDP defers DP-outer gradient reduction and handles optimizer-weight refresh and reduced-gradient buffer resets. ([#5956](https://github.com/NVIDIA/Megatron-LM/pull/5956), [#5972](https://github.com/NVIDIA/Megatron-LM/pull/5972), [#6450](https://github.com/NVIDIA/Megatron-LM/pull/6450))
- MFSDP execution phases keep parameters materialized across activation recomputation, alias-aware registration preserves tied parameter identity, and reduce-scatter-stream allocation protects persistent main_grad buffers during asynchronous reduction. ([#6153](https://github.com/NVIDIA/Megatron-LM/pull/6153), [#6164](https://github.com/NVIDIA/Megatron-LM/pull/6164), [#6187](https://github.com/NVIDIA/Megatron-LM/pull/6187))
- Fully reshardable torch_dist optimizer loading now accounts for stripped inter-bucket padding, and DCP helpers round-trip uneven MFSDP v2 DTensor model and optimizer shards with compute-weight resynchronization. ([#5077](https://github.com/NVIDIA/Megatron-LM/pull/5077), [#6024](https://github.com/NVIDIA/Megatron-LM/pull/6024))

### LayerWise Muon and optimizer memory scheduling

Optimizer work reduced update-time memory requirements and improved gradient scheduling and Muon placement for sharded training.

- Distributed Adam and compact LayerWise Muon gained chunked optimizer-state and master-weight offload through pinned CPU canonical storage. ([#6244](https://github.com/NVIDIA/Megatron-LM/pull/6244))
- MFSDP v1 ZeRO-1 and ZeRO-2 received default FSDP unit assignment, scheduled gradient reduce-scatter, and corrected ZeRO-1 fused weight-gradient accumulation. ([#6357](https://github.com/NVIDIA/Megatron-LM/pull/6357))
- LayerWise Muon now balances full-matrix Newton–Schulz work across optimizer shards and supports blockwise, duplicated, and distributed orthogonalization modes for GTP-sharded parameters. ([#6379](https://github.com/NVIDIA/Megatron-LM/pull/6379), [#6380](https://github.com/NVIDIA/Megatron-LM/pull/6380))

### GTP communication and CUDA Graph overlap

Generalized tensor parallelism gained safer communication overlap, buffer ownership, recomputation, MTP integration, evaluation, and checkpoint behavior.

- GTP communication ownership and buffer-lifetime fixes let local CUDA graphs overlap reduce-scatter completion and preserve incoming all-gather prefetch dependencies across graph boundaries. ([#6060](https://github.com/NVIDIA/Megatron-LM/pull/6060), [#6696](https://github.com/NVIDIA/Megatron-LM/pull/6696))
- Distinct and double-buffered gather tickets prevent adjacent or recomputed weights from overwriting in-use buffers, while a DDP readiness callback publishes updated parameter buckets before GTP prefetch consumes them. ([#6207](https://github.com/NVIDIA/Megatron-LM/pull/6207), [#6388](https://github.com/NVIDIA/Megatron-LM/pull/6388), [#6407](https://github.com/NVIDIA/Megatron-LM/pull/6407))
- CUDA graph capture now handles parameters used only during CheckpointWithoutOutput recomputation and records GTP all-gather accesses so DDP parameters are published before replay. ([#6373](https://github.com/NVIDIA/Megatron-LM/pull/6373), [#6525](https://github.com/NVIDIA/Megatron-LM/pull/6525))
- MTP inference now barriers before NVLS all-gathers and slices valid sequence-parallel shards, while GTP supports repeated MTP weight consumption with per-consume gathers and finalized reduce-scatter work. ([#5748](https://github.com/NVIDIA/Megatron-LM/pull/5748), [#6242](https://github.com/NVIDIA/Megatron-LM/pull/6242))

### GTP symmetric memory, evaluation, and checkpointing

GTP rematerialization gained collective-memory optimizations and corrected replica-group semantics for evaluation and distributed checkpoint writing.

- GTP and expert-GTP weight-gradient reduce-scatter send buffers can use process-group symmetric memory pools under independent opt-in flags. ([#6535](https://github.com/NVIDIA/Megatron-LM/pull/6535))
- Evaluation reduction and batch-divisibility checks now include GTP-rematerialization ranks, and checkpoint writer election uses caller-owned replica groups that exclude the rematerialization axis, including expert replica groups. ([#6717](https://github.com/NVIDIA/Megatron-LM/pull/6717), [#6775](https://github.com/NVIDIA/Megatron-LM/pull/6775))

### Gated Delta Product and Gated DeltaNet

GDP became a first-class hybrid-model mixer with optimized in-tree kernels, distributed checkpointing, and graph-captured dynamic inference paths.

- The Gated Delta Product mixer now supports training, static and dynamic inference, tensor and context parallelism, THD packing, checkpoint resharding, optimizer routing, and FLOPs accounting. ([#6074](https://github.com/NVIDIA/Megatron-LM/pull/6074))
- In-tree flash-linear-attention kernels cover GDP chunked and recurrent operations, while optimized paths reduce tensor copies and add CuTeDSL execution, selective projection recomputation, QKV offloading, and shared training and inference helpers. ([#6538](https://github.com/NVIDIA/Megatron-LM/pull/6538), [#6553](https://github.com/NVIDIA/Megatron-LM/pull/6553))
- Dynamic inference now supports Gated DeltaNet prefill and single-token decode, GDP CUDA graphs, and GDP chunked prefill with recurrent convolution-state carry. ([#6499](https://github.com/NVIDIA/Megatron-LM/pull/6499), [#6595](https://github.com/NVIDIA/Megatron-LM/pull/6595), [#6711](https://github.com/NVIDIA/Megatron-LM/pull/6711))
- GDP input-projection shards are gathered and unpadded before distributed-checkpoint splitting, then repadded and resliced during restoration. ([#6503](https://github.com/NVIDIA/Megatron-LM/pull/6503))

### Batch-invariant and disaggregated hybrid inference

Inference work added batch-invariant MoE and SSM execution, cache-aware request admission, and KV-cache and hybrid-state handoff between engines.

- Batch-invariant execution now spans Nemotron MoE and Mamba operations and supports the vLLM Triton fused-MoE backend, gated SwiGLU, aligned CUDA-graph buckets, and native Transformer Engine GEMM mode. ([#4871](https://github.com/NVIDIA/Megatron-LM/pull/4871), [#6521](https://github.com/NVIDIA/Megatron-LM/pull/6521))
- LRU-aware admission separates resumed-request allocation from active-buffer demand, while disaggregated inference can transfer prefetched KV-cache state through NIXL or NCCL with block ownership, prefix reuse, and failure synchronization. ([#5995](https://github.com/NVIDIA/Megatron-LM/pull/5995), [#6222](https://github.com/NVIDIA/Megatron-LM/pull/6222))
- Disaggregated hybrid inference can transfer Mamba-family state alongside attention state, and refit hooks refresh Mamba’s weight-derived decode cache after model weights are replaced. ([#6584](https://github.com/NVIDIA/Megatron-LM/pull/6584), [#6672](https://github.com/NVIDIA/Megatron-LM/pull/6672))

### mHC and activation recomputation

Manifold Hyper-Connection support was completed and hardened for fused precision, CUDA graphs, expert-parallel overlap, and aliased checkpoint storage.

- The core PyTorch mHC module now integrates with transformer layers and recomputation, while fused cuTile paths use FP32 mapping computation and backward reductions with BF16 activations. ([#4531](https://github.com/NVIDIA/Megatron-LM/pull/4531), [#6172](https://github.com/NVIDIA/Megatron-LM/pull/6172))

([#4497](https://github.com/NVIDIA/Megatron-LM/pull/4497), [#5869](https://github.com/NVIDIA/Megatron-LM/pull/5869))

### Context parallelism, THD, and expert data movement

Context-parallel execution was extended across RL, hybrid layouts, packed attention, sample routing, CSA alignment, and expert dispatch formats.

- NCCL expert-parallel dispatch and combine-backward operations can use configured BF16 or MXFP8 tensor formats through Transformer Engine. ([#6524](https://github.com/NVIDIA/Megatron-LM/pull/6524))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Open PRs do not carry into a new month without code or state activity in that month.
