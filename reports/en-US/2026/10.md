# Megatron-LM Monthly Activity Report — October 2026 (through October 4, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/10.md)

> Reporting window: 2026-10-01 through 2026-10-04 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work expanded model and parallel-training capabilities, improved checkpoint and configuration compatibility, and strengthened recurrent-state and inference reliability. Ongoing work advances hybrid and context-parallel training, DSA and multimodal model capabilities, distributed checkpointing, deterministic execution, and inference performance and reliability.

- Substantive PR activity after filtering: opened 86; merged 23; closed without merge 16; active at cutoff 164.
- Excluded from the report and statistics: test-only 12, CI-only 3, test/CI-only 2, format-only 0.

## Delivered

### Wide residual streams and model compatibility

Extended wide-residual execution across auxiliary architectures and updated model checkpoint and construction paths for hybrid inference.

- Wide residual streams now compose with MTP and MIMO while keeping auxiliary and modality paths at their ordinary widths; ShortcutMoE also supports residual replay, MTP/MIMO composition, and FP32 residual handling. ([main #6855](https://github.com/NVIDIA/Megatron-LM/pull/6855), [main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440))
- LLaVA can construct the required hybrid model, and Nemotron checkpoint and inference paths support updated mappings, hybrid blocks, wide residuals, and inference wrappers. ([main #7752](https://github.com/NVIDIA/Megatron-LM/pull/7752), [main #7799](https://github.com/NVIDIA/Megatron-LM/pull/7799))

### MFSDP and DBuffer parallel layouts

Added multi-axis and TensorAtomic layout support for distributed optimizer shards and uneven collective communication.

- DBuffer views and all-gathers support transitions across multiple placement axes, including hybrid ZeRO layouts, without requiring new process groups. ([main #7633](https://github.com/NVIDIA/Megatron-LM/pull/7633))
- DBuffer supports one-dimensional TensorAtomic placement with list-based all-gather and reduce-scatter for uneven rank segments, including ranks with no owned tensors. ([main #7671](https://github.com/NVIDIA/Megatron-LM/pull/7671))
- MFSDP fully_shard constructs TensorAtomic layouts from parameter-owner assignments while preserving parameter ordering and tied-parameter support. ([main #7672](https://github.com/NVIDIA/Megatron-LM/pull/7672))

### MoE routing and optimizer updates

Improved routing metadata handling, per-head Muon updates, and replicated-parameter accounting.

- Flex dispatchers consume Transformer Engine dense top-k routing indices when available while retaining boolean-map compatibility and existing padding, expert-TP, and bias-count handling. ([main #6615](https://github.com/NVIDIA/Megatron-LM/pull/6615))
- Muon supports optional per-head QKV orthogonalization and tensor-parallel-fragmented QKV reconstruction for attention and MLA layouts. ([dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085))
- Gradient norm and zero-count filtering uses the optimizer process-group collection for GTP ownership, with the MPU global as a fallback. ([main #7359](https://github.com/NVIDIA/Megatron-LM/pull/7359))

### Mamba cached continuation state

Corrected recurrent-state handling for hybrid inference and partial-prefill snapshots.

- Hybrid inference recomputes continuation chunks when matching attention KV blocks lack a usable Mamba state boundary, preventing cached prefixes from skipping recurrent transitions. ([main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714))
- Mamba snapshot extraction uses the scan’s actual chunk indices so partial-prefill snapshots align with their advertised token boundaries. ([main #7755](https://github.com/NVIDIA/Megatron-LM/pull/7755))

### Training and quantization configuration persistence

Structured reinforcement-learning settings and added serialization support for callable model and quantization configuration values.

- Training configuration now provides a dedicated RLConfig section with argument, serialization, and validation support. ([main #7430](https://github.com/NVIDIA/Megatron-LM/pull/7430))
- Callable model-configuration fields can be serialized and restored through model configuration and YAML argument paths. ([main #7571](https://github.com/NVIDIA/Megatron-LM/pull/7571))
- Quantization RecipeConfig can be converted to dictionaries for saving and restoration through dictionaries or YAML configuration. ([main #7590](https://github.com/NVIDIA/Megatron-LM/pull/7590))

### Checkpoint conversion and dependency compatibility

Improved hybrid checkpoint conversion and aligned the Transformer Engine dependency stack with deterministic expert-parallel settings.

- Torch-dist to FSDP-DTensor conversion reads embedded common state, avoids opaque common-state materialization, and merges fused Gated DeltaProduct projection keys. ([main #7674](https://github.com/NVIDIA/Megatron-LM/pull/7674))
- Transformer Engine was advanced to the release 2.20 tip with updated cuDNN Frontend, CUTLASS DSL, Quack, and deterministic NCCL expert-token settings. ([main #7683](https://github.com/NVIDIA/Megatron-LM/pull/7683))

### Multimodal and chat inference compatibility

Removed restrictive media handling and corrected response, tool-call, and vision-input edge cases in inference interfaces.

- The multimodal inference server now relies on the server-wide maximum for image and video size instead of an endpoint-specific byte limit. ([main #7702](https://github.com/NVIDIA/Megatron-LM/pull/7702))
- Reasoning-aware non-streaming chat responses preserve empty reasoning metadata and return null content when no final answer or tool call exists. ([main #7749](https://github.com/NVIDIA/Megatron-LM/pull/7749))
- Qwen3-Coder tool function names are normalized before schema lookup and response construction, avoiding invalid calls for empty normalized names. ([main #7753](https://github.com/NVIDIA/Megatron-LM/pull/7753))
- RADIO temporal grouping handles host-list image sizes using length-based inspection alongside tensor image sizes. ([main #7760](https://github.com/NVIDIA/Megatron-LM/pull/7760))

## In Progress

### Hybrid EP overlap, MFSDP, and distributed lifecycle

Hybrid expert-parallel overlap and MFSDP execution are being extended across recomputation, CUDA graphs, expert balancing, repeated modules, partial graphs, and delayed synchronization.

- HybridStack grouped scheduling and FSDP unit selection were refined for expert-parallel overlap, with layer-segment recomputation and safer CUDA-graph capture behavior. ([main #4942](https://github.com/NVIDIA/Megatron-LM/pull/4942), [main #4943](https://github.com/NVIDIA/Megatron-LM/pull/4943), [main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429), [main #6958](https://github.com/NVIDIA/Megatron-LM/pull/6958))
- HybridEP routing and expert balancing were hardened, while model-parallel teardown clears communicators and buffers across repeated initialization cycles. ([main #7029](https://github.com/NVIDIA/Megatron-LM/pull/7029), [main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450), [main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771))
- MFSDP v2 now handles repeated and shared modules, ShortcutMoE ownership and prefetch order, unused parameters, forward-graph gradient countdowns, frozen-weight guards, checkpoint child replay, and delayed gradient synchronization. ([main #7750](https://github.com/NVIDIA/Megatron-LM/pull/7750), [main #7757](https://github.com/NVIDIA/Megatron-LM/pull/7757), [main #7781](https://github.com/NVIDIA/Megatron-LM/pull/7781), [main #7783](https://github.com/NVIDIA/Megatron-LM/pull/7783), [main #7809](https://github.com/NVIDIA/Megatron-LM/pull/7809), [pull-request/7822 #7815](https://github.com/NVIDIA/Megatron-LM/pull/7815), [main #7822](https://github.com/NVIDIA/Megatron-LM/pull/7822), [pull-request/7757 #7836](https://github.com/NVIDIA/Megatron-LM/pull/7836), [main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854))

### Runtime context parallelism and GTP layouts

Explicit process-group propagation and runtime context-parallel metadata now support more independent model grids and contiguous attention layouts.

- Attention, model, inference, multimodal, MTP, and scheduler paths now use explicit process-group collections, with validation in LanguageModule constructors. ([main #6293](https://github.com/NVIDIA/Megatron-LM/pull/6293), [main #6303](https://github.com/NVIDIA/Megatron-LM/pull/6303))
- Dynamic context parallelism now operates through standard schedules and propagates per-microbatch geometry, groups, valid-token counts, and auxiliary-loss metadata through hybrid model layers. ([main #7046](https://github.com/NVIDIA/Megatron-LM/pull/7046), [main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047), [main #7048](https://github.com/NVIDIA/Megatron-LM/pull/7048))
- GTP can separate weight-ownership and token-processing groups, while softmax attention gains contiguous context-parallel support across packed-sequence and MTP paths. ([main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748), [main #7834](https://github.com/NVIDIA/Megatron-LM/pull/7834))

### DSA sparse attention and indexer training

Simplified DSA development covers bounded-memory kernels, sparse GQA, staged indexer training, deterministic execution, and context-parallel support.

- Triton and autograd kernels provide bounded-memory simplified DSA indexing, sparse GQA scoring, top-k routing, and associated gradients, with HybridModel integration for learned sparse attention. ([main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152), [pull-request/7152 #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156))
- The training loop supports staged DSA indexer freezing, initialization, optimizer-state handling, and split gradient logging. ([pull-request/7158 #7181](https://github.com/NVIDIA/Megatron-LM/pull/7181))
- DSv4 gained deterministic sparse-attention backward dispatch and stable top-k behavior, while simplified DSA GQA now gathers keys and values across context-parallel layouts. ([main #7708](https://github.com/NVIDIA/Megatron-LM/pull/7708), [pull-request/7158 #7766](https://github.com/NVIDIA/Megatron-LM/pull/7766))

### Hybrid model architectures and multimodal training

Model coverage expands with new hybrid attention components, mHC pipeline support, dual-mode audio encoding, and a DeepSeek multimodal SFT path.

- HybridModel adds Kimi Delta Attention with gated projections, packed-sequence context parallelism, and optional BF16 execution, while the audio encoder supports offline, causal, and mixed-mode packed attention with RoPE. ([main #7054](https://github.com/NVIDIA/Megatron-LM/pull/7054), [main #7066](https://github.com/NVIDIA/Megatron-LM/pull/7066))
- Pipeline and virtual-pipeline schedules now carry mHC-expanded residual widths through P2P buffers and intermediate stages. ([main #7336](https://github.com/NVIDIA/Megatron-LM/pull/7336))
- DeepSeek-V4-Flash-Vision support adds the model, image/text preparation, hybrid decoder integration, and a real-data supervised fine-tuning recipe. ([dev #7808](https://github.com/NVIDIA/Megatron-LM/pull/7808))

### Checkpoint interoperability and training-state ownership

Checkpoint and state-management work improves grouped-model interoperability, cross-layer tensor transport, optimizer restoration, and inference initialization.

- Existing GPT checkpoints can initialize grouped HybridModel layers, including optimizer and FSDP loading paths, while cross-layer tensor state can move through checkpointing, CUDA graphs, pipeline schedules, and parallel redistributions. ([main #7192](https://github.com/NVIDIA/Megatron-LM/pull/7192), [main #7678](https://github.com/NVIDIA/Megatron-LM/pull/7678))
- Hybrid optimizer step counters and distributed optimizer parameter indices are preserved across updates and mixed-dtype checkpoint reads and writes. ([main #7785](https://github.com/NVIDIA/Megatron-LM/pull/7785), [main #7804](https://github.com/NVIDIA/Megatron-LM/pull/7804))
- Inference runtime setup and checkpoint loading are separated from training-state, optimizer, scheduler, and batch-progress restoration. ([main #7792](https://github.com/NVIDIA/Megatron-LM/pull/7792))

### Deterministic CUDA kernels and large-offset safety

Determinism and fused-kernel reliability work adds early policy setup, pinned autotuning, and safer indexing and synchronization for MLA RoPE paths.

- Deterministic policy initialization now occurs before Core GPU imports, and Triton autotuning can pin in-tree configurations while preserving graph and shared-resource cleanup. ([main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076), [main #7419](https://github.com/NVIDIA/Megatron-LM/pull/7419))
- Fused MLA RoPE paths now account for partial head blocks and use 64-bit row, head, and channel offsets for large inputs. ([main #7770](https://github.com/NVIDIA/Megatron-LM/pull/7770), [dev #7787](https://github.com/NVIDIA/Megatron-LM/pull/7787))
- In-place MLA and DSA RoPE kernels add synchronization before permuting stores to avoid races between outstanding loads and warp writes. ([dev #7789](https://github.com/NVIDIA/Megatron-LM/pull/7789))

### CUDA-graph and inference-kernel execution

Inference work adds Nemotron graph execution, training-forward reuse of inference MoE kernels, reproducible request sampling, and correct sliding-window dispatch.

- Nemotron 4 text models can use local CUDA-graph inference with GDP, Shortcut MoE, wide residuals, graph-safe decode padding, and checkpoint expert-bias restoration. ([main #7772](https://github.com/NVIDIA/Megatron-LM/pull/7772))
- Supported MoE training forwards can use inference expert kernels through the FlashInfer or inference-kernel paths, including BF16 and MXFP8 preparation. ([main #7798](https://github.com/NVIDIA/Megatron-LM/pull/7798), [main #7830](https://github.com/NVIDIA/Megatron-LM/pull/7830))
- Dynamic Torch sampling supports request-local seeds whose draws are independent of batching and reordering, while sliding-window attention is routed to masking-capable softmax implementations. ([main #7828](https://github.com/NVIDIA/Megatron-LM/pull/7828), [main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Each PR citation identifies its target branch. Open PRs do not carry into a new month without code or state activity in that month.
