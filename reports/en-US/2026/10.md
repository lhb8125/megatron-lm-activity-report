# Megatron-LM Monthly Activity Report — October 2026 (through October 25, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/10.md)

> Reporting window: 2026-10-01 through 2026-10-25 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work advanced deterministic attention and CUDA-graph execution, MFSDP checkpointing, parallel layouts, MoE execution, and dynamic inference reliability. Ongoing work advances model architectures, parallel execution, MoE and inference systems, optimizer and checkpoint reliability, deterministic computation, and custom process-group support.

- Substantive PR activity after filtering: opened 566; merged 252; closed without merge 134; active at cutoff 469.
- Excluded from the report and statistics: test-only 61, CI-only 40, test/CI-only 9, format-only 0.

## Delivered

### DSA, MLA, and deterministic attention kernels

Expanded DSA and fused attention execution while improving deterministic behavior and masking correctness.

- Packaged deterministic Triton autotuning and extended fused MLA RoPE bounds handling to select consistent kernel configurations and avoid partial-head out-of-bounds accesses. ([main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076), [main #6890](https://github.com/NVIDIA/Megatron-LM/pull/6890))
- Added bounded-memory simplified DSA kernels and simplified DSA over GQA, including sparse attention, top-k routing, indexer loss, and validation paths. ([main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152), [main #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156))
- Made DSv4 supported paths bit-reproducible across compact indexing, sparse attention, indexer gradients, and grouped-MLP routing-probability paths. ([dev #7441](https://github.com/NVIDIA/Megatron-LM/pull/7441), [dev #7706](https://github.com/NVIDIA/Megatron-LM/pull/7706), [main #8194](https://github.com/NVIDIA/Megatron-LM/pull/8194))
- Corrected fused softmax selection for sliding-window attention so windowed configurations use the masking-aware path instead of silently applying full causal attention. ([main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850))

### MFSDP v2 checkpointing and gradient execution

Improved MFSDP v2 distributed checkpointing, delayed gradient handling, quantized buffers, and checkpoint process-group isolation.

- Added distributed checkpoint save and load for MFSDP v2 optimizer state, including rank-consistent DTensor keyspaces and empty-local-shard placeholders. ([main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215))
- Made delayed weight-gradient synchronization ownership explicit and completed MFSDP reductions only after all delayed Transformer Engine gradients arrive. ([main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854))
- Added expert-parallel MoE checkpoint save and restart support across current and older Transformer Engine paths, including optimizer-state handling and BF16 weight refresh. ([main #8230](https://github.com/NVIDIA/Megatron-LM/pull/8230))
- Padded MFSDP MXFP8 scale buffers before quantization and copied back only compact local regions to prevent writes across rank boundaries. ([main #8247](https://github.com/NVIDIA/Megatron-LM/pull/8247))

### Checkpoint distribution and process-group safety

Hardened distributed checkpoint discovery and process-group-specific shard distribution handling.

- Keyed distributed checkpoint process-group caches by a SHA-256 digest of ordered global ranks, preventing distinct groups with the same minimum rank from sharing shard distributions; resolved MIMO checkpoint directories on every rank before rank-zero metadata reads to avoid checkpoint-completeness synchronization deadlocks. ([main #7941](https://github.com/NVIDIA/Megatron-LM/pull/7941), [main #8251](https://github.com/NVIDIA/Megatron-LM/pull/8251))

### Model architecture and parallel-layout integration

Extended model architectures and parallel strategies across dynamic context parallelism, GTP rematerialization, MIMO, and gradient accumulation.

- Added Muon per-head QKV orthogonalization and reconstructed fragmented layouts across MHA, GQA, gated attention, heterogeneous attention, and MLA, including TP greater than the query-group count. ([main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326), [dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085))
- Enabled standard dynamic context-parallel training and evaluation schedules with caller-owned process groups, packed PP/VPP/MTP data, and runtime layouts. ([main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047))
- Added configurable sequence and batch partitioning inside GTP rematerialization with separate weight and batch/sequence process-group views. ([main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748))
- Integrated context-parallel batch and layout handling into MIMO alongside GTP sequence partitions for heterogeneous language grids, and integrated ShortcutMoE with wide residual streams, residual replay, MTP/MIMO composition, and FP32 residual handling so paired predecessor and MoE blocks use ordinary-width views. ([main #7440](https://github.com/NVIDIA/Megatron-LM/pull/7440), [main #7758](https://github.com/NVIDIA/Megatron-LM/pull/7758))

### GTP communication and model-gradient optimization

Improved cross-rank gradient communication and reduced unnecessary gradient materialization in parallel model paths.

- Associated completion events with recycled GTP weight-gradient scratch buffers and waited on the next writer stream at checkout to prevent cross-stream overwrites. ([main #7927](https://github.com/NVIDIA/Megatron-LM/pull/7927))
- Allowed vocab-parallel embedding backward to accumulate weight gradients directly into main_grad, avoiding dense DDP-hook gradients and unnecessary MTP LM-head dummy work. ([main #8142](https://github.com/NVIDIA/Megatron-LM/pull/8142))

### MoE expert parallelism and recomputation

Expanded expert-parallel execution with activation recomputation, virtual experts, safer routing exchange, and NVFP4 inference.

- Implemented full activation recomputation for the MoE expert-parallel A2A overlap path at layer-segment granularity. ([main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429))
- Added HybridEP virtual expert duplication with symmetric-memory weight and gradient arenas, route planning, and owner-gradient reduction. ([main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450))
- Replaced the timeout-prone HybridEP custom routing all-gather kernel with NCCL all-gather to prevent stale routing maps. ([main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771))
- Added CUDA-graph-capturable, batch-invariant NVFP4 routed-MoE inference through FlashInfer CuTe DSL grouped GEMMs. ([main #8262](https://github.com/NVIDIA/Megatron-LM/pull/8262))

### Dynamic inference state, caching, and streaming

Improved disaggregated serving, recurrent-state handling, cache validity, and streamed response alignment.

- Added end-to-end prefill/decode disaggregation with coordinator routing and NCCL or NIXL transfer of KV and SSM state between independently parallelized shards. ([main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675))
- Preserved MoE routing metadata through asynchronous inference scheduling, row compaction, prefix caching, MTP acceptance, and CUDA-stream transfer; staged draft metadata for expert-parallel dummy MTP forwards and ran them through the inference context when the MTP KV cache was enabled, reusing KV-aware CUDA graphs and avoiding an unsupported cache-free attention backend. ([main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310), [main #8040](https://github.com/NVIDIA/Megatron-LM/pull/8040))
- Recomputed hybrid-inference continuation chunks when attention KV blocks lacked a usable Mamba state boundary, keeping recurrent state aligned with the prompt. ([main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714))
- Re-salted and re-hashed unprefilled requests after model refits so new-weight requests cannot match KV or Mamba blocks from an earlier weight epoch. ([main #7891](https://github.com/NVIDIA/Megatron-LM/pull/7891))

### Inference streaming and recurrent decode correctness

Hardened response streaming and recurrent decode across partial outputs and pipeline-parallel execution.

- Aligned streamed token, log-probability, and top-n probability deltas with merged checkpoint-record coordinates after request eviction or suspension. ([main #8150](https://github.com/NVIDIA/Megatron-LM/pull/8150))
- Removed the replayed Mamba z buffer and used row-specific fused kernels for batch-invariant decode to reduce state storage and compute only consumed rows. ([main #8221](https://github.com/NVIDIA/Megatron-LM/pull/8221))
- Shared pipeline-wide recurrent-layer presence and applied consistent Mamba prefix-cache validation and prompt skipping across stages. ([main #8250](https://github.com/NVIDIA/Megatron-LM/pull/8250))

### CUDA Graph capture and inference memory safety

Improved CUDA-graph RNG capture and protected inference collectives and quantized replay from stale or invalid data.

- Primed CUDA generator capture states at the beginning of full-iteration graph capture on PyTorch 2.14 and newer to prevent lazy Philox initialization from invalidating capture. ([main #7885](https://github.com/NVIDIA/Megatron-LM/pull/7885))
- Masked final NVLS inference collective channel blocks against token boundaries when hidden dimensions exceed a block width. ([main #8002](https://github.com/NVIDIA/Megatron-LM/pull/8002))
- Zeroed dynamic-inference padding rows at their published real-token boundary to prevent stale activations from entering quantized amax calculations during CUDA-graph replay. ([main #8274](https://github.com/NVIDIA/Megatron-LM/pull/8274))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Each PR citation identifies its target branch. Open PRs do not carry into a new month without code or state activity in that month.
