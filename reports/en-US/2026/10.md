# Megatron-LM Monthly Activity Report — October 2026 (Final, through October 31, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/10.md)

> Reporting window: 2026-10-01 through 2026-10-31 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work advanced distributed training, attention and MoE execution, MFSDP checkpointing, CUDA Graph reliability, and dynamic inference serving across new model and hardware configurations. Ongoing work spans independent process-grid support, sharded training and checkpointing, CUDA Graph execution, MoE and attention kernels, hybrid model integrations, and inference reliability.

- Substantive PR activity after filtering: opened 841; merged 320; closed without merge 168; active at cutoff 675.
- Excluded from the report and statistics: test-only 79, CI-only 51, test/CI-only 13, format-only 0.

## Delivered

### DSA, MLA, and attention kernel correctness

Expanded DSA and attention support while improving deterministic execution, masking, and fused-kernel safety.

- Muon now supports per-head QKV orthogonalization and logical QKV layouts across MHA, GQA, gated attention, MLA, and fragmented tensor-parallel weights. ([main #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326), [dev #7085](https://github.com/NVIDIA/Megatron-LM/pull/7085))
- Fused MLA RoPE head bounds now use absolute indices for every launched block, preventing partial-block accesses into neighboring token rows. ([main #6890](https://github.com/NVIDIA/Megatron-LM/pull/6890))
- DSA sparse-attention backward now handles empty top-k query rows with static safe inputs and explicitly zeroed query gradients. ([main #6939](https://github.com/NVIDIA/Megatron-LM/pull/6939), [dev #7434](https://github.com/NVIDIA/Megatron-LM/pull/7434))
- Simplified DSA adds bounded-memory Triton and autograd kernels for indexer scoring, top-k routing, sparse GQA attention, and their gradients. ([main #7152](https://github.com/NVIDIA/Megatron-LM/pull/7152))

### DSA GQA and deterministic attention execution

Added hybrid DSA attention paths and tightened determinism and masking behavior for fused attention implementations.

- Hybrid models now include simplified DSA GQA attention with learned top-k indexing, sparse attention, reference paths, indexer loss, and configurable dense fallback. ([main #7156](https://github.com/NVIDIA/Megatron-LM/pull/7156))
- DSv4 deterministic mode canonicalizes compact top-k order, uses deterministic sparse-attention and indexer reductions, and rejects unsupported nondeterministic router auxiliary loss. ([dev #7441](https://github.com/NVIDIA/Megatron-LM/pull/7441), [dev #7706](https://github.com/NVIDIA/Megatron-LM/pull/7706), [main #8194](https://github.com/NVIDIA/Megatron-LM/pull/8194))
- Sliding-window attention now uses the masking-aware PyTorch softmax path instead of Apex fused kernels that could silently apply full causal attention. ([main #7850](https://github.com/NVIDIA/Megatron-LM/pull/7850))
- A packaged Triton autotune policy pins covered in-tree kernel configurations under deterministic mode so ranks select consistent configurations. ([main #6076](https://github.com/NVIDIA/Megatron-LM/pull/6076))

### MoE expert parallelism and routing

Improved expert-parallel dispatch, recomputation, virtual experts, routing exchange, and batch-invariant MoE execution.

- Inference MoE models can use NVLS-based expert tensor-parallel dispatch with expert groups propagated through routing and determinism coverage. ([main #4743](https://github.com/NVIDIA/Megatron-LM/pull/4743))
- Full activation recomputation is supported for the MoE expert-parallel A2A overlap path at layer-segment granularity. ([main #6429](https://github.com/NVIDIA/Megatron-LM/pull/6429))
- HybridEP adds MoonEP-style virtual expert duplication with symmetric-memory weight and gradient arenas, route planning, and owner-gradient reduction. ([main #7450](https://github.com/NVIDIA/Megatron-LM/pull/7450))
- HybridEP routing now uses NCCL all-gather instead of the timeout-prone custom all-gather kernel. ([main #7771](https://github.com/NVIDIA/Megatron-LM/pull/7771))

### MoK and batch-invariant MoE inference

Added a MCore-owned MoK backend and optimized routed-expert inference and unpermutation paths.

- Megatron adds the Mixture-of-Kittens MoE backend with MCore-owned routing, parameters, optimizer state, DDP hooks, checkpoints, and support for routed and gated shared experts. ([main #8210](https://github.com/NVIDIA/Megatron-LM/pull/8210))
- The default batch-invariant MoE unpermute path now uses a fused Triton combine kernel when probabilities are not required; FlashInfer supports batch-invariant NVFP4 routed-MoE inference for squared-ReLU and SwiGLU experts. ([main #8262](https://github.com/NVIDIA/Megatron-LM/pull/8262), [main #8559](https://github.com/NVIDIA/Megatron-LM/pull/8559))

### Hybrid architectures and parallel strategies

Extended hybrid models with dynamic context parallelism, KDA, wide residual streams, and sequence-partitioned execution.

- Dynamic context parallelism now uses standard training and evaluation schedules with caller-owned process groups, packed PP/VPP/MTP data, and runtime CP layouts. ([main #7047](https://github.com/NVIDIA/Megatron-LM/pull/7047))
- Kimi Delta Attention hybrid layers add GLM-style two-stage low-rank gates, packed and context-parallel execution, and configurable BF16 or FP8 projections. - GTP_remat supports configurable sequence and batch partitioning with separate weight and batch/sequence process-group views, integrated with context parallelism. ([main #7748](https://github.com/NVIDIA/Megatron-LM/pull/7748))

### MIMO context parallelism and checkpoint reliability

Connected MIMO context-parallel layouts with checkpoint-safe execution and heterogeneous language grids.

- MIMO now integrates context-parallel batch and layout handling with GTP sequence partitions while keeping embeddings, positions, labels, and masks aligned. ([main #7758](https://github.com/NVIDIA/Megatron-LM/pull/7758))
- MIMO checkpoint directory resolution now occurs on every rank before rank-zero metadata reads, preventing checkpoint-completeness deadlocks. ([main #7941](https://github.com/NVIDIA/Megatron-LM/pull/7941))

### MFSDP v2 sharding, checkpointing, and gradient synchronization

Expanded MFSDP v2 checkpoint support, shard layouts, expert-parallel restart, delayed reductions, and MXFP8 safety.

- MFSDP v2 optimizer state now supports DCP save and load in the shared FSDP DTensor format, including empty-local-shard placeholders; distributed checkpoint process-group caches are keyed by a digest of ordered global ranks to isolate shard distributions. ([main #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215), [main #8251](https://github.com/NVIDIA/Megatron-LM/pull/8251))
- MFSDP v2 makes delayed weight-gradient synchronization ownership explicit and completes reductions only after all delayed gradients are produced; VocabParallelEmbedding can accumulate weight gradients directly into main_grad and return a zero dummy gradient. ([main #7854](https://github.com/NVIDIA/Megatron-LM/pull/7854), [main #8142](https://github.com/NVIDIA/Megatron-LM/pull/8142))
- MFSDP v2 adds opt-in unpadded RowAtomic and BlockAtomic shards with uneven rank ranges and quantized-buffer support. ([main #8116](https://github.com/NVIDIA/Megatron-LM/pull/8116))
- MFSDP v2 checkpoint save and restart now support expert-parallel MoE models across current and older Transformer Engine paths. ([main #8230](https://github.com/NVIDIA/Megatron-LM/pull/8230))

### MFSDP MXFP8 safety and CUDA Graph execution

Hardened quantized MFSDP buffers and full-iteration CUDA Graph execution against synchronization and capture-state errors.

- MFSDP v2 pads MXFP8 scale buffers before Transformer Engine quantization and copies back only the compact local region; FlashInfer MXFP8 refit writes quantized experts directly into the routed weight layout and releases canonical expert storage. ([main #8247](https://github.com/NVIDIA/Megatron-LM/pull/8247), [main #8560](https://github.com/NVIDIA/Megatron-LM/pull/8560))
- Full-iteration GTP CUDA Graph capture now uses event ordering and stream-aware scratch ownership, with capture fences reset around replay and eager execution. ([main #7780](https://github.com/NVIDIA/Megatron-LM/pull/7780))
- GTP scratch buffers now carry completion events and wait on the next writer stream at checkout, preventing cross-stream overwrites across supported buffer paths. ([main #7927](https://github.com/NVIDIA/Megatron-LM/pull/7927))
- CUDA generator capture states are primed at the beginning of full-iteration graph capture on PyTorch 2.14 and newer. ([main #7885](https://github.com/NVIDIA/Megatron-LM/pull/7885))

### Dynamic inference state, serving, and recurrent models

Improved disaggregated serving, asynchronous routing, prefix-cache validity, recurrent inference, and streamed response correctness.

- Dynamic inference supports end-to-end prefill/decode disaggregation with coordinator routing and NCCL or NIXL transfer of KV and SSM state between independently parallelized shards, including replicated KV-head resharding with paired source replicas. ([main #6675](https://github.com/NVIDIA/Megatron-LM/pull/6675), [main #8506](https://github.com/NVIDIA/Megatron-LM/pull/8506))
- Asynchronous inference preserves each forward’s MoE routing metadata through scheduling, row compaction, prefix caching, MTP acceptance, and CUDA-stream transfer. ([main #7310](https://github.com/NVIDIA/Megatron-LM/pull/7310))
- Inference requests are re-salted and re-hashed after a model refit so new weights cannot reuse KV or Mamba blocks from the previous weight epoch. ([main #7891](https://github.com/NVIDIA/Megatron-LM/pull/7891))
- Expert-parallel dummy MTP forwards now run through the inference context when the MTP KV cache is enabled, reusing KV-aware CUDA Graphs; batch-invariant Mamba decode uses row-specific fused kernels without a replayed z buffer. ([main #8040](https://github.com/NVIDIA/Megatron-LM/pull/8040), [main #8221](https://github.com/NVIDIA/Megatron-LM/pull/8221))

### Inference lifecycle, recurrent state, and distributed handoff

Strengthened dynamic inference lifecycle behavior, pipeline-wide recurrent validation, collective masking, streamed output, and replicated KV-head transfer.

- Streaming partial responses now use merged checkpoint-record coordinates for tokens and probabilities after request eviction or suspension; inference lifecycle coverage also validates prefix-cached scores, MTP stop boundaries, worker failures, batch-invariant scaling, and disaggregated Mamba-state lifetime. ([main #8150](https://github.com/NVIDIA/Megatron-LM/pull/8150), [main #8426](https://github.com/NVIDIA/Megatron-LM/pull/8426))
- Pipeline-parallel inference now shares recurrent-layer presence and validates Mamba prefix-cache continuation boundaries, recomputing continuation chunks when cached attention blocks lack a usable Mamba state boundary. ([main #7714](https://github.com/NVIDIA/Megatron-LM/pull/7714), [main #8250](https://github.com/NVIDIA/Megatron-LM/pull/8250))
- NVLS inference collective kernels mask final channel blocks at token boundaries when hidden dimensions exceed a block width. ([main #8002](https://github.com/NVIDIA/Megatron-LM/pull/8002))
- Dynamic inference zeroes padding rows at the published real-token boundary to prevent stale activations from entering quantized amax calculations during CUDA Graph replay. ([main #8274](https://github.com/NVIDIA/Megatron-LM/pull/8274))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Each PR citation identifies its target branch. Open PRs do not carry into a new month without code or state activity in that month.
