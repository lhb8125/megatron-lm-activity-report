# Megatron-LM Monthly Activity Report — September 2026 (through September 20, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/09.md)

> Reporting window: 2026-09-01 through 2026-09-20 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work advanced DeepSeek-V4 sparse attention, MFSDP and context parallelism, MoE execution, inference serving, checkpoint reliability, quantized execution, and training correctness. Ongoing work advances hybrid and multimodal architectures, dynamic context parallelism, sparse attention, distributed sharding, CUDA Graph execution, inference, and determinism and checkpoint reliability.

- Substantive PR activity after filtering: opened 433; merged 227; closed without merge 135; active at cutoff 317.
- Excluded from the report and statistics: test-only 37, CI-only 17, test/CI-only 4, format-only 0.

## Delivered

### DeepSeek-V4 compressed sparse attention

Implemented native hybrid attention construction and fused, packed, and deterministic compressed sparse attention execution.

- Added native DeepSeek-V4 hybrid attention orchestration and HybridModel construction, including grouped projections, MTP identity propagation, indexer-loss scheduling, layer-ratio validation, and stack specifications. ([main #6402](https://github.com/NVIDIA/Megatron-LM/pull/6402), [main #6405](https://github.com/NVIDIA/Megatron-LM/pull/6405))
- Added the fused SBHD compressed sparse attention backend with hardware-aware selection and fused indexer loss, then fused packed-THD layout lowering, indexer and compressor preparation, attention glue, and sparse-loss postprocessing. ([main #6404](https://github.com/NVIDIA/Megatron-LM/pull/6404), [dev #7064](https://github.com/NVIDIA/Megatron-LM/pull/7064))
- Made CSA Top-K selection deterministic across gradient and no-gradient forwards and masked padded tokens before sparse attention. ([dev #7169](https://github.com/NVIDIA/Megatron-LM/pull/7169))

### MFSDP and packed context parallelism

Expanded MFSDP sharding and fine-grained scheduling while enabling packed context-parallel attention and accumulation workflows.

- Enabled different ZeRO sharding strategies for expert and non-expert parameters, hybrid inner and outer data parallelism, and explicit bucket layouts with corrected gradient scaling. ([main #6594](https://github.com/NVIDIA/Megatron-LM/pull/6594), [main #6773](https://github.com/NVIDIA/Megatron-LM/pull/6773))
- Integrated MFSDP v2 lifecycle hooks and no-sync gradient accumulation with combined 1F1B scheduling for expert-parallel overlap, preserving accumulated gradients across microbatches. ([main #7112](https://github.com/NVIDIA/Megatron-LM/pull/7112), [main #7186](https://github.com/NVIDIA/Megatron-LM/pull/7186))
- Added runtime context-parallel attention support with lazily created Transformer Engine streams and packed-THD batch layout views for independently partitioned sequences, while carrying multimodal metadata, partitioning and gathering vision tokens, preserving padding and loss weighting, and coordinating dataloader checkpoint state. ([main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821), [main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912), [main #7315](https://github.com/NVIDIA/Megatron-LM/pull/7315))

### MoE megakernels, routing, and hybrid blocks

Added alternative MoE execution and routing mechanisms, including megakernel integration, global balancing, expert-bias correctness, and ShortcutMoE blocks.

- Introduced a pluggable Mixture-of-Kittens MoE megakernel boundary covering routing, expert computation, combination, MXFP8 views, and gradient accumulation while retaining MCore parameter and checkpoint ownership. ([dev #6572](https://github.com/NVIDIA/Megatron-LM/pull/6572))
- Added Kimi K3 global-batch quantile balancing with persistent expert histograms across gradient-accumulation microbatches and preserved exact int64 expert counts for routing-bias updates. ([dev #6637](https://github.com/NVIDIA/Megatron-LM/pull/6637), [main #6638](https://github.com/NVIDIA/Megatron-LM/pull/6638), [main #7081](https://github.com/NVIDIA/Megatron-LM/pull/7081), [main #7394](https://github.com/NVIDIA/Megatron-LM/pull/7394))
- Added ShortcutMoE hybrid blocks with shortcut normalization and interleaved attention-over-A2A execution, including support for offload, recompute, and hybrid model paths. ([main #6959](https://github.com/NVIDIA/Megatron-LM/pull/6959))

### Inference coordinator, prefix caching, and MTP serving

Improved dynamic inference request handling and extended prefix-cache and MTP attention-cache support across serving paths.

- Changed inference coordinator messaging to separate metadata and body frames, moved prompt hashing to clients, versioned prefix hashes by weights, and added TTL-based eviction. ([main #6497](https://github.com/NVIDIA/Megatron-LM/pull/6497))
- Added MTP attention KV-cache support across dynamic inference, prefix caching, disaggregation, and CUDA-graph request paths. ([main #7033](https://github.com/NVIDIA/Megatron-LM/pull/7033))
- Hardened dynamic inference admission, checkpointing, pause/resume, recomputation, completion, and result construction while preserving request identity and prompt-memory ownership. ([main #7256](https://github.com/NVIDIA/Megatron-LM/pull/7256))

### Checkpointing, refit, and distributed state correctness

Improved quantized checkpoint reproducibility, distributed RNG and dataloader state, GTP rematerialization, and large-scale resharding transfers.

- Re-derived quantized parameters from FP32 optimizer masters during checkpoint loading and included data/context-parallel rank information in distributed RNG-state shard addresses. ([main #6666](https://github.com/NVIDIA/Megatron-LM/pull/6666), [main #6858](https://github.com/NVIDIA/Megatron-LM/pull/6858))
- Corrected GTP-rematerialization sizing, process-group propagation, inference shard declarations, and tied-embedding compatibility across checkpointing and RL refit flows. ([main #6940](https://github.com/NVIDIA/Megatron-LM/pull/6940))
- Bound NCCL refit peer-to-peer groups with parameter batches and task-ID windows to avoid oversized split kernel plans during large-model resharding. ([main #7189](https://github.com/NVIDIA/Megatron-LM/pull/7189))
- Changed dataloader checkpoint indexing to use the GTP-spanning data-parallel rank, with an opt-in shared state file for rank-independent loaders. ([main #7413](https://github.com/NVIDIA/Megatron-LM/pull/7413))

### NVFP4, MXFP8, and Megatron-Lite execution

Extended quantized training and inference execution across DeepSeek, selective module storage, batch-invariant MoE paths, and the DSv4 Lite stack.

- Added DeepSeek-V3 NVFP4 support for overlap and MTP paths, selective module precision configuration, delayed MLA down-projection gradients, and fused-MLA checkpoint-name compatibility. ([main #6841](https://github.com/NVIDIA/Megatron-LM/pull/6841))
- Added per-module BF16 or MXFP8 inference storage selection and batch-invariant MXFP8 execution across Torch, vLLM-selected, FlashInfer, and Transformer Engine grouped-tensor paths. ([main #7300](https://github.com/NVIDIA/Megatron-LM/pull/7300), [main #7302](https://github.com/NVIDIA/Megatron-LM/pull/7302))
- Moved the DSv4 Lite path toward Core attention, MoE, activation, rotary, and gradient-accumulation fusions while removing redundant layout and optimizer work. ([dev #7127](https://github.com/NVIDIA/Megatron-LM/pull/7127))

### CUDA Graph, optimizer, and deterministic training correctness

Strengthened graph-captured training, optimizer layout handling, cross-parallel gradient scaling, and determinism validation.

- Aligned Hybrid mHC activation-offload event ownership, backward completion, rotary capture, and delayed expert offload with Transformer Engine CUDA Graphs. ([dev #7014](https://github.com/NVIDIA/Megatron-LM/pull/7014))
- Corrected repeated MTP gradient accumulation by preventing unsupported first-microbatch signaling from overwriting contributions across repeated layers. ([main #6965](https://github.com/NVIDIA/Megatron-LM/pull/6965))
- Made Muon fused-QKV splitting depend on the globally gathered shape after GTP all-gather and corrected expert gradient prescaling when EGTP and GTP degrees differ. ([main #7117](https://github.com/NVIDIA/Megatron-LM/pull/7117), [main #7165](https://github.com/NVIDIA/Megatron-LM/pull/7165))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Each PR citation identifies its target branch. Open PRs do not carry into a new month without code or state activity in that month.
