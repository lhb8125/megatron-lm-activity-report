# Megatron-LM Monthly Activity Report — September 2026 (through September 6, 2026)

> Chinese version: [中文版本](https://github.com/lhb8125/megatron-lm-activity-report/blob/main/reports/zh-CN/2026/09.md)

> Reporting window: 2026-09-01 through 2026-09-06 (Asia/Shanghai); source: [`NVIDIA/Megatron-LM`](https://github.com/NVIDIA/Megatron-LM).

## Overview

Delivered work advanced inference serving, context-parallel execution, distributed optimization, model features, checkpointing, and validation across Megatron-LM. Ongoing work advances sparse attention, distributed training and sharding, hybrid architectures, inference, CUDA Graph execution, and dynamic context parallelism.

- Substantive PR activity after filtering: opened 87; merged 58; closed without merge 28; active at cutoff 147.
- Excluded from the report and statistics: test-only 12, CI-only 2, test/CI-only 1, format-only 0.

## Delivered

### Inference serving, routing, and request reliability

Improved inference frontend scaling, coordinator routing, prefix-cache behavior, request cancellation, sampling robustness, and multimodal execution.

- Scaled HTTP inference frontends with data-parallel replicas, moved tokenization and related CPU work off the coordinator event loop, and updated coordinator framing, prompt hashing, prefix-cache versioning and TTL handling, and load-aware routing. ([main #6223](https://github.com/NVIDIA/Megatron-LM/pull/6223), [main #6497](https://github.com/NVIDIA/Megatron-LM/pull/6497))
- Strengthened serving reliability by cancelling orphaned requests, sanitizing non-finite log probabilities and sampling filters, validating prefix-cache state across hybrid and asynchronous paths, covering asynchronous scheduling scenarios, and moving multimodal inputs to CUDA before vision-encoder recomputation. ([main #6916](https://github.com/NVIDIA/Megatron-LM/pull/6916), [main #6976](https://github.com/NVIDIA/Megatron-LM/pull/6976), [main #6993](https://github.com/NVIDIA/Megatron-LM/pull/6993), [main #7031](https://github.com/NVIDIA/Megatron-LM/pull/7031), [main #7053](https://github.com/NVIDIA/Megatron-LM/pull/7053))

### Context parallelism and packed-sequence training

Expanded variable-length and packed-sequence support while correcting hybrid and runtime context-parallel batch, attention, and THD layouts.

- Preserved dataset metadata during context-parallel partitioning, integrated variable-length batches and sequence-packing scheduling into GPT and hybrid pretraining, and restored the two-dimensional hybrid-CP batch schema required by tensor-parallel ranks. ([main #5531](https://github.com/NVIDIA/Megatron-LM/pull/5531), [main #6742](https://github.com/NVIDIA/Megatron-LM/pull/6742), [main #6820](https://github.com/NVIDIA/Megatron-LM/pull/6820))
- Made runtime context-parallel attention use lazily created Transformer Engine streams and runtime packed-sequence groups, partitioned packed THD sequences independently while reusing redistribution plans through MTP, and added GDP chunkwise context parallelism across supported backends. ([main #6821](https://github.com/NVIDIA/Megatron-LM/pull/6821), [main #6912](https://github.com/NVIDIA/Megatron-LM/pull/6912), [main #7038](https://github.com/NVIDIA/Megatron-LM/pull/7038))

### FSDP and MFSDP sharding, prefetch, and storage

Improved mixed MoE sharding, communication scheduling, persistent parameter and gradient storage, and distributed optimizer compatibility.

- Added FSDP parameter prefetching and independent MFSDP forward and backward prefetch budgets, while keeping model weights and main gradients in persistent storage across optimizer steps. ([main #5985](https://github.com/NVIDIA/Megatron-LM/pull/5985), [main #6905](https://github.com/NVIDIA/Megatron-LM/pull/6905), [main #6962](https://github.com/NVIDIA/Megatron-LM/pull/6962), [main #7001](https://github.com/NVIDIA/Megatron-LM/pull/7001))
- Enabled different FSDP sharding strategies for expert and non-expert parameters, connected delayed Transformer Engine weight gradients to MFSDP completion, detached distributed-optimizer parameter views into leaf shards, and aligned sharding-strategy validation with the shared ZeRO ladder. ([main #6594](https://github.com/NVIDIA/Megatron-LM/pull/6594), [main #6697](https://github.com/NVIDIA/Megatron-LM/pull/6697), [main #6982](https://github.com/NVIDIA/Megatron-LM/pull/6982), [main #6983](https://github.com/NVIDIA/Megatron-LM/pull/6983))

### Transformer Engine model features and training paths

Added fused attention and activation capabilities, LatentMoE normalization, and an MTP-only training mode while correcting activation dispatch.

- Fused DeepSeek Q up-projection with RoPE and MXFP8 quantization through Transformer Engine for MLA execution. ([main #6213](https://github.com/NVIDIA/Megatron-LM/pull/6213))
- Added SiTU-GLU across dense and expert paths, LatentMoE RMSNorm projection support, and tanh soft-clamped squared-ReLU and SiTU GLU variants across fused and unfused MoE training and inference paths. ([dev #6673](https://github.com/NVIDIA/Megatron-LM/pull/6673), [dev #6804](https://github.com/NVIDIA/Megatron-LM/pull/6804), [main #7003](https://github.com/NVIDIA/Megatron-LM/pull/7003))
- Corrected Transformer Engine activation selection for ReGLU and ReLU and added MTP-only training that excludes the backbone from optimizer and DDP buffers and runs its decoder without gradients. ([main #5999](https://github.com/NVIDIA/Megatron-LM/pull/5999), [main #7021](https://github.com/NVIDIA/Megatron-LM/pull/7021))

## Scope and Method

The narrative is grouped by technical theme rather than PR chronology. Related `dev` and `main` PRs are described once. The rebuildable raw ledger, exclusion evidence, commit activity, and state events are retained in the workflow database artifact. PRs closed without merge are counted but not narrated. Each PR citation identifies its target branch. Open PRs do not carry into a new month without code or state activity in that month.
